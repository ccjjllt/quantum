# VQCC modular parts bundle (public copy)

Metadata and typed interfaces for public inverse-square-root, chemistry and DQI circuit parts. Source KMB and NPZ bytes are in the separate public circuits corpus. One exact HW-25 cross-source assembly has a hosted official-verifier PASS; other cross-source joins retain their scoped local or unknown evidence tiers. DQI sampled reports are SHA-pinned but not included here. `query.py` returns pairwise status, never a whole-circuit proof.
