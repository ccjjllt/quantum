# VQCC modular circuit parts

Apache-2.0 metadata catalogue for circuit assembly research. This dataset contains no KMB or NPZ source bytes; attach `manwithacat/vqcc-apache-public-circuits` for those. The accompanying notebook explains the interface and evidence tiers. `module_index.csv` is the tabular search and credit index; `SCHEMA.md` defines the full JSONL records. Run `python query.py BUNDLE summary` after extracting the ZIP. Source authors, notebooks, versions and SHA-256 are in the family records. Recorded local cut checks are scoped; they are not full verifier certificates. Their compact 45-join receipt is included as `invsqrt_local_join_receipt.jsonl`; the source KMBs and verifier are needed to reproduce those checks. DQI stage data was derived from SHA-pinned sampled reports, not reread KMB bytes. Some chemistry factorization notebook versions were unavailable in the source ledger and are marked as such.
