## 2. 每条腿的杠杆与已测边界

### 2.1 invsqrt：`Q·(Toffoli + T/4)`

- 两个乘数都线性。1% 的 Q 或 1% 的 C = +0.094 GM。
- Q = 22（输入 x）+ 22（scratch）。单 wire 删除 110/110 全失败（`ARCHIVE_closed_lines.md` §1）。
- C 的 85.85% 是 Toffoli（1,459.37），14.11% 是旋转合成税（33 × 29.0837 T / 4 = 240 C）。
- 旋转 ε 由 `worst_error_over_tolerance = 0.9995606` 决定：剩余容差只有 0.044%，
  合成误差被迫压到 1.64e-13。要把 ε 放大 10× 需要电路误差降到 0.9956 tol（≈20× 更准），
  Toffoli 代价远超省下的 61 T。**旋转路线关闭。**
- 因此 invsqrt 要动就必须换合成体：要么 40Q 且 C ≤ 1869.93（+10.0%），
  要么 42Q 且 C ≤ 1781.06（+4.78%）。

### 2.2 DQI：`R(ε+)·Q²·T`

- **R 是常数税**：0 失败、N=102,400、δ=2^-128 → ε+ = 8.6606e-4 → R = 1.1912605。
  任何完美电路的 R 都相同，无杠杆。
- **Q 是平方项**：`dcost/cost = 2 dQ/Q`。合同下限 840（70 × 12）。我们 890。
- 盈亏平衡（对 28.15083）每 qubit 允许的 T 增量：

  | 减 k | Q | 成本收益 | 盈亏平衡 T 预算 | 每 qubit |
  |---:|---:|---:|---:|---:|
  | 1 | 889 | 0.225% | +826 T | 826 |
  | 10 | 880 | 2.235% | +8,391 T | 839 |
  | 25 | 865 | 5.540% | +21,527 T | 861 |
  | 50 | 840 | 10.933% | +45,005 T | 900 |

- **实测机制**：最便宜（q864，每 plateau episode 重算 1 个 CCX，925 episodes）= **925 T/qubit**；
  现实界 7,195；888Q 构建实测 7,932。也就是说全项目离「能赚」最近的一处只差 **12%**
  （925 vs 826），但离「每 qubit 都能赚」的 840Q 还差 2.1×（925 vs 447–900）。
- T 面已饱和：0 exact cancel pair（362,984 CCX 上）、0 dead-write、0 |0>-control。
- mean T = 367,120.004 vs 静态上界 367,993 → 条件执行现在只省 873 T（0.24%）。

### 2.3 chemistry：`λ_eff·T·Q`

- `T = angles + T_h`，`angles ≈ 6.6 × rows`（rows = 76 + R·B；当前 1,220 → 8,044），
  `T_h = f(R,B,C,brot)` 是 `SpinFreeData_V1` 的纯函数，`Q = 84 + J·brot + max(90, inner_temp, angles_temp)`。
- `(8,143,44,brot=8)` 落在 `inner_temp=303` 的口袋：k2=5 时 `ceil(log2(352·5)) + 31·19 = 11 + 589 = 600`
  恰好不满足 `< brot·(N−1) = 600`，模型退到 k2=4 → 297 + 6 = 303。B=144 → T_h 7,016（更差）；
  B=118/128 → temp 574/575 → Q 658（更差）。**B=143 是这一族的刀锋最优。**
- 组织者 starter kit 的 FeMoCo 基线 (65,60,60)：Λ=308.45，λ_eff=49.25，e2=16.13 mHa（更差）；
  8 个基线里只有它可提交（其余是别的分子）。
- **chemistry 的每条轴都已关闭，且 Λ 有精确下界**：`E_gap` 钉住 `2·Nneg + 0.5·ΣW² = 540.0`，
  `Nneg ≥ 0 ⇒ ΣW² ≤ 1080`，出厂点 `ΣW² = 1079.846` 已是上限的 99.99%；
  `lam_h2 ≥ 0.25[Σa² + 2|Σ s·H2_I| + ΣH2_I²] = 270.066`，出厂 270.115（距 Cauchy–Schwarz 地板 0.04%）。
  所以 `Λ ≥ 283.095` vs 283.144，**余量 0.049 Λ = GM +0.0003**。注意 verifier 的偏移是
  `W = H2_I − Σ_b w`，`lam_h2` 看 `H2_I`、`H1p`/`E_SOS` 看 `W`，两者不能混。
- 公开的全部 chem npz 都是同一套权重，λ_eff ∈ [46.9216, 46.9217]，**没有任何 Λ < 283.15 的公开件**。
- **Λ 是内禀量，不是项数不够**：组织者基线 (65,60,60) 用 **3,900 个 central 项**（K=R·C=65·60=3,900，
  是我们 K=352 的 11 倍），Λ 反而更高（308.45 vs 283.14）；其 λ_H2 = 295.58 也高于我们的 270.12。
  六个独立 refit 落在 λ_eff 的 1e-5 内，也说明这里没有搜索空间。
  结构下界是 `lam_h2 ≥ 0.25·Σ_k‖y_k‖² ≥ 0.25·‖H‖_F`（取等需 Y 列正交 + cell 内 w 同号；
  而实测 sign-mixing 超额只有 0.154 / 270），所以 Λ 距下界不会远。
- Λ 的下限门 49.0 是**合法性下限**（≈基线 Λ 的 16%），不是「可达 50」的证据。
  Frobenius 下界 ¼‖tei+shift‖_F = 3.70 太松，不构成约束。
- 精度侧：`error_1 = error_2 = 0.0199999985`（门 0.02，余量 1.5e-9）；`E_gap` 恰在 floor；
  loader `angles_qubits = 128 = QUBIT_CAP`。任何 T 削减都先破精度门。

## 3. 榜首 31.01379 的反解

用同一 CT 公式：以我们的 invsqrt + chem 为基准，31.01379 需要 DQI 260.4e9 ⇒ Q ≈ 771（低于合同）；
以我们的 DQI + chem 为基准，invsqrt 需要 56,183 ⇒ Q ≈ 33（不可能）。**所以榜首至少两腿同时领先**，
最可能是 chemistry 明显更便宜（例如 Q_total ≈ 318 或 λ_eff ≈ 35）加 DQI 接近 840。
这两件都不是「重排公开字节」能得到的。

## 4. 结论与条件

**28.15083 = 公开字节上限 × 三条腿实测下限。** 金线及以上需要下面任一条成立：

| 腿 | 需要的新东西 | 定量条件 |
|---|---|---|
| DQI | 新的 in-place 调度，把 1 条 pool wire 的净代价压到 < 826 T/qubit | 当前最好机制 925（差 12%）；840Q 需 < 447–900 |
| invsqrt | 新合成体 | 40Q 且 C ≤ 1869.93，或 42Q 且 C ≤ 1781.06 |
| chemistry | 新因式分解（不是 refit）或新 loader | Λ ≤ 280.22（+0.05 GM）→ ≤ 253.09（金）；或 rows 显著下降且 T_h 不升 |

研究优先级应按「离可赚的距离」排序：**DQI 宽度（差 12%）≫ chemistry Λ（refit 已被证明只能
−0.13%，需要新分解）> invsqrt（需要新算法）**。
