## 4. 为什么其它轴都关死（每条一行证据）

- **chem Q**：`Q = 84 + J·brot + max(outer_temp, inner_temp, angles_temp)`；`k2` 是「从大到小、
  首个体积 < brot·(N−1) 就接受」——**它最大化 inner_temp**。要 k2=3 必须让 k2=4 分支失败，
  brot=8 时需 `B ≥ 67,108,865`。gate-legal `Q_min = 427`。
- **chem rows**：精度按 **B/C 比**标定（实测锚点 3.25→20 mHa、2.93→19.83（量化后 FAIL）、
  1.93→40.24、1.58→73.07），所以 `rows ≈ 76 + 3.25·K`，**与 R 的拆分无关**；K=352 是精度所需 ⇒ rows 钉在 1,220。
- **chem λ**：Cauchy–Schwarz 地板 283.095 vs 实测 283.144，余量 0.049 Λ。
- **chem loader 用 qubit 换 Toffoli**：loader 已用满 128 qubit 上限（77 是临时）。
- **chem SPRINT 合并**：1,144 条 two-body 行全不重复、无互补对，收益恰好 0。
- **chem tree 重选**：path 树更可压（rowdiff 0.753 vs 0.975），但深度 76 会放大角度量化误差，
  而我们的精度余量只有 1.5e-9。
- **DQI Q 口径**：`score = rep_factor · num_qubits² · toffolis`，Q 取**声明值**；但所有非 syndrome
  qubit 被要求逐 shot 回到 `|0>`，所以「分配不用」的 wire 不存在（除非 liveness 实测有例外）。
- **invsqrt**：44Q 是 liveness 峰值；旋转 ε 已被容差钉死（剩余 0.044%）；Z_POW 是逐 bit、dyadic、
  每 wire 一个，无可合并结构。
