## 新解码器算法候选（化学 retrain 失败后的 fallback）

G2 的失败根因是多项式度数形式里 `x` 不是自由移位：`(A,B)←(B,A−q xˢB)` 在度差 1 时交换后不降度，所以需要 ≈2t 步。下一步不是继续优化这个调度，而是换表示/算法。

**x-adic 原型实测（2026-11-18，内核 `jiyujia/qcc-dqi-xadic-gate-29` v4）**：t=35 行数 **3,221/趟**、平均 T **325,671**、4,620/4,620 输入 0 mismatch、42 T/行；宽度 **144 字 = 1,728 Q**。T 轴通过（比现役 367k 低 11.3%），宽度是唯一 gate；若 ≤890 Q，GM **29.33（+1.15）**。

**宽度削减实测（`jiyujia/qcc-dqi-xadic-width-29` v1）**：流式 syndrome 把 σ-only 宽度从 144 降到 **110 字 = 1,320 Q**，但 `u+B+unconsumed syndrome = 72 = 2t+2` 是逐步恒等式；真正的超额是 backward discrepancy window `L_r+1`，峰值 **36 字**。下界 **111 字 = 1,332 Q**；去掉 window 才是 **75 字 = 900 Q**（仅比部署多 1 字）。SIGMA 变体 2,591 行/趟、272,867 T、1,320 Q → GM **23.92**；若 window 免费则 900 Q → GM **30.88**。x-adic 拿到行数，多项式拿到宽度，二者互斥：window-free discrepancy 只能退回多项式 quotient schedule（74 字、3,830 行）或 4 数组（≈4t）。

**quotient sweep 实测：BLOCKED。** 逐字节重建 `5f901c55` 后，tape 里没有 36 字 sweep：544 个 sweep run 全是长度 2，最大 2。362,006 CCX 的实际结构是 219,948（60.8%）三根线都在 72 主字里的真 word×word MAC、**142,058（39.2%）在 26 根 ancilla/control 线（864–889）上**、3,035 个 clean 42-CCX row = 127,470 CCX、49,440 个孤立单 CCX。“104×36”只是算术归一化，不是构建结构；exact row saving = 0。若真按那个模型，天花板是 1,785 行/趟 → 217,526 T → GM 33.55；但 tape 不是那样建的。

**ancilla/control 分类实测：0 T。** 142,058 的构成：D_all3 **79,441（55.9%）**、A_ancilla_target 46,343（32.6%）、B_flag_control 15,218（10.7%）、C_anc_anc 1,056（0.7%）；26 根线在三种角色都忙，无死线。279,570 个 identical CCX 对**全部被 target span 阻塞（0 clean）**，CCZ 5,406 也 0。class A 是真实的 compute/uncompute 链（11,183 个 triple，partner 中位 262 op，p90 42,923）。作者 PW4 只取了 6 个 B_flag_control + 6 个 D_all3，**0 个 class A**。理论上把非首次 class A 全换成 HMR+phase-fix 可到 35,160 T / GM **29.14**，但没有源码无法证明相位修正；这正是作者只取 6 个的原因。tape 已在 floor：39.2% 的 Toffoli 在 2.9% 的 qubit 上，每个 control-bit assignment 一个 Toffoli。**没有可认证的 DQI T 工作剩下。**

**成本模型更正**：部署 tape 的 `.kmb` 逐字节 census 是 **46,221 FIXED / 3,830.5 行/趟**，不是旧参数化的 61,551 / 3,648；旧的“11 行 gap”是参数化伪影。890 Q 的打平行数就是现役行数，部署件已在成本 floor。

候选算法：

1. **x-adic / almost-inverse EEA**：把状态写成 x-adic（幂级数/逆形式），每步是自由移位，可能恢复 1 度/步；需要重新设计表示、Forney 条件、相位清理和宽度。这是最直接的修复。
2. **Berlekamp-Massey**：仓库旧测 1,680Q 是全并行 BM；低宽度 2 数组 BM（35 字）可能 ≤890Q，行数可能低于 EEA。需要 4–8 支点原型。
3. **Gao / Welch-Berlekamp**：从 syndrome 直接插值/解线性系统，可能绕开 EEA 的商项调度；宽度/行数待测。
4. **normalized divstep**：旧原型一致率 0%、贵 12×；只有在 x-adic 表示下重写才有意义。

验收线同 G2：4–8 支点 **≤2,450 行/趟、≤890 Q、100% 与教科书 EEA 一致**；不过线不进整机。

## 结论

- 公开代（44Q/890Q/427Q）的接线、删门、旋转、抽稀、889Q、6T 都已实测关闭；28.18965 是这一代的公开上限附近。
- 原先假设的两条下一代路线——DQI 2 数组 EEA 和 invsqrt 43Q——都已用门级/结构证据判为 no-go：前者 4,970 行/趟、1,728Q、GM 25.70；后者 Q≥44 是当前中间值集合的结构下界。
- 新的 x-adic EEA 把行数降到 **3,221/趟、325,671 T**（若 890Q 则 GM 29.33），但宽度下界 **111 字 = 1,332 Q**；x-adic 拿到行数，多项式拿到宽度，二者互斥。
- quotient sweep 实测 **BLOCKED**：tape 无 36 字 sweep（544 个 run 全长度 2，最大 2），exact row saving 0；x-adic 让行数够但宽度 111 字，二者互斥。
- DQI 掩码插值也已在 890Q tape 上实测 no-go（相位层，~50% phase 失败）；DQI EEA 11 行局部省门实测 0 行可删，floor 就是 367,110.166 mean T；化学 (8,129,44) 重训实测 96.72 mHa（gate 20），重训后 λ=69.74，实际成本 floor **418.3M**，也已关闭。
- DQI 的 ancilla/control 轴也已实测 **0 T**：142,058 个 CCX 的 identical 对 0 个可消，26 根线无死线，class A 是真实 compute/uncompute 链；作者 PW4 只取了 12 个安全 site。tape 的 mean T 367,110.166 是本仓库能认证的 floor。
- **低宽度 BM / Gao / Welch–Berlekamp：实测 no-go（2026-11-18，内核 `jiyujia/qcc-dqi-bmgate-29` v2 COMPLETE）。** 假设“BM 顺序消费 syndrome 可以避开 x-adic 的 backward window”被证伪：`Δ_r = Σ_j C_j s_{r−j}` 中 C 每步都变，所以每个 `s_i` 在生命周期内会配 `L` 个不同 C 系数，窗口无法释放。t=35、30/30 输入一致（t=4–8 共 1,030/1,030）：

  | 变体 | 行/趟（σ+ω） | 行/趟（只 σ） | 峰值字 | Q | 一致性 |
  |---|---:|---:|---:|---:|---|
  | BM-STD（2 数组 + 内积 Δ） | 3,221 | **2,591** | **111** | **1,332** | 30/30 |
  | BM-RES（残差 R=C·s） | 3,711 | 3,711 | 145 | 1,740 | 0/200（未复现，只作宽度上界） |

  - 决定性的下界：`C + B + 未消费 syndrome = 2t+2 = 72`（峰值取等），窗口必须在这 72 字之外 → **3t+6 = 111 字 = 1,332 Q**。
  - 最强形式：`74 − 72 − 3 = −1`，**即使窗口宽度为 0 也装不下（75 字 = 900 Q）**。74 字对任何“2 数组 + 残余 syndrome”的解码器都不可达。
  - 行数 2,591 是所有原型里最好的，但仍超门槛 141 行（5.8%）；成本在 1,320Q 下是现役的 1.635×（GM 23.92）。
  - Gao 插值 `deg q0 = 4,059` → 4,060 字 = 48,720 Q；WB 稠密/三角 → 5,041 / 2,556 字 = 60,492 / 30,672 Q，**严格比 BM 更宽**，故解析关闭，不做 t=4–8 原型。
  - 结论：74 字预算只容得下**不持有 2t 字 syndrome 的单池原地 quotient EEA**，也就是部署件本身；解码器表示这一族到此为止。
  - 证据：`.worktree/dqi/experiments/dqi/20261118_bm/{README.md,RESULT.md}`、`artifacts/20261118_bm/out_v2/bm_gate.json`（SHA-256 `c2f80648…501b`）。
- 所有公开代与已尝试的下一代变体（含 BM/Gao/WB）都已关闭；DQI 在 Q=890 上是结构最优。29+ 需要真正的新一代表示，本轮没有可提交的 DQI 量级候选。
