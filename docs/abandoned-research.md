# 研究概况与放弃原因

2026-11-20 停止三条自研线。下列门数按各自实验范围记录。

| 任务 | 方向与结论 | 放弃原因 |
| --- | --- | --- |
| DQI | 17 阶双载荷欧氏变换。在规则输入上，890Q 整机平均少约 19,516 门。支持异常支点的 890Q 双窗要约 113,553 门，原双窗约 105,453。 | 普通路径漏掉真实跳阶。统一守卫、双阶和三阶融合消耗了节省。 |
| DQI | Padé 编码能把 34 个矩和一个尺度放回 35 个域词。Hankel 双载荷累加 2,772 门。 | 独立输出版本要 1,212Q。原位恢复系数和载荷仍贵。 |
| DQI | Cauchy–Schur、对角修正与伴随补阶。后者对独立 65,536 条输入中的 263 条异常均精确。共享相位的三对角往返子块实测 889Q、7,218 门。 | 完整中心尺度、受控升阶及整窗连接仍超预算。前两条路线还要额外工作位、反馈列或更贵的生成元更新。 |
| DQI | 固定填充降阶、重复乘积复用、域乘降秩。已知重量时可缩短；真输入上的相邻乘积仍满秩，GF(4096) 单乘搜索仍为 42 项。 | 未获得可用于整窗的相干重量标签。复用与降秩都没有可计入的节省。 |
| DQI | 早期 BM、Gao、Welch–Berlekamp 和扩展欧氏重写。 | 同时保存伴随式和解码状态使位宽远超 890Q。 |
| invsqrt | 平移平方拟合覆盖全部 3,133,452 个输入。 | 314 段系数装载、指数处理及清理昂贵，早期完整准备需 90Q。 |
| invsqrt | 两次 14 位表的 50Q 电路全域通过，成本 102,870.59。根地址回收局部少 21.5 门。 | 公开 44Q 电路成本约 74,340，也已使用同一根地址线回收。直接相位展开与历史局部改写没有替换价值。 |
| 化学 | 共享 Givens 角模板单向 3,399 门，实测两体误差 6,615 mHa。精确 J=4 重分批保留全部 1,220 个轨道矢量，单向 5,374 门。 | 前者超过 20 mHa 物理容差，后者高于 4,162 门的打平线。降秩、角字缩减与重训也未同时满足精度和成本。 |
