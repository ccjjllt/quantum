## 3. 四组块检验（全阴性：划分不可机械复述）

作者"五个 rank-86 块"若是机械的，应在 kmx 拓扑留下以下任一痕迹；四组检验全部阴性。

- **3.1 时序块（215 = 5×43 连续块？）**：215 条 loads 间 214 个 CX gap 均匀（均值 65.1，
  57–84，无异常大 gap；假设边界 43/86/129/172 处 gap 为 63/61/66/66，无特征）。
  按目标位切 5 个连续 43-chunk，每 chunk 目标混合比基本相同（q11 恒占优 13–20/43，
  §1 脚本输出）——chunk 不是按目标分离的。
- **3.2 增量秩（19 维？）**：记每条 load 相对上一条向 q126/q127 的 CX 增量向量
  （215×256）。GF(2) 秩：acc126 侧 92、acc127 侧 92、合并 93；双侧拼合行秩 184。
  19 维子空间**不在增量空间里**。
- **3.3 因子秩（19 维？）**：线性化追踪（每 CCX 目标发一个 fresh 形式变量，CX 作 XOR），
  430 个因子向量（215×(L126,L127)）的 GF(2) 秩 = **93**（= 向累加器供数的 93 个源头），
  用到 173 个基变量。朴素线性化下无 19 维 confinement；真因子语义（AND 非线性、
  R 门相位、word 反馈）需要 ANF/酉语义，kmx 拓扑 + 公开文档给不出。
- **3.4 聚类/种子签名**：loads 增量 k-means(k=5) 得尺寸 93/50/36/19/17，
  簇内平均距离 66.3 vs 全局 72.7——基本无分离。按 setup 种子 fresh 变量签名分组得
  85 种组合，最大的两组仅 48/24 条——无 5 分块。k1/k2/k3 的增量程序**互不相同**
  （逐位比较全异），即每 loader 各自重拆分，无共享骨架可抄。
- **3.5 "19"的候选计数（全对不上）**：selection 11；单 word 8（11+8=19 但无对应结构，
  实际被读的 word 位是每字末两位×5=10）；phase-2 去重控制线 8；目标位 12；
  setup 种子 5（q121–q125）或 6（含链）。"19 维"在 kmx 中无句法对应物，应属作者
  合成模型的设计空间（因子基底选取），不可静态复述。

## 4. 形式化：products 重拆分优化问题（自研口径，不复刻作者块）

把"重拆分"写成与作者块定义无关的优化问题。记参考 loader 为
C_ref = P（69 前缀，冻结）+ S_ref + L_ref（m 条 loads，每条 (a_j,b_j→t_j)，a_j/b_j 为
当时刻的线性型，t_j 为 word/借位目标），CX 重编程程序 R_ref 交织其中。

- **输入**：(i) products 多重集：L_ref 的 m 条三元组（对 k1-Lera：m=217，82 种控制对；
  对 k0：m=217，65 种控制对；由 §1 脚本机械提取）；(ii) 控制位宽约束：累加器对数 A
 （k1-Mao 取 A=1：全局单对 q126,q127；一般 A≥1）、qubit 上限（k1：≤128；
  全局 Q=427 不动）、每 block 内重编程 CX 预算（k1 实测均值 ~65/load，可作初始上界）；
  (iii) 功能规格：§0 作者口径——4 seeds 正反可达态 words_match=True、
  无 R 门落在可能-|1⟩ qubit 上。
- **决策变量**：setup 子函数集 S（种子 AND 个数/接线/目标）、loads 序列
  ((A_j,B_j)→t_j)_{j=1..m'}（A_j,B_j 为累加器上的线性型取值）、交织的 CX 重编程、
  目标位映射 t_j。
- **目标**：min 总 CCX = |S| + m'（T 的主项；精确 T 再经 heuristic_costs/circuit_costs 计量。
  k1：6+215=221 phase-2；k0 现状：11+217=228，目标 ≤226 即 static −2）。
- **约束**：(C1) 功能：4-seed 正反 words_match（廉价 oracle；全量 verify.py 只在终选跑）；
  (C2) 架构：每 block 内 loads 共用同一控制对（CX-only 重编程；k1 的制胜结构）；
  (C3) loader-only：字表 W/tree_edges/angle_words 冻结（e2 余量仅 0.003 μHa，
  任何改表先算 error_2——本约束直接禁止，化学门误差 by construction 不动）；
  (C4) 反例约束：k4–k6 同方法 +1/0 增益，优化器在有码 batch（products ~194）
  上必须能复现"不增益即停"（下界感知的早停），不硬拆。
- **与 k0hand 试错的关系**：`20261111_k0hand` 已证 kmx 文本级 peephole（CCX 相邻抵消，
  严格/宽松 0 候选）无路——stage-2 必须在"因子/程序级"搜索，不在文本级删门。

## 5. 判据与 verdict（两条线分开）

- **复刻作者 5×86/19 维划分 → 关闭**（§3 四组阴性 + 无生成代码 + k1/k2/k3 程序互异；
  块成员关系活在因子设计空间，不在电路时序/目标/增量里；继续猜=手工 magic）。
- **自研拆分器（§4 形式化）→ 可立项 stage-2，限定范围**：(i) 先在 toy 上验证方法
  （取 Lera-k1 的单目标邻域如 q17×1+q16×2，或 3-bit selection / ~12-product 微实例，
  BFS 穷举单对程序，对比 Mao 同局部选择；成功标准：复现"单对重 pack 省条数"的
  原理且 CX 开销 ≤ 实测上界）；(ii) toy 通过后才在 k0 上试（目标 static 297→≤295，
  words_match 4-seed 口径先行，verify.py 最后）；(iii) k4–k6 反例约束进早停；
  (iv) 不承诺复现 215，不碰字表。期望上限：k0 −4 双遍 T ≈ −80K（−0.027%），
  失败即关（k0hand 判据延续）。
