原始清单在 `out/block_dump.json`（1,292 条 op）。

## 结构

开头三条就是全部秘密：

```
CCX  66[0] ,  1[0]  -> 67[0]        # 一个 scratch 位：s = a0 & b0
CX   67[0] -> 67[11], 67[9], 67[8], 67[6], 67[5], 67[4], 67[2]
CX    1[6] ->  1[0] ;  1[8] -> 1[0] ; 66[6] -> 66[0] ; 66[8] -> 66[0]
CX   66[8] -> 66[4] ;  1[8] -> 1[4]
CX   67[0] -> 67[1], 67[2], ...
CCX  66[4] ,  1[4]  -> 67[0]        # 直接 toggles 掉上一个积
```

也就是说：

* 整个块**只用一个 scratch 位** `67[0]`；
* 每个 `CCX` 计算一个秩-1 项 `A_l(a) & B_l(b)`（操作数是 word 66/1 的线性组合，由周围的 CX 维护）；
* 算出来立刻 `CX` fan-out 到它贡献的**多个**输出位（这就是双线性算法的 `γ_l` 线性型，CX 免费）；
* 下一个 `CCX` 用**新的线性组合**把同一个 scratch 位 toggles 掉 —— 既算了新项，又清了旧项。

所以 41 个 CCX 就是 **41 个秩-1 项**，没有 2× compute/uncompute，没有 ancilla 阵列，没有垃圾。
和 `dqi_multrank` 从张量侧得到的结论完全一致：这个块的 42 项精确等于 GF(2¹²) 域乘法
（模 `x¹²+x⁶+x⁴+x+1`）的 Toom-4 分解（7 × μ₂(3)=6）。

## 对成本模型的意义

块级乘法的 Toffoli 成本就是 **42**（不是 84）：`7,565 × 42 = 317,730` 与 EEA 两趟实测的
`317,748` CCX 吻合到 0.006%。tape 的 Toffoli 因此 **100% 闭合**：

```
EEA 两趟    317,748  (7,565 个域乘法 × 42)
Chien 判定   44,264  (4,024 位置 × 11)
Chien 相位    5,977  (CCZ)
合计        367,989  = 实测静态 Toffoli
```

没有任何第 4 类 Toffoli 可以捡。唯一能减的是**乘法次数**，而次数由 EEA 的调度
（每步商项数 δ+1）决定 —— 见 `SUMMARY_R3.md` §4.1 与 `dqi_normeea/`。
