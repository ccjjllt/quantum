## 0. 结论

1. **没有一份公开因子分解能赢现役件。** 把两个公开数据集里**全部 19 个**带
   `angle_words` + `tree_edges` 的 npz 都用官方 `evaluate_words` 打分，最低的是
   `open_refit_40.npz` = **298,084,926.15**（+1.17% vs 我们）。其次是
   `refit_845.npz` = 298.40M、`final_refit_40.npz` = 298.93M。
2. **我们的点在三根轴上同时最优**（Pareto）：
   * `T·Q`：我们 **6.2795e6**；公开最好 6.3132e6（`refit_845`），最差 8.3874e6。
   * `λ_eff`：我们 **46.9217**；公开 47.07–49.13（`Λ` 284.94–290.45，我们 283.146 最低）。
   * 精度不是优势：公开件也有 `error_2≈19.98 mHa`、`error_1` 低到 5.69 mHa 的，
     但 Λ 反而更高——**Λ 与形状/精度几乎无关**，由 E_gap 地板 + LCU 一范数钉住。
3. **因此：chem 关闭——公开因子分解空间已穷尽。** 在“形状必须 R·C ≥ 352、
   B=143 才能过精度门”的实测前沿上，现役 `(8,143,44)` 就是合法族的成本最优点
   （形状侧的证明见 `../chem_shape/RESULT.md`：`(4,200,44)` 的 K=176 秩下界
   143.97 mHa，7.2× 门槛，对任意分解不可能）。
4. 没有任何候选值得重建 loader 或打包；本轮**不提交、不打包、不改 `submissions/`**。

## 3. 这张表说明什么

1. **`Λ` 不是形状的函数。** 19 份的 `Λ` 全部落在 284.94–290.45，`λ_eff` 47.07–49.13；
   我们 283.146 / 46.9217 是全体最低。`(4,239,128)` 的 K=512、`error_1` 只有 11 mHa，
   `Λ` 却 290.45；`(8,143,45)` 的 `error_1` 9.5 mHa，`Λ` 287.07。
   这实证支持 `E_gap` 地板 + LCU 一范数的下界 `λ_eff ≥ 46.787`（精确 46.7873），也说明
   “用更多份数/更好精度换低 λ”不存在。
2. **`T·Q` 的最小值就是现役点。** 所有公开件的 `T·Q ≥ 6.3132e6`（`refit_845`），
   比我们 6.2795e6 高 0.54%；而它的 λ 又高 0.74%，合计 +1.28%。
   行数更多的 `(9,143,*)` 系列在“现役 loader 密度”这个乐观假设下都输，
   真实 loader 只会更差。
3. **公开件的 loader 不是我们的对手**：它们自带的完成件 T 是 17,479–18,416
   （`(9,143,46)`/`(8,156,60)`），我们 14,706。这也是为什么公开件里
   `(9,143,46)` 自称 9.47×、我们 11.39×。
4. **“再训练一个公开 seed”没有意义**：即使把某个公开件的 `error_2` 压到 17.8 mHa
   （`M8x156x60_b8`），它的 T·Q 已经 7.09e6，score 335M。

## 4. 与形状工作的关系

形状侧的完整证明在 `../chem_shape/RESULT.md`。一句话版本：

* `error_2` 的 rank-K 下界（K=R·C，来自 2926 维 vech 目标谱）：
  K=176 → **143.97 mHa**、K=264 → 29.94、K=288 → 20.51、K=344 → 8.17、K=352 → 7.36。
  所以简报的 `(4,200,44)`（K=176）和 `(6,143,44)`（K=264）**对任意 U/w/W 都不可能**。
* 该族的结构余量实测 ~13 mHa 且随 C 减小而增大，因此 `error_2 ≤ 20` 要求 K≥352；
  在 K=352 上 `B=136` 实测 21.605、`B=129` 27.226，`B=143` 才过门。
* 减 R 的路线被“合并一组损失 207–392 mHa”（最优化 span 实测）封死。
  结论：`(8,143,44)` 是合法族里 T·Q 与 λ 同时最优的唯一点。
* 无新电路可收的 C 轴（words 只编码 U）也已实测封闭：`C=43` → 21.2264 mHa、
  `C=42` → 23.2501 mHa（都 FAIL），`C≤36` 被秩下界判死。
