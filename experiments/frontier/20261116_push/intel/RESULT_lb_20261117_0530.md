## 2. MCP access notes (for the next session)

- The server is configured in `~/.config/opencode/opencode.jsonc` under `mcp.servers.kaggle`
  (remote, bearer token). It exposes **76 tools** and is reachable, but it is **not injected
  into the Code Mode tool catalog** in this session: `tools.opencode.list_mcp_resources()`
  returns empty and `search({query:"kaggle"})` finds nothing. Calls had to be made as
  JSON-RPC POSTs to `https://www.kaggle.com/mcp` with
  `Accept: application/json, text/event-stream`; responses arrive as SSE (`data: {...}`).
- Two practical gotchas: the leaderboard page token field is **`next_page_token`**
  (snake_case), and long SSE bodies occasionally truncate — retry 3–4× on
  `IncompleteRead`.
- **Permission gap:** `list_notebook_files` / `get_notebook_info` return
  `Permission 'kernels.get' was denied` when called over the raw JSON-RPC path. After the
  MCP tools were injected into the Code Mode catalog (`tools.kaggle.*`, 76 tools) the same
  calls succeed, so use the injected tools first and fall back to the CLI otherwise.
