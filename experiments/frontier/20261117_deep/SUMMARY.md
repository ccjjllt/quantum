## 3. 结论与下一步

**28.15083 不只是「公开字节的上限」，它是三条腿各自可证明/可测下界的交点。** 本轮为每条腿
都给出了下界的来源：

| 腿 | 下界类型 | 余量 |
|---|---|---|
| DQI 宽度 | 实测（全 50 wire 重算表） | 最便宜 1,831 T/qubit vs 盈亏 826 |
| DQI mean-T | 实测（条件深度统计） | 873 T（0.237%） |
| invsqrt 宽度 | 实测（令牌峰值 + Q43 逐线定价） | Q43 需 ≥308 T vs 预算 158 |
| invsqrt uncompute | 实测（MBU 已回收 83.6%） | 付费 uncompute ≤6.7% |
| invsqrt 旋转 | 公式 + 实测 worst/tol=0.99956 | 需 20× 更准才换得 61 T |
| chem T（loader） | 实测（0 条件门、ANF 满支撑） | 金线需 −10%，现件已比公开构造便宜 4.6× |
| chem T（形状） | 实测 + 模型 | B≤128 → Q≥629；保 Q=427 最小 rows=1,108 |
| chem Λ | **精确算术下界** | **0.049 Λ（GM +0.0003）** |

因此本代技术的天花板就在 28.15 附近；金线 28.71339 需要单腿 **−5.77%**，而三条腿都拿不出来。
榜首 31.01379 反解为「至少两腿同时领先」，最可能是 chemistry 明显更便宜 + DQI 接近 840 ——
都是未公开的新一代电路。

**下一步（按性价比）**：
1. **盯公开前沿**（零研发成本、期望收益最高）：任何 team 放出 840–880Q 的 DQI 或 ≤42Q 的
   invsqrt，直接用 `integration/make_main.py` + `kgpu.py` 复核并替换，单项就是 +0.2~+1.1 GM。
2. **换族研究**（数周）：DQI 需新的可逆调度（把 ≤1 条 wire 的净代价压到 <826 T/qubit）；
   invsqrt 需新的合成体（40Q 且 C ≤ 1869.93，或 42Q 且 C ≤ 1781.06）。
3. **chemistry 不再投入**：Λ 已有精确下界，T/Q/形状/loader/λ 全部实测关闭。
