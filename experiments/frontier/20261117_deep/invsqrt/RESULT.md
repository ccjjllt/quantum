## (A) 逐线角色（静态）

解压：b64→zlib **180,382 B**，sha256 `0af21cb8…6b1b`（本机 + kernel 双重复核）。
`num_qubits=44`、`num_bits=377`、`num_registers=1`，唯一寄存器 `"x" = q0..q21`
（little-endian），故 **44 = 22(x) + 22(scratch q22..q43)**。

门表（20833 ops）：`CX 12316, CZ 2136, CCX 1526, HMR 1276, Z 1045, X 964,
PUSH/POP_CONDITION 697/697, BIT_INVERT 54, Z_POW 43, CCZ 34, NEG 30, SWAP 12,
BIT_STORE0 3`。静态 toffoli-like **1560 = 1526 CCX + 34 CCZ**。

要点：

1. **没有任何 scratch 线"只作 control"**，也没有"只被 1 个 CCX 写一次"的线：
   CCXw 分布 0（4 条）、9（2 条）、12–20（6 条）、27–62（7 条）、259/346（2 条）。
2. **x 线不是只读**：q0–q21 上有 **503/1526** 个 CCX target 写入和 **360** 个 HMR。
   即电路把 x 寄存器本身当 AND 工作区（最后再还原），"22 干净 x + 22 scratch"只是
   寄存器划分，不是工作集划分。
3. **不存在 y 寄存器**：20833 ops 里 3258 个（15.6%）是相位门（CZ 2136、Z 1045、
   CCZ 34、Z_POW 43），且 33 个旋转集中落在 6746–7207 与 12000–12500，即
   **1/√x 的数位一算出来就顺着阶梯位把相位倾倒掉**，随后用 HMR 把该数位抹掉。
   电路结束时 scratch 全 |0>（追踪器复核 `scratch all |0> = True`，
   见 kernel `qcc-invsqrt-toffoli-face-0af21cb8` v3），所以 y 从未被存储。
4. q21 是全场最热的线（1498 ops），因为它是 x 的最高位，同时充当相位倾倒的汇。

## (B) compute / uncompute 占比 → 测量式反计算已用尽

- 付费 toffoli-like 1560，其中只有 **52 对（104 个 CCX，6.7%）**能找到"后面出现同一个
  CCX"的镜像对（栈式配对）；其余 1422 个 CCX 的反算由 **1276 个 HMR** 完成。
- 697 个 `PUSH_CONDITION` 块中 **630 个（90.4%）只含相位门**（Z/CZ/CCZ）⇒ 修正网络
  是纯 Clifford，反计算 **0 Toffoli**；只有 67 个块含会改值的门（X/CX/CCX）。
- 因此 **uncompute 占 Toffoli 的比例 ≈ 0%（上界 6.7%）**，远低于 35% 触发线。
  本件已经是"全部 AND 都用测量式反计算"的形态，这条路线没有剩余空间。

若要复用到别处，可判定判据是：只有当被反算的垃圾位是**控制线的 AND**
（`t = a∧b`，修正只需 `CZ(a,b)` + 若干 `Z`，全 Clifford）时才免费；若垃圾位是
`x` 的拷贝/XOR（`CX`/`X` 生成），修正依然是 Clifford 但本来就不需要测量；若垃圾位
含**和/或**不可 Clifford 化的项，修正本身要 CCX，价格与直接重算相同甚至更贵。
本件 100% 落在第一类，因此最小实验（把某个镜像 CCX 换成 HMR+修正）无收益，不设计。

## (C) 宽度-门数交换 → Q44 是这条门序列的下界

令牌模型（可靠）：写目标都是**异或累加**，所以旧值除"写前值是静态已知常数"（HMR 复位、
X 跟踪）外都被该写消耗；令牌 = 从创建写到最后一次读（若下一次写前值未知，则延长到那次写）。

| 量 | 值 |
|---|---|
| 令牌总数 | 15,058 |
| **令牌并发峰值** | **44 @ op 1689**（`CCX q16 q17 q43`），此时 44 条线全部承载令牌（22 x + 22 scratch） |
| 并发分布 | 44 × 5470 ops、43 × 7067、42 × 2105、41 × 1125、40 × 868 |
| 单线退役效果 | 退役**任意一条**线（22 条 scratch 或 22 条 x 任选）都把峰值降到 **43** |
| 贪心退役 | 连续退役 q22,q23,q24,q25 → 峰值 43,42,41,40（每退 1 条降 1） |
| 生命期不相交的 scratch 对 | **0**（22 条两两重叠，x/scratch 之间也 0） |

因此：**Q44 = 这条门序列的最小宽度**；Q42 要且只要退掉 **2** 条 scratch，Q40 要退 **4** 条。
这也解释了归档记录里 Q42 单 wire 删除 110/110 全失败——不是删错了线，是**没有可删的线**。

### 退役代价（用重复计算替代）

唯一可退役的候选是 A 组的 q22–q25（只有它们从不需要非仿射值）：
把 `CCX(a1⊕…⊕ak, y, t)` 展开成 k 个 CCX（因 `(⊕ai)·y = Σ ai·y`），
所以每条线的价格 ≥ `Σ_reads(k−1)`，读次数分别是 **64 / 41 / 34 / 26**。

| 目标 | 需要 C ≤ | 相对 1699.9401 的预算 |
|---|---|---|
| Q43 | 1739.47 | **+39.53** (+2.32%) |
| Q42 | 1780.89 | **+80.95** (+4.76%) |
| Q40 | 1869.93 | **+169.99** (+10.0%) |
| Q44 金线 | 1606.50 | **−93.44** (−5.50%) |

最便宜的两条（q25=26、q24=34）加起来 **60** Toffoli，形式上落在 Q42 的 81 预算内

这条收尾反计算链，不是文本级改写。→ **NO-GO**（不是代价问题，是测量语义问题）。

| 检查 | 结果 |
|---|---|
| ① 相邻自逆对消（X/Z/CX/CZ/SWAP/CCX/CCZ 栈式） | **0 对** |
| ② 死 CCX（`a∧b ≡ 0`） | **0** |
| ②′ CCX→CX 降级（`a∧b ≡ b`、`≡ a` 或 `a ≡ b`） | **0** |
| ③ 死写（写了从不读、也不被下次写消耗） | **0** |
| ④ 死相位：CCZ / CZ / Z·Z_POW | CCZ **2**、CZ 8、CX 15（死门）、Z·Z_POW **0** |

（kernel 日志里写的 0.137% 是把分母误用成 1459.99 的结果，正确分母是含旋转 T 的
1699.94；两种口径都远低于门槛，判定不变。）

即便如此仍做成候选（只删 `op 20739 CCZ q22 q2 q3` 与 `op 20746 CCZ q25 q4 q5`，
其余 20831 ops 一字不动，候选 sha256 `85220a0f…a128c`，静态 toffoli-like 1560→1558），
在 kernel `jiyujia/qcc-invsqrt-2ccz-dead-verify` **v1 COMPLETE** 上用**未修改的官方
verifier、全 200,540,928 shots、默认 salt** 跑：

```json
{"status": "FAIL",
 "error": "x=12: phase error 5.000e-01 turns exceeds tolerance 1.721e-08."}
```

⇒ **这 2 个"死 CCZ"是假阳性**。原因：它们在条件块内，相位贡献是 `m·a·b·c`，其中 `m`
是 HMR 的 X-基测量结果。追踪器把 `m` 当成 iid 随机位，能通过"a∧b∧c 在采样到的 m 上恒 0"，
但真实电路的 m 不是自由的（否则相位会随机），追踪出的**中间值因此与真实电路不同**。
这条 falsification 同时说明：**该追踪器对条件块内的门不可靠**，所以 (D) 的"0"只能算
"未发现"，不能算"证明不存在"；而唯一的正发现已被官方 verifier 否掉。

## 要什么样的新合成体才可能突破 Q44 / C1699.94

定量条件（三条互斥的可行方向，任一满足即可）：

1. **换宽度**：新体在**每一个 op 上并发 scratch 令牌 ≤ 20**（当前 22 @ op 1689），
   且 `C ≤ 1780.89`（+80.95 Toffoli-equivalent，+4.76%）。等价说法：22 条 scratch 里
   **至少退掉 2 条**，且这 2 条的 CCX-control 读次数之和 ≤ ~80（当前最便宜的两条
   q25+q24 = 60，但它们的收尾 HMR 反计算链必须重设计）。
2. **换宽度更狠**：4 条退役 + `C ≤ 1869.93`（+169.99，+10.0%）→ Q40 = 67,998，
   GM +0.91。当前 4 条最便宜之和 = 26+34+41+64 = **165 < 170**，是**形式上唯一**
   还有一丝余量的组合，但同样卡在测量语义上。
3. **只降 C**：`C ≤ 1606.50`（−93.44，−5.50%）才能单独换到金线。Toffoli 面只剩
   0.118% 可刮，所以这要求相位多项式本身**少 ~6% 的 AND 项**（≈95 个 CCX），
   或把 33 个旋转的单价 29.08 T 降下来（ε 被 `worst-tol=0.99956` 锁死，
   必须先把算法误差压低 ≥4 个数量级，代价远超收益）。

即：**在这条算法族里做局部改写已经没有出路**；要么拿到能少 2 条并发工作位的
新合成体（代价上限 +80.95 Toffoli），要么换相位多项式的合成方式（少 ~95 个 AND 项）。
