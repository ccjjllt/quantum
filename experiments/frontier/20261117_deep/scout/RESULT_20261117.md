## 1. Method

*Local (no simulation):*
- `kaggle datasets files <ref>` / `kaggle datasets download <ref> -f <member>` for
  listings and for files ≤ 2 MB. The 479 MB DQI member was **not** downloaded; it was
  hashed inside the kernel.
- sha256 of every member we compared; `numpy` reads of `angle_words` (1220, 75 int64),
  `tree_edges` (75, 2 int64), `W` (8,143,44), `H2_I` (8,44). Nothing larger.
- Cost arithmetic: `chem = lambda_eff · T · Q`, `invsqrt = Q · (Toffoli + T/4)`,
  `dqi = R(eps+) · Q² · T`; GM via `scripts/gm.py`.

*Kaggle CPU kernels (unchanged official code from the competition mount):*
1. **`qingyu1232/qcc-scout-ratnachand-floor` v3** (COMPLETE). Mounts
   `ratnachand/vqcc-verified-public-floor` + the competition. Prints sha256/size of all
   19 members and runs the unmodified `verifiers/dfthcsos/verify.py::verify()` on the
   dataset's `dfthcsos/` directory (78,080 shots).
   Outputs: `artifacts/20261117_scout/out_ratna/ratna_hashes.json`,
   `.../ratna_chem.json`.
2. **`qingyu1232/qcc-scout-word-screen` v2** (COMPLETE). Mounts the Apache mirror + the
   atlas + ratnachand + the competition; loads each `factorizations/*.npz` and compares
   its `angle_words`/`tree_edges` with ours by value (dtype-tolerant), and for exact
   matches evaluates the official `evaluate_words` and re-verifies the cheapest one.
   Output: `artifacts/20261117_scout/out_ratna/word_screen.json`.
   Sources: `experiments/frontier/20261117_deep/scout/kernel_ratna/main.py` and
   `.../kernel_words/main.py` (both pushed with `scripts/kgpu.py`, CPU-only metadata).

*Evidence tiers used below:* (a) **official verifier, run by us** — only the ratnachand
chemistry file (PASS, default salt, 78,080 shots, unchanged `verify.py` from the
competition mount); (b) **publisher's own ledger number** — all hedge/atlas/Apache
figures, quoted with the column they come from and not re-verified here; (c) **our local
hash/array comparison** — the "identical to ours" and "same word table" claims.
No Kaggle leaderboard score was produced or claimed.
