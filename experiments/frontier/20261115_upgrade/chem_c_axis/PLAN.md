# 化学：换轴研究——C（乘积数）而不是 B（基函数数）

日期：2026-11-15。状态：**新方向，已上线实测**（前面的 B 轴结论不变，但这条轴此前从未被检验）。

## 1. 为什么此前一直在砍错的东西

官方 `score = lambda_eff · T_total · Q_total`，其中 `T_total` 是静态 Toffoli 数。
`T` 由 `verifiers/dfthcsos/scoreinfra/costs_prepare.py` 的 `SpinFreeData_V1` 给出：

```
T = outer_state_prep() + inner_state_prep() + givens_rotations()
```

把 (R,B,C) = (8,143,44)、N=76、chi=10、beta=8 代进去得到 **6,662**，而我们的提交件实测
`T = 14,728 ≈ 2 × 6,662 + 1,404`（正/反两遍 + loader 的额外 Toffoli）。用这个标定
（`T_real ≈ 2·model + 1404`）做**局部**斜率：

```
dT_real/dC ≈ -156  Toffoli / 每个乘积（C 减小）
dT_real/dB ≈   -4  Toffoli / 每个基函数（B 减小）
```

**C 轴的单价是 B 轴的约 40 倍。** 原因在结构里：`inner_state_prep` 的 QROAM 项是

```
for_qroam = R*C*ceil((B+1)/2**k2) + 2**k2 * b2
```

C 是**线性**乘数，B 只在跨过 `ceil((B+1)/2**k2)` 的台阶或 `QR(...)` 的 k 变化时才跳变。
所以 143→129（−14 个基函数）在模型里只省 28 个 Toffoli，而 44→36（−8 个乘积）省 628 个。

这解释了为什么上一轮把整个 B<143 线关掉之后仍然看不到希望：那条轴本来就只有
**+0.003…+0.03 GM** 的量级（不是之前估的 +0.2~+0.7 —— 那个 +0.2 来自错误的
`dT/dB = −42.4`，而 −42.4 是 Stage A 的外推，不是模型真值）。

## 3. 唯一的门槛：精度

现用 (143,44) 的连续 floors 是 **14.778 mHa**，量化后正好 **20.000 mHa**（闸门 = 20 mHa），
即公开件**没有任何余量**。所以砍 C 必须同时把 fit 变好，否则 error_2 直接越界。

这正是 Adam 那条"尚未拉动的杠杆"的用处：
上游 `adam_train.py` 自述 *"the public seeds came out of tens of thousands of Adam epochs and
prune far better"*。若 Adam 能把 (8,143,44) 的连续 error_2 从 14.78 压到 ~11，
那么 C 砍到 36（rounding 代价按角度数等比略降到 ~4.8 mHa）仍有 ~4 mHa 余量，
**143×36 = GM 28.14**，是本会话能碰到的最大单点收益。

## 5. 与已关闭的 B 轴的关系

B 轴（`chem_b129/CLOSED.md` §1–§14）的结论**依然成立且更强**：它的收益上限本来就只有
+0.02~+0.03 GM，而实测连续误差 16.17/18.41/19.83/21.13 全部越界。那份工作的真正价值是
把 (143,44) 的连续地板与 rounding 代价钉死成 14.78 / 5.22 mHa——这两个数正是本节 C 轴
实验的判据来源。
