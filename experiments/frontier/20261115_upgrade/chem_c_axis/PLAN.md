# 化学：换轴研究——C（乘积数）而不是 B（基函数数）

日期：2026-11-15。状态：**新方向，已上线实测**（前面的 B 轴结论不变，但这条轴此前从未被检验）。

## 1. 为什么此前一直在砍错的东西

官方 `score = lambda_eff · T_total · Q_total`，其中 `T_total` 是静态 Toffoli 数。
`T` 由 `verifiers/dfthcsos/scoreinfra/costs_prepare.py` 的 `SpinFreeData_V1` 给出：

```
T = outer_state_prep() + inner_state_prep() + givens_rotations()
```

把 (R,B,C) = (8,143,44)、N=76、chi=10、beta=8 代进去得到 **6,662**，而我们的提交件实测
`T = 14,728 ≈ 2 × 6,662 + 1,404`（正/反两遍 + loader 的额外 Toffoli）。用这个标定
（`T_real ≈ 2·model + 1404`）做**局部**斜率：

```
dT_real/dC ≈ -156  Toffoli / 每个乘积（C 减小）
dT_real/dB ≈   -4  Toffoli / 每个基函数（B 减小）
```

**C 轴的单价是 B 轴的约 40 倍。** 原因在结构里：`inner_state_prep` 的 QROAM 项是

```
for_qroam = R*C*ceil((B+1)/2**k2) + 2**k2 * b2
```

C 是**线性**乘数，B 只在跨过 `ceil((B+1)/2**k2)` 的台阶或 `QR(...)` 的 k 变化时才跳变。
所以 143→129（−14 个基函数）在模型里只省 28 个 Toffoli，而 44→36（−8 个乘积）省 628 个。

这解释了为什么上一轮把整个 B<143 线关掉之后仍然看不到希望：那条轴本来就只有
**+0.003…+0.03 GM** 的量级（不是之前估的 +0.2~+0.7 —— 那个 +0.2 来自错误的
`dT/dB = −42.4`，而 −42.4 是 Stage A 的外推，不是模型真值）。

## 3. 唯一的门槛：精度

现用 (143,44) 的连续 floors 是 **14.778 mHa**，量化后正好 **20.000 mHa**（闸门 = 20 mHa），
即公开件**没有任何余量**。所以砍 C 必须同时把 fit 变好，否则 error_2 直接越界。

这正是 Adam 那条"尚未拉动的杠杆"的用处：
上游 `adam_train.py` 自述 *"the public seeds came out of tens of thousands of Adam epochs and
prune far better"*。若 Adam 能把 (8,143,44) 的连续 error_2 从 14.78 压到 ~11，
那么 C 砍到 36（rounding 代价按角度数等比略降到 ~4.8 mHa）仍有 ~4 mHa 余量，
**143×36 = GM 28.14**，是本会话能碰到的最大单点收益。

## 5. 与已关闭的 B 轴的关系

B 轴（`chem_b129/CLOSED.md` §1–§14）的结论**依然成立且更强**：它的收益上限本来就只有
+0.02~+0.03 GM，而实测连续误差 16.17/18.41/19.83/21.13 全部越界。那份工作的真正价值是

实验的判据来源。

## 6. 实测：砍 C 的精度账单（`jiyujia/qcc-chem-cprobe`，T4，COMPLETE）

同一公开 seed、同样 L-BFGS 预算（`500/2500/8000`，`--select impact --kappa 5e-5`），只改 C：

```
== shrinkage to (8,143,40)   [rc 0, 222 s]
    8x143x44: error_2   20.000 ->   20.000 mHa  D  0.15  (2 s)      # 起点＝已量化的公开表

 143x40 x0.2: error_2  150.190 ->   23.797 mHa  D 14.16  (44 s)
    8x143x40: error_2   37.016 ->   20.103 mHa  D  6.27  (170 s)   # 连续值
== shrinkage to (8,143,36)   [rc 0, 420 s]
 143x36 x0.5: error_2 1032.494 ->   32.305 mHa  D 17.51  (25 s)
 143x36 x0.2: error_2  292.266 ->   33.292 mHa  D 19.50  (42 s)
    8x143x36: error_2   64.771 ->   29.127 mHa  D  8.08  (164 s)   # 连续值
```

（`8x…` 那行的值就是**连续** error_2，这一点由 roundcal 那次同格式日志
`8x143x44: 16.178 -> 14.777` 与独立测得的 14.777 对齐确认。）

| shape | 连续 e2（L-BFGS） | 相对 (143,44) 的 14.777 | 每砍 1 个 C 的代价 | 过闸门需要的 e2 |
|---|--:|--:|--:|--:|
| 143×44 | **14.777**（两次复现） | — | — | 14.78（已压线） |
| 143×40 | **20.103** | **+5.33** | ≈ +1.33 mHa | ≤15.02 |
| 143×36 | **29.127** | **+14.35** | ≈ +2.25 mHa（深砍更贵） | ≤15.28 |

**结论：C 轴也是"要有 Adam 才谈得上"的轴。** L-BFGS 在 C=40 上已经是 20.1 mHa，
比闸门高 5.1；C=36 是 29.1 mHa，连未量化的 20 mHa 都过不去。

所以 C 轴的可行性完全取决于同一件事：**Adam 能把 (8,143,44) 的连续 14.777 压低多少**。

- 若 Adam 只到 ~13.5（−1.3）：C 轴全死，B 轴本来就只值 +0.02，化学线彻底关闭；
- 若 Adam 到 ~12（−2.8）：(143,42) 可行（需 ≤14.90，估计 17.4−2.8=14.6）→ **+0.20 GM**；
- 若 Adam 到 ~9.5（−5.3）：(143,40) 可行 → **+0.40 GM**；
- 若 Adam 到 ~7：C=38/36 进入射程 → **+0.6…+0.8 GM**。

这就是 `zhuating/qcc-chem-headroom` 与 `jiyujia/qcc-chem-adam-traj-gpu` 里 143 段 Adam 的作用：
它现在是**整条化学线的唯一决定量**。

**读法（这条数据很关键）：**

1. 默认 `--lr 1e-3` 对这个已 L-BFGS 收敛的起点**太大**：第 1000 步冲到 100.9 mHa，
   用了 13,000 步（≈22 min）才回到起点。整条 24k 轨迹的大部分算力花在"从自己造成的破坏里爬出来"。
2. 即便如此，最终仍比起点好 **−0.69 mHa**（20.179 → 19.486），说明 Adam 在这个问题上
   *不是无效*，而是**被错误的学习率浪费了**。
3. 与 C 轴的需求对比：C=40 需要 −5.3 mHa、C=42 需要 −2.5 mHa。
   默认 lr 的 −0.69 远不够；但把 lr 从 1e-3 降到 1e-4（起点不再被摧毁）完全可能多拿几 mHa。

因此下一条实验的唯一改动就是 **lr**：1e-4 → 1e-6，36,000 步，先在锚点 (143,44) 上看
Adam 到底能把 14.777 压到多少，再在 C 轴目标 (143,40) 上用同一配置。
