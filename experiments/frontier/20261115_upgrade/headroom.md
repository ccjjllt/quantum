## 2. 每一项离它的**结构下限**还有多远

### DQI（最值钱的一条）

契约要求 `S0..S69` 共 **70 个 12-bit 量子寄存器**，它们本身就是电路量子比特的一部分：

```
Q >= 70 * 12 = 840        ->  889 -> 840 就是 (840/889)^2 = 0.893，即 -10.7%
```

**−10.7% 单任务 = 成本乘积 −10.7% → 分数 28.36（约 rank 13）。** 也就是仅"把 49 个
ancilla 全砍掉"就能前进约 190 名。但 EEA 不可能零 ancilla，现实目标是砍掉 10–20 个：
**每个 qubit = +0.0205 GM**，这是全表里最陡的单价。

公开件里已经有人做到 **877 qubits**（`ahmedberatozer`，score 444.15e9，隐含 T=485,272），
但它的 T 太贵；只要 877Q 的 T ≤ **393,580** 就能反超我们的 360.2e9。也就是说
"把别人省下的 12 个 qubit 装到我们 T=383k 的算法上" = 444.15e9 → ~360e9×(877/889)²=350.4e9
（+0.24 GM）。这是唯一一条已被证明存在前例的路径。

### invsqrt

公开生成器只有 **46/47/48** 三种手写 body（`patch_w47_body.py:210` 实测断言），
参考件是 Q=260。到 rank 1 需要 **Q=40**（或 T 1,479→1,126，即 −24% Toffoli）。
46→40 需要重新合成 body，与"45 都不存在"是同一件工程。

### chemistry

`cost = λ_eff·T·Q`，Q=427、T=14,728。到 rank 1 需要 T=11,215（−24%）。
按官方成本模型 `dT/dC ≈ −156`、`dT/dB ≈ −4`：**T 只能靠 C 砍**（44→37 才够），
而实测砍 C 的精度账单是 **每砍 1 个 C 约 +1.3 mHa**（(143,40)=20.103、(143,36)=29.127，
基准 14.777），闸门只允许 15.0。所以化学到 rank 1 需要"重新训练一个 C≈37 的基组"，
不是修剪能达到的。

## 3. 结论

- 我们已在**公开件的帕累托前沿上**（DQI 889Q/383k、invsqrt 46Q/1479、chem 427Q/14,728
  都是公开件的最优组合，拼装上限 27.31219）。
- 再往上**每一条**都需要原创电路综合：DQI 的 ancilla 回收、invsqrt 的 40 线 body、
  化学的 C≈37 重训。它们都不是"再跑几次 GPU"能兑现的，性质是数周工程。
- 单点性价比排序：**DQI 每 qubit +0.0205（有 877Q 前例）> invsqrt Q 每 qubit +0.2（无前例）
  > 化学每份 C +0.098（精度账单 1.3 mHa/份，闸门不允许）**。
