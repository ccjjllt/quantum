### 1.2 选择语义 diff（不可同构的三点）

1. **读写方向相反**：已转 q51 步是 `CX q51 q28`（q51 只读，q28 ^= q51；再 `CCX` 得
   q28 ^= q51·(1⊕q21)）；剩余 q41 行是 `CX q28 q41`（q41 被写，借用为 scratch），
   净效果 q28 ^= q21·(q41⊕q28) 且 q41 同步被改（`CX–CCX–CX` 三明治不恢复 q41）。
   两者布尔函数不同，不是同一选择器。
2. **q41 是 live 累加器，不是每步重载的路由 ancilla**：ozer 行 16317 `CCX q21 q28 q41`
  （以 q41 为目标）写入 q41，16318 `CX q41 q28` 读出，值一路存活到 16430 三明治。
   而 S1-loop 的 q41 由 `CSWAP q23 q1 q41`（gengsr 8630）逐次装载、用完即弃。
   改写前提（"CSWAP 装载的大 aux 源"）在剩余行处不存在。
3. **支撑集与当量**：已转步骤支撑 ≈ {q21,q28,q4,q23,q51,q0,q27,q3,q20}（9 线，
   3 CCX：路由三元组 2 + 选择 1）；剩余行上下文支撑 {q21,q28,q41,q18,q0,q27,q2,q3,q6,q23}
   且**零 CSWAP**、当前代价已是下限 1 CCX/处。复制 S1 改写需引入路由三元组
   （`CCX q18 q28 q0` + `CCX q27 q28 q{2,3}` = +2 CCX），净 **+2 tof/处**，当量为负。
   S1-loop 每步 −1 的来源（2×CSWAP 消除）在剩余行处无可消之物。

判：**不可复制，关**。再省只能走"字仿真证三明治恒等/与邻组合并"（新实验，非同构复制）。

## 3. S2 合并税：0 分支恒等成立但无删除效力，1 分支字仿真证 CCX 承载相位（关，不记候选）

### 3.1 方法前置（本节基础，实测纠正原假设）

- `PUSH_CONDITION if bX` 为**标准条件栈 AND 语义**（确定性探针：BIT_STORE 置位 + 直接读 qubit，
  无 HMR 随机路径；6 组 PUSH/bare/if 组合 + 嵌套全部符合"内层操作执行 ⟺ 栈全 1 ∧ 自身位 1"）。
  原"无条件 CCX"指文本无 `if` 后缀；动态上 18332 `CCX q18 q21 q50` 仅当 b64003=1 执行。
- `HMR` = Hadamard + 测量 + 复位到 |0>（`X;HMR` 单样本多 trial 出随机；HMR 后 qubit 恒读 False）。
  早期未控随机性的 PUSH 探针结论作废，以本节确定性探针为准。
- q50 在 18332 前的末次写入是 16563 `HMR q50 b70001`（复位 |0>），其后至 18332
  约 1770 行无 q50 读写 → **q50_in = |0> 已确证**（`awk NR<18332` 全区 grep 尾段止于 16563）。

### 3.2 字仿真（ozer 18331–18349 原块 O vs 删 CCX 块 N，q50_in=|0>，seed 固定）

- **b64003=0 分支（全 constituent 位 0）**：4 组 (q18,q21)∈{0,1}² × seed{1,2,3} 共 12 次，
  O 与 N **逐次全同**（q18/q21/q50 位、b64002、shot-phase 全部相同，phase=0）。
  恒等成立——但原因是条件栈关闭、块内**根本无操作执行**，不是 CCX 冗余。
- **b64003=1 分支（b70000=1，其余 0；q19=1 使 CZ 扇显形）**：
  q18=q21=1、seed=8 时 **O≠N（O phase=1，N phase=0）**，其余输入/seed 组合多为 SAME
 （含 seed=7 的 HMR 抽样巧合）。存在性差异一处即证 CCX 非冗余：CCX 把 q18&q21 装入 q50，
  `CZ q50 q19/q25 if b70000` 扇才 imprint 相位；删 CCX 则 q50=|0>，扇区空转，
  后续 `HMR q50 b64002 + CZ q18 q21 if b64002` 无法补偿（X 基测量结果分布改变）。
- b64003=1 分支可达：b70000/b70001 是 16549/16563 处 X 基测量结果，逐 shot 随机，
  全量 200M shots 必大量命中（对照报告 §2 全量 PASS 即含两分支行为）。

判：**否，关，不记 −62 分候选**。0 分支恒等是"条件关闭"的平凡恒等，不产生删除许可；
1 分支字仿真给出删 CCX 改变可观测行为的实测反例（seed=8，q18=q21=q19=1）。
合并税 1 CCX 保留。

## 4. 61Q 峰值重扫：高水位 62（4 处），−1Q 不报价

- 分窗 distinct（仅参考，窗边 live-out 未播种故为下界）：S0-head 62 / S1-loop+ 61 /
