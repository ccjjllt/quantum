## 2. 方法：精确单 shot 相位模型（及其**适用边界**）

`9c708f7b` 是**经典可逆相位 oracle**：电路里没有任何 H，所有量子比特始终在计算
基态，追踪相位是 x 的确定函数（HMR 的随机结果只用于驱动精确抵消的修正）。
因此对**基线**电路 **1 shot/x 就复现官方误差函数**：全定义域 3,133,452 个 x
单进程约 45 s（官方 200M shots 约 5 min）。

证据（三条独立）：
1. 同一 x 在不同 salt / seed / 域下相位逐位相同（`worst=0.9993237694@161` 恒等，
   官方 200M 与本机模型 eps 一致到 2.434041481e-13）；
2. 41 个旋转逐个删除后，相位差只取 `{0, ±θ_k}` 两个值（§4.1）；
3. scratch 在全部 3,133,452 个 x 上回归 |0⟩（`dirty=0`）。

> **边界（本实验实测教训）**：单 seed 中性**不能**证明候选正确。删门会破坏
> “随机相位精确抵消”结构，使相位重新依赖 HMR 随机结果：单 seed 下完全中性的
> 删除，在别的 salt 下会以 0.5 turn 失败（§8）。**候选必须用多 salt × 64 shots/x
> 的官方验证器仲裁**；1 shot/x 只对基线成立。

## 3. 方向一：S1/S2 compute/uncompute 对普查（只读 + 随机采样域删除）

方法：对每个 Toffoli-like 门找**向后第一个同 kind、同控制集、同目标**的门，得
420 对；其中 **305 对条件栈完全相同**（其余 115 对条件不同，结构上不可能严格抵消）。

只读分类（`scripts/census_uncompute_pairs.py`）：

| 区间内目标的使用方式 | 对数 |
|---|---:|
| a) 目标完全未被触碰 | 15 |
| b) 目标只作对角门（CZ/Z/CCZ）控制 | **0** |
| c) 目标被另一个 Toffoli 改写 | 252 |
| d) 目标被测量 | 35 |
| e) 其它非对角使用 | 118 |

**类别 b = 0**：不存在 Hosen 判据（“目标在两门之间只作对角控制”）的形状。
机制上说得通：该电路已经用 859 个 HMR 实现了“测得的值 = 被控 AND；HMR 引入的
随机相位由同一 AND 的条件相位抵消”，即 Hosen 方案本身；剩下的 CCX 全是**算术
compute**，不是 uncompute。

15 个类别 a 对（目标未被触碰）在 x∈[1,300000] 全枚举域上删除后**全部失败**
（控制位在两点之间改变）：11 对最大 |Δ|=0.5 turn，4 对改变 58,435–137,872 个 x。

305 个条件相同的对：随机采样域（x ≤ 200,000 全枚举 + 300,000 个均匀随机 x，
共 485,101 点）删除两门后 **0 对相位不变且 scratch 干净**。最小足迹的一对
（8817→8862）也改变 8 个采样 x、|Δ| ≥ 0.437 turn。

结论：方向一 = **0 对可转，0 分**。

## 4. 方向二：旋转 T 侧（41 个一般旋转，295.09 C ≈ 19.6% 成本）

### 4.1 精确数字分解

`scripts/split_digits.py` 逐个删除 41 个 Z_POW 并在全定义域求相位差。41/41 个
旋转的差值只取 `{0, ±D_k}` 两个值，证明

```
phase(x) = Σ_k b_k(x)·θ_k + c(x),  b_k(x) ∈ {0,1}
```

41 列数字两两不同（无重复、无互补），GF(2) 秩 = **41**，没有可合并的两列。

### 4.2 逐旋转删除（全定义域精确判定）

| 旋转 | θ（半转） | 1 占比 | max |b·θ|/tol | 单删 |
|---|---:|---:|---:|---|
| #15（最小） | 2.886076e-11 | 0.490 | 0.4286 | ratio 1.3304 @x=3,063,147 |
| #16 | 5.872781e-11 | 0.459 | 0.8721 | ratio 1.7689 @x=3,063,147 |
| #17 | 1.158828e-10 | 0.490 | 1.7208 | ratio 2.6124 |
| #18–#40 | 2.3e-10 … 9.8e-4 | ≈0.5 | 3.45 … 1.3e5 | 全部 FAIL |
| #0–#14（粗阶梯） | 7.6e-6 … 0.125 | 0.0001–0.53 | 1.1e5 … 1.7e7 | 全部 FAIL |

**41 个旋转全部 load-bearing**。最小的 #15 单独删除已把最坏点推到 1.33×容差
（官方验证器多 salt 复核：x=644，2.360e-9 vs 容差 2.349e-9，3/3 salt FAIL）。
要 2,800 分需删 7 个 → 差 7 倍以上。

### 4.3 角重拟合（Chebyshev / minimax）

若误差 `e(x)` 落在 41 个数字张成的空间里，改角度即可降误差、放大 margin、抬高 eps。
实测（`scripts/refit_angles.py`，全 3,133,452 个 x）：

| 指标 | 值 |
|---|---:|
| 基线 max |e|/tol | 0.99932 |
| 基线 rms |e|/tol | 0.26019 |
| 最小二乘后 max |r|/tol | **1.11341**（更差） |
| 最小二乘后 rms |r|/tol | 0.25304（仅 −2.7%） |
| IRLS minimax | **1.63**（无法改善） |

即误差与数字空间**近乎正交**，改角度换不到任何 margin，eps 固定 2.434e-13。

结论：方向二 = **0 分**。T 侧 295.09 C 无法通过删/合并/重拟合降低。

## 5. 方向三：61Q 值级重算

只读活性剖面（`scripts/structure.py`）：

- **峰值 value-liveness = 62**（op 1618）：在 36,965 个 op 内 62 个比特几乎全程
  同时有效；每个比特 usage span ≥ 23,830 op（q58），多数 36,900+。
- 控制位读取次数：最小 **52**（q1），中位 ≈ 650，最大 1,308（q27）/1,272（q28）。

预算（基线 C=1,508.9567）：

| Q | 同 C 时 score | 打平需 ΔC | +2,800 需 ΔC |
|---:|---:|---:|---:|
| 61 | 92,046.36（毛赚 1,509） | **+24.74** | −21.17 |
| 63 | 95,064.27（毛亏 1,509） | −23.95 | −68.40 |
| 64 | 96,573.23（毛亏 3,018） | −47.16 | −90.91 |

61Q 的净赚 >1,000 分只允许 **+8.3 C**；要 2,800 分反而要 **−21.2 C**。
释放任一比特都要重算一个被读 ≥52 次、跨 ≈24k op 的值：≥52 次重算 × 每次 ≥1 CCX
≈ **≥52 C**，已是打平预算 24.7 C 的 2 倍。x 寄存器 22 位必须互异，40 位 scratch
全程占用。结论：no-go（量级差 ≥2×）。

## 6. 方向四：Q+1 / Q+2 加 ancilla 换 C（预算表）

### 6.1 成本池（只读，按段精确；各段 CCX 之和 = 1,191）

| 段 | 区间 | CCX | CCZ | CSWAP | HMR | 说明 |
|---|---|---:|---:|---:|---:|---|
| 前缀 + 44-CSWAP normaliser | `[0:8546)` | 193 | 0 | 44 | 32 | WCao24 normaliser |
| 阶梯一 16 步 | `[8546:8928)` | 51 | 0 | 0 | 16 | 18 Z_POW |
| 中部（S1 测量/重算域） | `[8928:16389)` | 372 | 7 | 0 | 306 | 测量驱动 uncompute |
| 阶梯二 26 步 | `[16389:16781)` | 76 | 0 | 0 | 28 | 26 Z_POW |
| 尾部（48-CSWAP 逆 normaliser） | `[16781:36965)` | 499 | 85 | 48 | 477 | 最终测量/相位/复原 |

阶梯单步：**3–4 个 CCX/比特**（最细几位 1–2 个），即“每比特 1 CCX 的条件加法”
形态，已是该 digit-recurrence 形状的常规下界。

### 6.2 为什么 +1/+2 ancilla 换不到 C

1. 计分只数**门数**，不数深度：进位保存/并行前缀的深度收益 = **0 分**。
2. 本模型 CCX 恒计 1（与 ancilla 干净与否无关）：Gidney 式 clean-ancilla AND **不省分**。
3. ancilla 唯一省分方式是**消除重算/uncompute**；而 859 个 HMR 已把 uncompute 换成
   “测 + 对角条件修复”，1,131/1,375 门无条件（是 compute），244 个条件门平均执行率
   34%——没有剩下 ≥24 C 的 uncompute 可省。
4. 任何时刻都没有空闲比特（§5：peak liveness 62），插 ancilla 必须重排，而重排
   就要动算术与相位常数（→ 0.9993 裕度）。

### 6.3 阈值

| Q | 打平 ΔC | +2,800 ΔC |
|---:|---:|---:|
| 63 | −23.95 | −68.40 |
| 64 | −47.16 | −90.91 |

+1 ancilla 至少要换掉 **24 个 CCX** 才不亏、**69 个**才达 3%。本电路不存在
≥24 CCX 的局部 ancilla 变换；−69 CCX 只能来自**换算法**（逐位恢复余数除法换成
冗余表示/进位保存的 digit recurrence），那是全段重写，且会改数字 b_k(x)、摧毁
0.9993 裕度（§4）。结论：no-go（预算表不成立，不立项）。

## 7. 方向三 vs 四：只做成本更低的那个

- 61Q：毛 +1,509，净 >1,000 只允许 +8.3 C，实现需 ≥52 C → 净亏 ≈1,500；
- Q+1：毛 −1,509，需 −24 C 打平、−69 C 达标，局部无空间。

两者都 no-go；**61Q 的下限证据更硬**（≥52 C vs 预算 8.3 C），且方向四的
“换算法”与 61Q 也不兼容（同一段算术）。

## 8. 附：单门删除 / 死门 / 均值条件化普查

对 1,375 个 Toffoli-like 门逐个删除，先用“x ≤ 50,000 全枚举 + 100,000 均匀随机 x”
筛（`scripts/screen_dead.py`），得 **22 个单 seed 中性候选**，全定义域复核 22/22
在 seed=12345 下相位逐位不变（3,133,452 个 x）。但**官方验证器多 salt 复核**：

| 组 | 结果 |
|---|---|
| 22 门合集（`cand_dead22.kmb`） | 官方 200M FAIL：`x was not restored`（含 x 比特上的 CSWAP 36830） |
| 8 门子集（`cand_dead8b.kmx`） | x≤200,000 × 64 shots/x，salt a1/a2/a3 → 3/3 FAIL（x=223/753/2289，0.5 turn） |
| 逐门 22 × salt dd（x≤2,000） | 8 PASS / 14 FAIL |
| 8 门再筛（x≤3,000 × 3 salt） | 只剩 17764 / 18327 / 18332 全 PASS |
| 3 门（x≤200,000 × 64 shots × 3 salt，共 115M shots） | **3/3 salt 全 PASS** → 真可删 |

即：**静态池里恰好有 3 个门可删（17764、18327、18332）**，其余 22 个单 seed 候选
都是“随机相位抵消碰巧对齐”的假阳性（§2 边界）。

**但这 3 门的收益是 0.000 分**：删除后全定义域均值仍是 **1,213.8662**（逐位不变），
因为它们的条件栈深达 18–20 层，执行概率为 0。
`cand_dead3.kmx`：静态 1,372、均值 1,213.8662、worst 0.99932377、score 93,555.3343
（= 基线，Δ = 0.000）。

由此得到一个干净的结论：**静态/均值之差 1,375 − 1,213.87 = 161.13 恰好就是
“永不执行的分支门”**（作者已用条件化把它们从均值里扣掉），再剪它们对分数没有意义。

副产品：单 seed “门足迹” `q_g`（删除该门后相位改变的 x 比例）之和为 **196.7**
（1,131 个无条件门贡献 187.0，均值 0.165；244 个条件门贡献 9.7）。若每个门都能精确
条件化，均值理论下界 ≈197（−63,000 分量级）；但该电路只有 574 个经典比特、全部来自
X 基测量/深分支指示，没有可用“精确谓词”，且条件化要求谓词**恰好等于**该门的
matters 集合（多执行一次就错），所以这条上限不可达。该 `q_g` 为单 seed 量，仅作
指示性上界记录，不构成立项依据。
