## 2. 全域精确相位模型（新工具）

电路无 H 门：所有可达态都是计算基态（HMR/R 引入随机相位与经典 bit，但相位对 seed 不敏感，
已用 seed 101/202 在 5164 个 x 上验证系数与相位逐位相同）。

- 方法 A（系数提取）：对每个 rotation 类的 `Z_POW` 把角度 += 2^-10 turns 重跑，相位差 ∈ {0, 2^53}（整数精确），
  得到 41×5164 系数矩阵；两种 seed 完全一致（0 差异）。
- 方法 B（全域经典仿真）：把全部 3,133,452 个 x 打包成 62 条大整数线（3.9e5 bit），
  跟踪量子线、经典 bit（BIT_STORE/INVERT/NEG）与 PUSH 帧，一次 0.4 s；
  与有限差分系数在 5164 点上 **0 失配**；自检 `x 全部恢复`、`scratch 全部清零` 均通过。
- 结论：相位(x) = Σ_k c_k(x)·angle_k/2（rotation 的 c_k 与 coin 无关），可对全部 x 精确评估。

## 3. 旋转角 LP：现有角度已是最大余量最优

  最大误差比 0.99932377 @ x=161（与官方 verifier 完全一致）。

  最终覆盖 55k 个最紧点并在全 3.13M x 上复核）。
- 结果：**LP 最优 m = 5.8598e7 = 基线余量（1.00×）**。即现有 41 个角度在最大余量意义下已最优，
  角度重调无任何收益。

## 8. 成本模型备忘

`score = num_qubits × (toffoli_count + t_count/4)`；
`t_count = t_base + n_rot × (0.56·log2(1/eps) + 5.3)`，`eps = π·min_margin/2^64/n_rot`；
Toffoli 只统计**实际执行**的 CCX/CCZ/CSWAP（守卫为假的帧内门不计成本）。

## 12. 旋转合并的精确判据（结论：不可合并）

- 41 个 rotation 的**全域系数掩码两两不同**（`full_masks.npz`，41/41 distinct）：
  ```
  rotations: 41 distinct coefficient masks: 41 duplicate groups: 0
  ```
- 因此任何「两个旋转合并为一个、角度相加、删掉一个 Z_POW」的变换都不成立
  （相位函数不同，合并会改变相位）。
- 早前按「CCX 乘积」找出的 32 个重复也不能用：Z_POW 作用在 CSWAP 之后的 q28 上，
  旋转系数 ≠ CCX 乘积；梯步 [15596] 的 CSWAP 目标 q0/q2 紧接着被 `Z_POW q0 0.5` / `Z_POW q2 0.5` 使用，
  且其 HMR 位 b400 被 11 处 CZ/BIT_INVERT 引用（b392 更是 20+ 处），
  整步删除会破坏大范围修正网络。

## 14. 精确 ANF 复核（反计算恢复）

- 修正上一版缺陷（CCX 目标被反计算后应恢复线性）：用精确单项式集合跟踪，
  在 op 15999 处已有 61 条线的 ANF 超过 2 万项上限 → 该区域函数不是可因式分解的低次多项式，
  而是深度算术电路；无法用「共享部分积」在局部重写。
- 全部 93 个 `Z_POW` 的全域系数掩码：84 个互不相同，唯一重复组是 10 个
  `mask=0` 的 b418 守卫门（b418 ≡ 0 死区，本就不执行、不计成本）。
  → 任何「同系数合并角度」的变换都不可用。

## 15. 量化的结构下界（为什么局部原型不可行）

- 相位函数需区分 3,133,452 个 x；R 个旋转的和最多产生 2^R 个不同相位值 → **R ≥ 22**。
  现电路 R=41，且全域 LP + 掩码分析证明在这 41 个模式上已最大余量最优。
- Toffoli：1280.66 / 22 bit ≈ 58 门/输入位；即使换成可逆 Newton 迭代（Karatsuba 乘法），
  量级仍是 500–800 门，属于**全新算法**（需重新推导近似多项式、因式分解、修正网络），
  不是把某一段 AND 换成共享部分积的局部补丁。
- 结论：局部原型无法在保持相位正确的前提下降低 toffoli_count；要突破必须换算法。

## 19. Newton/Karatsuba 重设计的预算证伪（2026-11-05 追加）

基线：`C = score/Q = 97859.546/62 = 1578.380`，其中 toffoli 1280.664、旋转 1179.4 T（294.84 C，
7.19 C/rot，eps=2.434e-13）。任何重设计必须满足 `toffoli + t/4 < 1578.380`。

| R（旋转数） | 旋转成本 C | Toffoli 预算 |
|---|---|---|
| 41 | 294.8 | 1283.5 |
| 32 | 230.1 | 1348.3 |
| 24 | 172.6 | 1405.8 |
| 12 | 86.3 | 1492.1 |

n=24 乘法器：schoolbook 576 ANDs；Karatsuba 3 层（27 个 3×3 子乘）243 ANDs。
Newton 迭代每轮需 3 次乘法（x²、a·x²、x·(·)），3–4 轮收敛：

| 乘法器 | 轮数 | AND 总数（仅计算，不含反计算/LUT/修正） | 对 R=24 预算 1405.8 |
|---|---|---|---|
| schoolbook | 3 | 5284 | 超 3.8× |
| schoolbook | 4 | 7012 | 超 5.0× |
| Karatsuba | 3 | 2287 | 超 1.6× |
| Karatsuba | 4 | 3016 | 超 2.1× |

即使按旋转成本下限（5.3 T/rot，不计合成惩罚），R=24 时预算也只有 1546.6，仍 < 2287。
而上表还是**乐观估计**：未计入可逆反计算的翻倍、LUT 初始化、修正网络和乘法器辅助比特的额外旋转。
结论：Newton/Karatsuba 家族的替代算术在门数量级上就不可能击败 1280.66，
「换全新算术」这条路也被量化预算关闭，不是多天投入能解决的。

## 20. 对角门等效掩码分组原型 + 分支依赖根因（2026-11-05 追加）

- 新判据：对角门（CCZ/CZ/Z）不改变量子态；两个等效触发掩码全分支相同的对角门相位和恒为整数圈，
  可整体删除。用全域经典仿真（零分支）对 15107 个对角门按（种类，量子乘积掩码，守卫，帧）归组：
  14669 个互不相同，337 组重复，其中 39 组通过「帧/守卫位无重写」检查（SAFE）。
- 关键事实：39 组 SAFE **全是免费门（18 CZ + 21 Z），零 CCZ**；全部 CCZ 乘积两两不同。
  即该判据下没有任何计费门可删。
- 按指令仍接线验证：删除非零乘积守卫 CZ 对 `[48265, 48268]`
 （`CZ q22 q20 if b7917` + `CZ q30 q20 if b7917`，零分支掩码相同，pop=43692）→
  `proto_diagpair.kmb` 完整验证 **FAIL**：`x=5: phase error 5.000e-01 turns`。
- 根因（决定性实验证据）：同电路三 salt 对比，硬币位 salt 相关而相位 salt 无关——
  ```
  seed 101: b7917@x5.. = [F,T,T,F,T,F,F]  phase@x5 = 8249634640135948259
  seed 303: b7917@x5.. = [F,T,F,F,T,F,F]  phase@x5 = 8249634640135948259
  seed 404: b7917@x5.. = [T,F,T,T,T,F,F]  phase@x5 = 8249634640135948259
  ```
  HMR 含 Hadamard，真随机测量；后续条件 CZ 修正使总相位确定。
  因此零分支仿真的触发掩码**不等于**验证器分支的触发掩码（对该 CZ 对：零分支 pop=0，
  随机分支 pop=4/10），「SAFE」分组依据不成立。梯形区有 126 处守卫量子写，
  装载区更多——凡涉及守卫写线的掩码结论都只对零分支成立。
- 影响评估（哪些既有结论仍然成立）：
  - 旋转层证书成立：41 系数掩码经 seed 101/202 在 5164 点上逐位相同（0 差异），
    LP 最优 1.00× 与 verifier 的 worst@x161 逐位一致——旋转线的值与分支无关是实测事实。
  - 所有删除类 FAIL 结论成立：仲裁者始终是完整验证器，不依赖分支假设。
  - Q 下界 62（HMR 切分区间峰值）、自逆对 0/1115（酉区间精确比较）是结构性的，不受影响。
  - 作废：零分支仿真给出的「常量控制 116 个」「共享部分积 16 个」「SAFE 对角组 39 个」
    等候选清单——它们只是零分支假设，正确做法（已做）是一律用完整验证器仲裁，
    仲裁结果全 FAIL（计费门部分）。

## 21. T 成本侧单删全测（2026-11-05 追加）
