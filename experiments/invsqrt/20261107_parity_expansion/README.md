## 0. 一句话机制

目标在 `[1, 3133452]` 上有 1,770 倍的动态范围，而容差是**相对**的
`2^-24/sqrt(x)`，所以每个十倍程都要 ~24 bit 的相对精度。
在 Walsh（dyadic）基里这类"尺度不变"函数的谱是幂律，
每个 rank 十倍程携带相近能量；截断到 K 项时相对误差一直是 O(1)，
直到 K 接近 2^22。最直接的证据：**最小的那个系数本身
`7.0937e-9 = 210.7 × tol_min`**，所以连"只丢一项"的 N-1 项展开都失败 211 倍。

## 1. 构造、相位约定与计费口径

一个 K 项奇偶展开

```
p(x) = Σ_{S∈F} a_S χ_S(x) turns ,   |F| = K
```

用 **一个 ancilla** 实现（`Q = 22 + 1 = 23`）：

```
for S in F:
    for i in bits(S): CX x_i -> a      # 奇偶扇入，Clifford，免费
    Z_POW a  h_S                      # 1 个旋转
    for i in reversed(bits(S)): CX x_i -> a   # 反算，免费
```

**约定的三个坑（都已在真实 KMB 上核对）：**

1. `CircuitBuilder.z_pow` 的指数是 **half-turns**：`Z_POW q h` 在 q=1 时给 `h/2` turns。
   官方 `half_turns_to_units` 也是同一约定。
2. 作用在奇偶 ancilla 上的 `Z_POW h` 给 `h/2 · [parity odd]`
   `= h/4 − (h/4)χ_S(x)`。所以要实现 `a_S χ_S`，必须取 **`h_S = −4 a_S`**，
   并补一个**常数旋转** `+Σ_S a_S`（`X; Z_POW; X`，X 免费，不占额外量子位）。
   即总旋转数是 **K+1**。
3. 常数项不能省：截断展开的 `Σ_S a_S = P_F(0) ≠ 0`，
   而 verifier 比较的是绝对相位（模 1），不是"差一个全局相位"。

计费（官方 `verify_submission_invsqrt.py`）：
`eps = π·min_margin/n_rot`，`T = 0.56 log2(1/eps) + 5.3`，`C = T/4`。
本构造 **Toffoli-like = 0，T = 0**，全部成本是 K+1 个一般旋转；
CX 是 0 成本，但门数是 `2·Σ_S|S|`（K=N 时 = 92,274,688 条 CX）。

## 3. 方法 A：直接最小二乘 / Chebyshev（未 wrap）

`fit.py`：对 K×K Gram 矩阵精确求解。合法域是**前缀区间** `[1,M]`，所以

```
G[S,S'] = Σ_{x=1..M} χ_S(x)χ_S'(x) = What_{1_legal}[S xor S']
b[S]    = Σ_{x=1..M} χ_S(x) T(x)   = What_{T·1_legal}[S]
```

两次 WHT 就得到任意支撑的精确正规方程（无采样）。三种延拓的排序
加合法域投影排序 `|b|/N` 共 4 种支撑，K = 41/96/200/500/1000/2000，
截断（B 的线性版）与重拟合（A）都测：

|---:|---:|---:|---:|---:|---:|
| 41 | 1.657e+07 | 1.657e+07 | 3.07e+06 | 31/41 | 8.5e-04 |
| 96 | 1.646e+07 | 1.646e+07 | 1.48e+06 | 72/96 | 8.5e-04 |
| 200 | 1.632e+07 | 1.632e+07 | 1.32e+06 | 150/200 | 8.5e-04 |
| 500 | 1.614e+07 | 1.605e+07 | 1.13e+06 | 376/500 | 8.5e-04 |

## 8. 结构性发现：合法域是前缀区间 → Gram 精确退化

`M = 3,133,452 < 3·2^20 = 3,145,728`。因此对**所有**合法 x（也含 x=0）：

```
(1 − χ_{2^21}(x)) (1 − χ_{2^20}(x)) = 0
```

因为 bit21=0（x<2^21）或 bit21=1 且 bit20=0（2^21 ≤ x < 3·2^20）都让它为 0。
于是任何包含 `{∅, 2^20, 2^21, 2^21+2^20}` 的支撑在合法域上**线性相关**。
这解释了 `fit.py` 里 Gram 矩阵的有效秩（41→31、2000→1496）和
`cond ~ 1e16`：不是浮点毛病，是精确的代数退化。
更一般地：任何乘积 `Π_{i∈T}(1−χ_{2^i})`（它是某个 dyadic 子立方上的指示函数）
只要该子立方与合法域不交，它的展开就给出 `2^{|T|}` 个字符之间的一个精确线性关系。
这也是为什么"只看高位"的子空间（`top m bits`）在合法域上维数虚高。
对后续任何在本合法域上做最小二乘/基底选择的实验，这是一个可直接复用的判据。

## 9. 为什么谱是幂律（机制，不是定理）

1. 目标在 `[1,M]` 上的值从 1 降到 5.65e-4，而容差同比缩小，
   所以要求**每个尺度上相同的相对精度** `2^-24 ≈ 6e-8`。
   这是一个"尺度不变"函数，Walsh 谱没有快衰减的机制。
2. 实测 `|c_r| ∝ r^-0.58`，能量按 rank 的每十倍程近似均匀分布，
   截断 K 项就丢掉与 K 无关的那部分相对误差 → 一直 O(1)。
3. ℓ1 质量 `Σ|c| ≈ 1.06`，而 x=1 的相位必须是 0（模 1）；
   要 6e-8 精度就得把 1.06 的量抵消到 1e-8，即 7 位以上抵消。
   最小单项已经是 `210.7 × tol_min`。
4. 自由度估计：3.13e6 个点 × 24 bit 相对精度 ≈ 7.5e7 bit，
   而每项系数 ~53 bit → K ~ 1.4e6 量级；实测的通过点就在 N 附近。
   这是启发式量级估计，不是下界证明。

**范围说明（重要）**：本文**没有**证明"任意 K≤2000 的支撑都不可能通过"。
实测的是：四种排序（三种延拓 + 合法域投影）、LS 重拟合、Chebyshev LP、
复幅度选择、以及低次多项式 / 高位前缀两类结构化子空间，
全部落在 `1.5e7 ~ 2.5e8 × tol`；唯一测得通过的支撑是完整基。
结合"最小系数已是 211×tol"，任何仍然稀疏的支撑需要凭空获得 7 个数量级，
目前没有任何机制支持。
