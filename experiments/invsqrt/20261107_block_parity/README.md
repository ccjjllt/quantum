三个独立的否定证据，任何一个都足以停止这条线：

1. **K 阶梯在预算内是"未启动"。** 预算 694.840824C 按官方公式只能买 **K ≤ 88** 个一般旋转
   （即使假设理想余量 = tol_min）。而 K < B 时必然有整块未被建模，该块误差等于整个函数值，
   实测最坏比**恰好等于 2^24 = 16,777,216**。b≤10 的 B = 3,061..48,961 > 2000，
   所以题目要求的 K=41/96/200/500/1000/2000 全部落在 2^24 这条"零近似"线上。
2. **方法无关的下界仍差 147 倍。** 用 Bessel 不等式给出任意 k 项近似（不限 LS/Chebyshev）
   的 L2 下界，得 b=12 时 `K ≥ 11,561`；把该 K 按最便宜的电路计价仍是
   **C ≥ 102,360C = 147.3 倍** 预算。即"换拟合方法"最多省 57%，救不回来。
3. **块/小波本身被迫全分辨率。** 容差是相对量 `2^-24`，而输入只有 22 位、`x ≤ 2^21.6`，
   所以任何宽度 w 的常数块在相对意义上都要求 `w ≤ 2^-24·x ≤ 0.187 < 1`：
   常数块部分必须逐点（3.13e6 项）。实测 Haar 细节 **765/765（b=12）、48,960/48,960（b=6）
   全部高于容差**，一个都不能丢；纯分段常数最坏比 1.18e7..1.61e7（即 70%..96% 的 2^24）。

**真实 KMB/PASS 只存在于缩减实例**：`max_x=16`（5 块、b=2、K=20）的
`artifacts/20261107_block_parity/block_parity_exact_x16.kmb` 通过官方验证器
（`PASS`，`toffoli_equivalent=189.9613`，与 `paid + (15·c_rot+3)/4` 逐位一致，
最坏误差/容差 2.4e-9）。它验证 gadget、相位约定和计费公式，**不是** invsqrt 成绩。

## 1. 构造、相位约定与计费

把 22 位输入按 `x = h·2^b + L` 拆分（h 是高 `m = 22-b` 位，L 是低 b 位），模型为

```
p(x) = Σ_h I_h(h(x)) · Σ_{S⊆[b]} c_{h,S} χ_S(L),   χ_S(L) = (-1)^popcount(S&L)     (1)
```

`I_h` 是高位比特的 AND（0 控制用免费 X 翻转），`χ_S` 是低位奇偶（CX 扇入免费）。
每个非零 `c_{h,S}` 需要一个旋转；因为旋转必须同时以"块指示"和"局部奇偶"为条件，
用 `ccx(a,p,t); z_pow(t,·); del_and(a,p,t)` 实现（`z_pow` 没有控制参数）。

**相位约定（用真实电路核对，不是推导假设）：**
1. `z_pow(q,h)` 在 q=1 时给 `h/2` turns（`h` 是 half-turns）。
2. `t = a·p` 上 `z_pow(t,-4c)` 在活动块内给 `-c + c·χ_S`；那个 `-c` 是**块内常数**。
3. 于是每块只需**一个**常数旋转（作用在 `a` 上，单控，0 个 CCX），
   角度取 `c_{h,∅} + Σ_{S≠∅} c_{h,S}`，正好把 (2) 的 `-c` 全部吸收。
   **n_rot = K（不额外加全局常数旋转）**；`S=∅` 项不需要 CCX。

计费（官方 `verify_submission_invsqrt.py`）：`eps = π·min_margin/n_rot`，
`T = 0.56 log2(1/eps)+5.3`，`C = paid + T/4`，本族无 T 门。

## 2. 全域数值拟合（block-diagonal LS，water-fill 分配）

块互不相交且 `χ` 在整块上正交，所以合法域最小二乘是**块对角**的、可精确求解：
`G_h = WHT(mask_h)`、`b_h = WHT(mask_h·g)`；只有块 0（x=0 非法）和最后一块
（x>M 截断）是部分块。目标/容差直接取官方 `target_units`/`tol_units`
（`x=1` 目标 1 turn ≡ 0）。因为块独立，"K 项"用 water-fill 分配：给定阈值 t，
每块取满足"块内实测 `max|e|/tol ≤ t`"的最少项数，`K(t)=Σ_h k_h(t)`。
**所有报告的最坏比都是实际分配下的全域实测值，不是上界。**

- **第一块（x∈[1,4095]）需要整个 4096 项局部基**，单独占 K 的 15%。它的局部函数在

## 4. 共享支撑（同一局部奇偶基 + 块依赖角度）：不存在

题目要求的"shared coefficient structure"实测无效。把局部子集按**跨块总能量**
`Σ_h c_{h,S}²` 排序、所有块共用同一 `K_L` 个 `S`（角度仍逐块不同）：

| K_L | K = 766·K_L | 最坏比 (b=12) |
|---:|---:|---:|
| 1 | 766 | 1.61e7 |
| 2 | 1,532 | 1.59e7 |
| 4 | 3,064 | 1.55e7 |
| 8 | 6,128 | 1.49e7 |
| 16 | 12,256 | 1.41e7 |
| 32 | 24,512 | 1.29e7 |
| 48 | 36,768 | 1.14e7 |
| 64 | 49,024 | 1.18e7 |

即使给到 64 项/块（K=49,024，比 water-fill 的 26,859 多 83%），最坏比仍 ≥ 1.1e7；
只有 `K_L = 2^b`（整局部基，b=12 时 K=3,133,504 = 全基）才精确
（b=6 的 `K_L=64` 实测 1.5e-8 正是这种情况，因为 b=6 的整局部基就是 64 项）。
原因：局部比特 j 的重要性随尺度变化（bit j 只有在 `2^j ≳ x·2^-24` 时才有用），
**块无关的支撑在每个尺度上都错**。所以"共享支撑"是被逐块支撑严格支配的：
它省不下旋转（旋转数相同），却把精度彻底毁掉。

## 5. Haar / 小波变体：一个细节都不能丢

把块常数 `A_h = c_{h,∅}` 重写成"粗值 + 相邻块差分"（telescoping / 前缀指示）后，
残差在合法域上完全相同（块正交性），变的只是**差分的稀疏性**与成本。
差分 `d_h = |A_h - A_{h+1}|` 的判据是 `d_h/2 ≤ min(tol)`：

| b | 相邻对 | 高于容差的差分 | 占比 | 相对差分 min..max | 纯分段常数最坏比 |
|---:|---:|---:|---:|---:|---:|
| 6 | 48,960 | 48,960 | **100%** | 1.02e-5 .. 0.667 | 1.18e7 |
| 8 | 12,240 | 12,240 | **100%** | 4.09e-5 .. 0.800 | 1.41e7 |
| 10 | 3,060 | 3,060 | **100%** | 1.63e-4 .. 0.857 | 1.55e7 |
| 12 | 765 | 765 | **100%** | 6.54e-4 .. 0.889 | 1.61e7 |

即：**没有任何一个块间差分可以省略**，前缀/望远镜表示需要全部 B 个阈值项
（每项还要一个比较器指示，比 AND 指示更贵）。纯分段常数在 b=12 时反而比 b=6 更差
（1.61e7 vs 1.18e7），与"块越大越糟"的机制一致。

**只做成本计数不会发现这种错误**，这也是本轮坚持"真实 KMB + 官方验证器"的原因。

## 10. 机制：为什么这一族必然亏

1. **相对容差 vs 有限输入分辨率。** `tol/|T| = 2^-24`，而 x 只有 22 位、跨度 `2^21.6`。
   宽度 w 的常数块在相对意义下误差 ≥ `w/(4x)`，要求 `w ≤ 2^-24·x ≤ 0.187 < 1`。
   所以块常数部分必须逐点（3.13e6 项），Haar 细节一个都不能丢（§5 实测 100%）。
2. **局部奇偶基比局部多项式贵 ~5 倍。** 平滑块用 Chebyshev 二次只需 3 项，
   用 Walsh 需要 13..17 项（b=12）——因为 Walsh 要按"位权"分级，`2^q` 项才换来 q 级分辨率，
   而多项式是 q+1 项。这正是 `20261106_piecewise_cost` 里"分段多项式算术太贵"的另一面：
   换成免算术的奇偶基，项数又太多。
3. **旋转数 = 项数，且每项都要双控。** `n_rot = K`，每项 1 CCX；预算 694.84C 只买 88 个
   旋转（`c_rot ≈ 7.9..10`），而 K 的下界是 11,561。任何"把 CCX 变便宜"的优化
   都只能动那 9.2%。
4. **块索引不是免费的。** 即使 selector 做到 1 CCX/块（实测 0.998），B 本身在
   b≤12 时是 766..48,961，K < B 时最坏比恰为 2^24。
