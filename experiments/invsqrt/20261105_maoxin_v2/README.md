## 公开方法及贡献归属

Maoxin 的新发现主要在化学权重迁移，inverse 直接沿用公开 `0104…` 家族。
研究读取了以下源码，保存于 `artifacts/20261105_maoxin_v2/invsqrt/sources/`，
只用 `ast.literal_eval` 取 gate list 和报告，没有导入或执行 notebook Python。

- [Kirill Four Loaders V10 / 365663103](https://www.kaggle.com/code/kirilltym/quantum-circuits-four-loaders-eight-toffolis?scriptVersionId=365663103)：`kirill_four_v10.ipynb`，提供 Syed、Qiu 的完整窗口与零 coin 方法。
- [Kirill Quantum Compilation 19 V7 / 365875650](https://www.kaggle.com/code/kirilltym/quantum-compilation-19?scriptVersionId=365875650)：`kirill_q19_v7.ipynb`，明确 Maoxin V2 组合及 inverse 完整回执复用范围。
- [Maoxin V2 / 365853243](https://www.kaggle.com/code/maoxin123/lb-24-786-pi-gauge-loaders-transferred-weights?scriptVersionId=365853243)：根目录 `artifacts/20261105_maoxin_v2/source/` 保存本次版本。

主要 inverse 改进如下：

1. **SomeJoint 跨 HMR 乘积复用、归一化和 phase-split carry。** 两个跨 HMR 窗口省 2C；旧本地候选已经吸收，不能再算成本轮独立收益。
2. **Syed 五乘积到四乘积的 decode 重综合。** 328 条操作换为 471 条，CCX 从 5 到 4。这依赖可达输入结构，不是任意 dirty 输入的通用恒等式。
3. **Leo Tang / Qiuqiu 的共享目标二次合并。** Qiu 完整窗口从 82 条/3 CCX 变为 95 条/1 CCX；允许更多免费 CX，以减少计费门。组合 Syed 后，当前 op18602 起 484 条窗口只有 2 个 CCX，已在 Maoxin 中。
4. **Malachi Moody / Syed 的 free-coin 思路，经 Kirill 集成。** 符号证明 HMR 前 q21 为零，保留 HMR，但立即把内部结果 b417、b418 固定为零。作者 V7→V8 报告从 98,123.17 降至 98,045.64，约 77.5 成本；含 T 分支成本变化，不能只看 CCX 静态数量。

本轮自写 ANF 审计重新证明 Qiu 窗口对全部 62 根任意边界线的输出多项式完全相等，
并拒绝删除唯一 CCX 的负控。相反，Syed 5→4 的任意边界比较**不等价**：只有 q50
存在 569 项差多项式；`q15=1，其余边界线=0` 是边界反例。这不是比赛输入反例，
不否定公开电路有效性，而是说明继续做此类压缩必须带上真实前缀可达条件。
该发现也修正了本轮首次“两个窗口都应是通用恒等式”的过强假设。

## 已落实：无回退选择器仍可迁移

新电路 `[27911,28919)` 与旧 Kirill V5 `[27745,28753)` 的 1,008 条指令逐项相同；
两段经典系数准备也相同。新算术前缀不同，因此本轮重新验证前缀，未直接复用旧结论。

生成器 `selector_migration.py` 复用本仓库既有发现/证明助手，不调用旧脚本的 hash/main 入口：

- 从新前缀实际获得 x=1…63 的 62 线状态，生成 trial 1/2/40 三分支。
- 新前缀 65 项 SSA 断言全部 UNSAT：q21=1 蕴含 x≤63；q28/q40 恒零；每个小输入的全线状态在任意前缀测量结果下固定。
- 原两个选择器的任意输入值/相位/计费语义各通过一次 UNSAT 检查。
- 每个成功分支的 ANF 证明所有输出恢复、HMR 相位消去，且其相位单项式均含 q21；逐源残差只出现在该分支失败条件下。
- 三个失败奇偶式秩为 2 且 XOR 为零，三者不能同时失败，故不需要回退分支。删除一条 CZ 修正的负控被拒绝。
- 全条件栈精确期望计费（测量结果平均）：旧窗口 `524287/262144 C`，新窗口 `1 C`；静态付费门 38→3 不等于每 shot 省 35C。
- 新增经典位 b42006…b42014；窗口外指令、全部 Z_POW 顺序不变。
- 原生 kickmix seeds 101/202/303，每 seed 21,760 输入：恢复失败、scratch 错误、相位差与容差失败均为 0。观察到 Toffoli 节省 0.9880 / 1.0446 / 0.9955；均为样本统计。
- T 样本均值出现小差别，因为新增 HMR 改变后续 PRNG 消耗，同 seed 不等于全程配对测量历史。没有据此额外宣称 T 收益。

产物和证据：`selector_migration.json`、`selector_migration.log`、`maoxin_v2_nofallback.kmb`
均在 `artifacts/20261105_maoxin_v2/invsqrt/`。正式候选评分仍需要另外手动运行完整官方验证。

## 下一步优先级与停止条件

| 优先级 | 方向 | 当前证据与最小下一步 |
|---|---|---|
| 1 | 将无回退候选做完整官方验证 | 已生成且局部证明通过；预期仅约 1C，单项约 0.0633%、总 GM 约 0.0211%。若需要可用候选，再手动做全量；不要把预测当成本次成绩。 |
| 2 | HMR 两侧联合重综合 | 新基线普查 37 个合格跨度，可取 32 个互不重叠窗，28 无条件/4 带守卫；24 个纯 CCX、8 个含 CSWAP。先挑有可解释乘积关系的少数窗，保留测量输入函数、最终相位和输出。该集合只是几何研究入口，不承诺收益，也不保证排除了全部已优化形态。 |
| 3 | 带真实前缀约束的共享目标二次压缩 | Qiu 的成功窗口有 26 根边界线，旧 ≤10 线筛查会漏掉此类结构。先提取同目标多乘积的完整 X/CX/CCX 段，做可达域上的二次秩分析；再构造具体重综合并证明。Syed 的 dirty 反例说明不能忽略域约束。当前没有第二个新候选。 |
| 4 | 较大尺度精度/表示重设计 | 当前数值余量仅约容差的 0.0676%；41 个一般旋转计费约 294.84C，占总等效成本约 18.67%。只有建立新的误差分配与完整可逆恢复方案后才考虑动精度，直接删旋转或缩位宽不作为近期小补丁。 |

若 32 个窗口都能各省 1C，所列模板集合的极乐观静态上界为 32C/1,984 成本；
守卫概率仅以 ≤1 计。它不是预期收益、不是全电路上界，也不是量子电路下界。
独立段模型的旧负结果不能否定跨 HMR 联合改写，但也不能据“联合”二字假定有收益。

**不继续盲扫 free coin：**本轮保守符号扫描在当前真实电路证明 9 个无条件 HMR 的输入为零。
其中 b417/b418 已被固定；另外 7 个按“该写入版本直到下次写入”追踪，付费依赖均为零：
b14000、三次 b7902 和尾部 b0 没有读者，b415/b416 只控制免费 Z/CZ/NEG。
因此这 7 个已证零点的进一步固定没有计分收益。插入 X q21 的负控会使 b417 零证书消失。
该结论仅覆盖这套保守分析证明的零点，不是所有可能 zero/coin 优化的全局否定。
