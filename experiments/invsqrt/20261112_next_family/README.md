## 2. 已读外部证据（避免重复证明 Q 下界）

### 2.1 Zenodo v0.3（DOI 10.5281/zenodo.23817707，2026-10-30）

作者 J. M. Barlow，技术笔记，非同行评审；配套 notebook
`manwithacat/is-the-63-qubit-inverse-square-root-optimal`。与本任务相关的三条：

1. **误差预算（对 63Q 家族）**：worst = 0.99932×tol @x=161，误差对 x 确定；对所有 41 个
   旋转角做线性规划只把定价裕度抬高 **2.7 units**。→ 与本 worktree `refit_angles` 的
   “改角度 0 收益”独立同构，已关闭，不再做。
2. **Q 轴**：63Q 家族里每个 63 宽 stage 收窄 1 线的 62Q 版本（yoyobar `a568bc79`）
   只多花 **+4.48 Toffoli-equivalent**，打平预算约 **26**。→ 与我们的 61Q 打平预算
   **+24.7 C** 一致（`20261112_newfamily_census` §5）。62Q 已是该架构的宽度下限。
3. **AND 计数**：63Q 架构的 main lookup 有 172 个 AND，而其下界为 **35**；
   Özer 的 `6dbb98b3` 用仿射恒等式替换 1 个 CSWAP 的 AND，随后对全部 1,501 个
   Toffoli-class op 做精确扫描，**再无第二个**。→ 局部恒等式路线在旧家族已饱和。

它自己的 README 也写明“public same-task comparison reports about 20×”（对 paper reference
2,076,774 的 22.2× 而言）。因此“更简单多项式 / 更大区间 / QROM 系数位宽”这三个旋钮
在**实测**上被锁死：减小表 → 次数升高 → 乘法位宽主导（32-cell 三次已 9,252）；
减小位宽 → 相对误差撞 2^-24（1024-cell 线性的 max rel err 4.60e-8 只剩 1.29× 余量）。

“CSWAP/multiplexed rotation 重综合”在本架构（digit recurrence，无系数表）没有对应物；
它的对应物是下面 §4 的旋转阶梯。

## 3. 当前 C 的精确构成（本机测得 mean）

方法：op 切点截断 + 前缀模拟差分（`scripts/segment_mean.py`），8,000 个 x
（x≤6,000 全枚举 + 2,000 随机）1 shot/x；合计 1,213.9536（官方 1,213.8659，偏差 0.007%）。

| 段 | op 区间 | CCX | CCZ | CSWAP | 静态 | **mean** | 占比 |
|---|---|---:|---:|---:|---:|---:|---:|
| prefix（前导位检测 + 44-CSWAP 归一化） | 0–8546 | 193 | 0 | 44 | 237 | **237.00** | 19.5% |
| ladder 1（2^-17…2^-2） | 8546–8928 | 51 | 0 | 0 | 51 | **51.00** | 4.2% |
| mid（x 重建 + 粗相位） | 8928–16389 | 372 | 7 | 0 | 379 | **372.99** | 30.7% |
| ladder 2（2^-35…2^-10） | 16389–16781 | 76 | 0 | 0 | 76 | **76.00** | 6.3% |
| tail（延迟校正 + 复原 + 收尾） | 16781–36965 | 499 | 85 | 48 | 632 | **476.96** | 39.3% |
| 合计 | | 1,191 | 92 | 92 | 1,375 | **1,213.95** | 100% |

tail 内部 mean：16781–18000 **3.76**；18000–20000 **92.25**；20000–22000 **113.53**；
22000–24000 **94.42**；24000–26000 **103.01**；**26000–32000 = 0**（6,000 op 全免费）；
32000–34000 **10.95**；34000–36965 **59.05**。

相位算术本身只有 **127 mean（10.5%）**，42 步平均 **3.02 CCX/步**（O(n) 的进位保存形态）。
**89.5% 是“可逆性 + 62Q 复用”的代价。**

### 3.1 62Q 不是浪费：x 自己的比特被回收（本机实测）

在 4 个切点读 x 寄存器（q0–q21）的值：

| 切点 | x 是否复原 | 该寄存器当时的内容 |
|---|---|---|
| end-prefix (8546) | 0/9 | 归一化尾数（如 3·2^20，前导 1 在 q21） |
| end-ladder1 (8928) | 0/9 | 同上 + 进位 |
| end-mid (16389) | 0/9 | 重建中的中间值 |
| end-ladder2 (16781) | 0/9 | 同上 |
| end (36965) | **9/9** | x 复原 |

且 mid 段对 x 比特做 **97 次 HMR**、tail 段 **144 次**（合计 241 个 x 比特实例被“测掉再重建”）。
即：**设计已经把 22 个 x 比特当 scratch 复用**，这是 62Q 能成立的原因。
→ 我上一版报告里“靠降 Q 拿 20%”的假设**撤回**：Q=62 已无宽度余量，
任何“去 normaliser / 去 mid”的改写都必须原样付出宽度或重建成本。

## 4. T 侧已到理论底（41 旋转 → 33 位）

解析 44 个 `Z_POW` 的 `Fraction` 指数：1.5/0.5/0.25 为 Clifford/T，**41 个一般旋转**，
覆盖 **2^-3 … 2^-35 = 33 个权重**，其中 **2^-10 … 2^-17 这 8 个权重被施加两次**
（ladder 2 的角相对 2^-k 有 +1e-6 偏移，是对 ladder 1 截断误差的修正）。

- 精度需求 `tol(max_x)=2^-24/√3,133,452=2^-34.79` → 2^-35 必需 → **33 位是信息下限**；
- 现状 T = 1 + 41×28.7896 = 1,180.36 → **295.09 C**；
- 33 位各一次：T/rot = 28.7896 + 0.56·log2(33/41) = 28.614 → **236.3 C**；
- **T 侧毛上限 −58.8 C = −3.9%**，且 8 个修正对同时承担 digit 信息（它们的测量结果
  驱动下游校正），不是“删掉 8 个旋转”的局部编辑，而是重排 ladder。

## 5. C 侧逐项可挖空间（本轮唯一实质工作）

| 杠杆 | 毛收益 | 现实性 |
|---|---:|---|
| ① 融合 8 个重复权重（ladder1 精确化 + ladder2 去掉 2^-10…2^-17） | −57.6 C（旋转）+ ~−24 C（阶梯步） = **−81.6 C（−5.4%）** | 需 ladder1 进位加宽 + 下游 digit/校正链重排；净估 **−40 C（−2.6%）** |
| ② prefix 重综合（193 CCX / 22 bit = 8.8 AND/bit，朴素下界 ~5/bit ≈ 110） | **−83 C（−5.5%）** | 需重写前导位检测 + 移位网络；会改 digit b_k(x)，须重建 0.9993 裕度 |
| ③ mid（373）| — | 是 x 重建 + 粗相位，**不是纯 uncompute**：逆 normaliser 只需 237，它多出的 ~136 用于取相位；无可删的纯簿记 |
| ④ tail（477）| — | 499 CCX + 85 CCZ 是 477 次 HMR 的“值计算 + 三体修正”；按 1 CCX/次已近 1 AND/erase |
| ⑤ 仿射恒等式扫描（Özer 式） | 每门 62 分（0.066%） | 旧家族 1,501 门扫描=0；本电路 1,375 门，上限 1 门 |

①+② 全部实现且不互相抵消 = **−165 C = −10.9%**（C=1,344，score 83,330）；
到 20%（C≤1,207）仍差 **137 C**，到 37.8%（C≤939）差 **404 C**。

## 6. 为什么 20% 在本架构里不成立（结构性论据）

1. **相位算术 O(n)**：127 mean / 33 位 = 3.8 C/位，已低于“每位 1 个 AND + 1 个修正”的
   自然下界（≈2 C/位）之上不多；把它压到 0 也只省 10.5%。
2. **剩下 89.5% 是 compute/erase 对**：859 HMR、1,191 CCX，即 ~1,191 次 AND 型值计算。
   20% 需要 −302 C ≈ 少 300 次 AND/erase（−25%），38% 需要 −511（−43%）。
   Zenodo v0.3 的 AND 下界方法（35 vs 172）表明“单个 lookup 块可低于其信息下界 5×”，
   但本架构没有 lookup 块可压：最大块 tail 的 477 mean 分布在 20,184 op 上，
   最大 2k-op 子块只有 **113.5**。
3. **宽度锁死**：62Q 是该架构最优（外部 + 本轮实测两路证据），mid 的 373 是
   “把 x 比特当 scratch 复用”的必然重建成本；去掉它就等于 84Q。
4. **插值家族实测 3.5× C / 7.3× 总分**（§2.2），不是误差常数没调好，是
   QROM 2^k 与乘积位宽的结构性代价。

## 7. 建议（未执行，需另立多日任务）

- **不做**：Q 下界、角度重拟合、仿射扫描、插值/QROM 家族、Q±1 预算——全部已有硬结论。
- **可做但只值 2–3%**：①（融合 8 个重复权重）。若要做，先做 8-bit toy 验证
  “ladder1 精确化 + 去重”语义，再上 200M 验证；预期 −40 C ≈ −2,480 分。
- **要 ≥20% 必须换“compute/erase 计数”**：目标把 1,191 次 AND/erase 降到 ≤890。
  唯一有量级依据的形状是“一次归一化 + 单条全精度阶梯”（省掉 mid 的 373），
  但那要求把 x 的 22 位低比特保留在宽度里（62→84Q，score 反升到 1.35×），
  或把指数做成 11 位相干 one-hot（Q 回到 58–60，20% 消失）。**这条线在 62Q 约束下自相矛盾。**
