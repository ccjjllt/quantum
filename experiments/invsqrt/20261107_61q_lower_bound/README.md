# invsqrt：当前门序列的 61Q 下界与算术替换预算前沿

日期：2026-11-07。基线：`artifacts/20261106_syed_v9/invsqrt/syed_v9_nofallback.kmb`
（62Q，官方本地 PASS，score 97,700.776777236，C=1,575.818980278）。
本文不是又一个近似变体；它把已有测量整理成**当前门序列的 61Q 不可行下界**，
并说明为什么新的算术替换无法进入 25.8331C 的 61Q 预算。

## 0. 结论

1. **值保持改写下界：** 在当前门序列上，任何 61Q 调度至少需要 **53C**
   的重新计算/重建成本；61Q 的允许新增成本是 **25.8331C**。
   因此当前门序列不存在 added C <25.8331 的 61Q 改写。
2. **算术替换前沿：** 当前 front+rotation 成本是 **694.840824C**；
   所有已实测的替换算术（piecewise、direct tap、digit recurrence、Newton/Goldschmidt）
   都至少 **3,362C**，而仅相位提取脚手架（归一化+对齐+旋转）就已约 **698C**。
   新算术必须同时重写相位提取，否则无法进入预算。
3. 这两条不构成对任意新算法的普遍不可能性证明；它们关闭的是
   **当前门序列**和**已测量的算术族**。要获得明确收益，需要一个目前没有构造的新算法。

## 1. 当前门序列的 61Q 下界

证据：`20261107_peak_rank/`、`20261106_q61/`、`20261107_quadratic_61q/`。

### 1.1 峰值秩 62

在 2,550 条值活跃性 62 峰值指令中，**1,175 条**的 62 个活跃值 GF(2) 秩为 **62**
（首次/末次 op16731/24364），覆盖 `[16731,18483)` 阻塞区。
秩 62 意味着不存在任何线性 `CX` 重编码或经典奇偶表示能少一个量子位；
61Q 必须在这些峰值处**不物化**至少一个独立值，或用非线性方式重建它。

### 1.2 重建成本

- q23 在阻塞出口 op24922 的仿射覆盖集为空：它不是任何一族仿射型的 AND，
  单项式表示（任意 CCX 数）不存在。
- q42@16877、q40@17921、q52@18483、q61@16886 是精确二次型，秩 10 → **5 CCX**；
  q43@16222、q57@15306 秩 14 → **7 CCX**。全部在 3,133,452 个 x 和随机分支上精确。
- 对 10 个关键选项做核空间秩下降，未发现任何低于 5/7 的二次型表示。
- 因此当前重建族的最低单位成本是 **5C**（q23 不可重建，代价视为不低于 5C）。

### 1.3 精确覆盖

免费暂停覆盖 1,918 条峰值，q61 交换新增 54 条，共 1,972/2,550；
剩余 **578 条 / 33 段**。对 1,352 个 `(wire,gap)` 候选按真实二次型 rank 定价，
精确加权区间 DP 的最小覆盖是 **53C**（11 个选项：1×1C + 9×5C + 1×7C）。
即使把所有 rank-1 重建当免费、所有 rank≥5 一律按 5C 计，下界仍是 **50C**。

```
61 · (C0 + ΔC) < 62 · C0   =>   ΔC < C0/61 = 25.833098C
53C > 25.8331C
```

所以：**当前门序列上不存在满足预算的 61Q 值保持改写**（在当前重建族内）。

## 2. 算术替换预算前沿

当前 front+两个旋转簇：

```
front 247.0 + 旋转簇逻辑 153.0 + 旋转合成 294.840824 = 694.840824C
```

任何替换 front+rotation 的新算法必须总 C <694.840824C（62Q 口径），
或整电路 C <1,601.652C（61Q 口径）。已实测：

| 分解 | 实测/下界 C | 对 694.84C |
|---|---:|---:|
| piecewise cubic（d3/S32，Horner） | ≥3,370.7（乘法计数为下界） | ≥4.85× |
| direct phase tap（A） | 19,991.4 | 28.8× |
| digit recurrence（radix-2） | 3,362.0 | 4.84× |
| Newton/Goldschmidt（变精度） | 14,052.3 | 20.22× |
| digit recurrence 的相位脚手架 | 698.0 | 1.00× |

关键：digit recurrence 的**相位提取脚手架**（归一化 124 + 对齐 274 + 38 旋转 255.75 + LOD 44）
已经是 698C，约等于整个 694.84C 预算；其算术即使完全免费也放不下。
Newton/Goldschmidt 的单次不可省乘法含反算 2,398C，是预算的 3.45 倍。
piecewise 的 `multiplier()` 经 256 例穷举发现计算的是低位回绕而非高半，
所以其 3,370C 只是下界，真实成本更高。

这不是“某个变体差一点”的问题：**任何保留现有相位提取/41 旋转的算术替换，
都要在 694.84C 内同时支付约 540–698C 的相位提取和至少数百 C 的算术**；
所有已测量的算术都远超余量。

## 3. 边界

- 本下界适用于：**当前门序列的值保持改写**，以及**已测量的算术替换族**。
- 它不证明任意新算法不可能：一个全新的算法可以避免在峰值处物化这 62 个值，
  或使用比 41 旋转更便宜的相位提取。这样的构造目前不存在。
- 任何未来的候选仍必须满足：真实 KMB、added C <25.8331、完整官方本地 PASS；
  本文不把任何账面方案记为收益。
