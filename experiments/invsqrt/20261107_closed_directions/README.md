## 1. 当前门序列的 61Q 下界（形式化，scoped）

**定义（值保持改写族）。** 从基线 KMB 出发，只允许改变值的停放/重算/寄存器分配；
在不改变全部 62 峰值值集合和逐 x/逐 HMR 分支边界值、相位的前提下，
用仿射型乘积之和重建被停放的值；其余门语义不变。

**定理。** 该族内任何 61Q 电路的 added C 至少为 **53C**；53C > 25.8331C，
故族内不存在满足预算的 61Q 改写。

**证明要点。** 2,550 条值活跃 62 峰值中 1,175 条秩为 62（`[16731,18483)` 全满秩），
线性/奇偶重编码不可能；q23 在阻塞出口的仿射覆盖集为空；
q42/q40/q52/q61 二次型秩 10（5 CCX），q43/q57 秩 14（7 CCX），核检查无更低表示；
免费停放+交换覆盖 1,972/2,550，剩余 578 条的精确加权区间 DP 最小覆盖为 53C
（乐观下界 50C）。∎

范围：只覆盖当前门序列的值保持改写，不是对任意新算法的普遍不可能性证明。
