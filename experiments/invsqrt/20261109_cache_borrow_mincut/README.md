   时刻计算的是**不同乘积**（累加器模式：同一目标被不同轮次的新乘积异或累加）。
   即使语义成立，每组跨度内 15–21 根未触碰线也**全部是脏线**（零/常1检验
   `clean=[]`，8 组全军覆没）。9 个跨界同伴组同样端点不等。无一对满足缓存语义。
2. **[25300:28200] 脏线借用：closed（精确到 +62 分净亏）。**
   4 有效对重验确认：两端无条件、控制字全等、目标字全等、乘积 XOR pop = 0，

   每对跨度内 14–21 根未触碰线在跨度起点**全部非零非常1**（全定义域字精确比较），
   即零干净线；4 跨度两两交叠（全局交集 [25699,27995] 长 2296，区间图 4-团⇒需 4 根线）。
   借用代价模型（ pipeline 恒等式，见 §2）：干净线每组净 −(k−1) CCX；
   脏线每替换一处净 **+1 CCX**（`[CCX a b d][CX d t][CCX a b d][CX d t]` 四门恒等式，

   k=4 联合缓存不可行（4 个乘积两两不同，pop 615,631–1,462,945，无共享子积）；
   最短跨度子集 `(q10&q61)` 单对脏借用净 +1 CCX（+62 分）；中继缓存仍需起点干净线
   （无）且 k=2 中继净 ≤0。6 个无效对中 `(q46&q30)`、`(q21&q26)` 乘积虽两端全等
   （pop=0）但控制各异，缓存+恢复仍需 +1 CCX，不改变结论；`(q26&q18)` 窗内不存在。
   全部未触碰线在跨度起点后**皆有后继读**（无死亡线，HMR 提前腾线不可行）。
3. **62→61Q 最小割：closed（不可行性定理级）。**
   `[2006:14215]` 确为 12,209 ops 纯无条件段（CX 12,058 + CCX 134 + X 17；
   前人“CX 12,059”差一，本实验计数和 12,058+134+17=12,209 精确吻合段长），
   前向精确非零 trace 全程 62（与后向活性一致，段内活性结论精确）。
   段内 15 根零触碰线（q0–q13 输入位 + q23）经主源依赖集（dep）分析**无一是真常量**
   （dep@2006 非空：单输入位函数或多输入仿射函数），且 Bennett 重算有效性
   （锥输入在 `[prod,14215]` 不变）对全部 15 根不成立（task3d 违反表：锥输入在
   生产点之后即被触碰）。段内真常量线数为 0（逐点 dep-DP 全段扫描最小值 0）。
