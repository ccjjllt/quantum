## 1. 历史脉络：三次跃升的机制本质

### Frontier 的 −2316：补丁叠加（patch stacking），同一算法骨架内做加法

谱系（`20261108_frontier_audit/README.md` §1）：Step 1 移位树裁剪 + lo-pass
三态延迟线（第二选择器 0 CCZ，−789）→ Step 2 死分支裁剪（−690）→
Step 3 Hosen 早期测量坍缩移植（−248）→ Step 4 `CARRY_PATCHES` 92 处进位擦除移植
（−527）→ Step 5 `q25` 处 2→1 坍缩（−62）。
五步互相正交、寄存器分配不变、逐步可 diff 验证。**本质是固定算法骨架上的局部
窥孔收割**——这也正是它能走到头的原因：单删/仿射张成/辛秩/HMR 窥孔/脏借用/T 融合
此后被逐一证明饱和（`20261109_*` 六个 closed 实验）。

### gengsr 的 −893：算法更换（algorithm replacement），整族重写

七段账（`20261110_gengsr_audit/README.md` §2，引 `evidence.json`）：
S0 移位树（CCX 不变 191/191，CX −7278——省的是免费 Clifford，不计分）+
S1 重分块（**+54** Toffoli-like）+ **A3 shift-select 循环（−72）** +
S2 相位窗合并（CZ −4915、Z −804，免费门为主；付费门 +8）+ 首尾锚点逐字相同。
净 −11 静态门对应约 −682 分，剩余约 −211 分来自 T 侧（Z_POW 48→45）。
**本质是新 family**：A3 控制/目标支撑集与旧电路完全不同
（新 `q18/21/23/27 → q28 + q52/55` 重装；旧 `q3/38/39/42/54/24/14…` CCX 树），
且与 S1 累加器分配、S2 相位窗重构耦合——旧 family 局部探针全部 closed 的前提下，
A3 不可单段迁回（审计 §4 结论）。**补丁叠加已证走到头；此后只能换算法。**

## 2. 新 family（shifter-46）的可扩展点与数量级 upside

基线：`C ≈ 94537.59/62 ≈ 1524.8`；静态池 CCX 1095 / CCZ 93 / CSWAP 204 / Z_POW 45。

### S1（`[8893:16329)`，CCX 365，占全电路 1/3）：+53 测-重算循环能否压缩？

S1 相对旧 family 多花 +53 CCX +1 CSWAP（累加器改用 `q41/q50`，
写目标 `q28×47/q27×35/q40×34…`，HMR 313 一一配对，属测-重算循环）。
若能回到旧 312 水平而保留 A3/S2 收益：**−53 CCX ≈ −3286 分**（上限，不现实——
与 A3 分配耦合）。现实切口是循环内部分重算共享：按 A3  precedent（−72/段），
S1 压缩 10–20 CCX 即 **−620 ~ −1240 分**。首要问题是先刻画 S1 循环在算什么
（累加器宽度、重算函数），而非直接动手。

### S2（`[16499:36427)`，CCX 499 + CCZ 78 + CZ 9124 + 条件块 280）：相位窗合并能否推广？

注意 S2 合并省的主要是**免费门**（CZ/Z 不计分），付费门反而 +8。
进一步 CZ 合并在旧 family 已证 Δscore=0（`20261109_tphase_fusion`：1311 对免费对消，
CCZ 0 对）。所以 S2 的推广方向不是 CZ 对消，而是：
（a）S2 内 499 CCX / 78 CCZ 自身的 Hosen 式擦除（见 §4 方向一）；
（b）T 侧：S2 仅剩 5 个 Z_POW，梯子已接近最简，upside 小。
S2 CCX 压缩 5% 即 −25 CCX ≈ **−1550 分**，但需先做新 family 的 uncompute 对普查
（旧 family 对应普查在 `[8860:15800]` 得 0 可转门——新 family 结构不同，结论不自动继承）。

### M1（A3 核心）：微角 Z_POW 补偿能否系统化为通用模板？

M1 = 移位-测-条件修正-重装 + 二进制权重微相位舍入补偿（A3 内 21 个 Z_POW，
角度从 2.9e-11 起倍增）。可系统化为模板 **“近似计算 + 测量修正”**：
用粗糙的 shift-select 路由代替精确乘积树，误差由条件修正 + 微角补偿吸收。
A3 单段 precedent：−50 CCX −22 CSWAP，代价 +21 Z_POW（T 侧）+24 HMR。
模板推广的两个着陆点（按优先级）：
1. **反方向——A3 微角梯子剪枝（T 侧，最便宜）**：21 级微角是否每级都在容差内
   load-bearing？每剪 1 个旋转 ≈ **−446 分**。但 worst 比 0.9993@x=161 说明裕度在
   最坏点几乎耗尽，需逐级掩码敏感度分析，不能整段删（旧 family 候选 B 对合并
   FAIL：误差恰为被搬移角 θ/2，2509×容差——微角搬移必做同分支真机仲裁，
   零分支字仿真在此处已证为假阳性来源）。
2. **正方向——S1 循环的 M1 化**：S1 已是测-重算形态，问题是重算仍用精确 CCX 链；
   若其中部分重算可降级为 shift-select + 微角补偿，每处省数个 CCX。
   S1 池 365 CCX，10% 转化 ≈ **−2250 分**，但语义分析成本最高。

### S0（CCX 191/191 两 family 不变）：接近下限

两代独立设计的移位树 CCX 完全相同（191），强烈暗示该寄存器分配下优先编码+桶形移位
已近 CCX 下限；新树已把免费 CX 扇入压到 −7278。upside 仅数个 CCX（**数百分**），
优先级最低。

## 3. 跨任务/跨 family 启发（只转运已验证的机制，不转运结论）

- **DQI 的测量擦除模板**：invsqrt 已转运过一次且成功——Step 4 `CARRY_PATCHES`
  就是 Hosen 式“测 + 条件清理”移植（−527）。DQI 侧的反面教训同样适用：
  脏线借用语义错误（toy 实测污染；正确模型每处 +1 CCX，做即亏，
  与本工作区 `20261109_dirtyfrag_proof` 独立同构）——凡无干净线的缓存一律先算
  四门恒等式账。转运到新 family 的含义：**只做 Hosen 式（测 + 对角条件修复），
  不做脏借用**；而新 family S1/S2 是否含可转 uncompute 对，需重跑普查
  （旧 family 的 0 结论不可继承）。
- **化学的 QROM 共享 planner 思想**：化学 loader 侧用共享 QROM 摊薄多组角度加载成本。
  invsqrt 类比物是 Newton 迭代种子/早期轮次：若粗近似表可被多个求精阶段共享摊薄，
  则“查表代替算术段”成立。但旧 family 已有证伪：分段三次最好成员 7.4× 基线、
  非算术固定开销 534C 超预算；掩码 ANF 需百万级 CCX。**结论：整段查表替换仍
  被旧下界压制**，唯一活口是“多阶段共享摊薄”（旧实验未覆盖的形状），列为第三方向。
- **61Q 宽度**：旧 family 的不可能定理只覆盖“值保持改写族”（scoped），新 family
  活性剖面不同（S2 条件门 −45、HMR 分布已变），233→372 峰区间清单需重跑。
  61Q 毛收益 ≈ 1525 分、预算 ≈ 25C。列为方向一的零成本前置探针，不单独成方向。

## 4. 新架构方向（按 预期收益 × 实施成本 × 可验证性 排序）

### 方向一：新 family S1/S2 的 Hosen 式擦除普查 + A3 微角梯逐级敏感度（高收益/低成本/高可验证）

- 内容两步：（a）对新 S1 `[8893:16329)`、S2 `[16499:36427)` 重跑 uncompute 对普查
  （同三元组 compute/uncompute 配对、守卫/HMR 链、Hosen 式条件修复可行性），
  旧脚本（`task1_product_cache.py`、`t1_uncomp.py` 口径）改输入即用；
  （b）A3 的 21 级微角逐级掩码敏感度（同分支真机读数，沿用 `prefix_branch_check.py` 方法）。
- 预期收益：（a）每转 1 对 ≈ 0.5–1C ≈ 31–62 分，S1 池 365 CCX，5–10 对即 150–600 分；
  （b）每剪 1 级 ≈ 446 分，剪 1–2 级即 450–900 分。合计数量级 **500–1500 分**。
- 第一个实验：新 KMB 上跑 S1 uncompute 对 census（输入：`26ebf39d` S1 段；
  改动：无，只读统计；判据：depth-0 compute/uncompute 同三元组对 ≥3 且修复路径为对角条件门；
  成功标准：输出 ≥3 个可转对清单 + 其中之一的手工切片 Simulator 语义持平）。
  通过后再构建候选并跑官方验证器（复盘阶段不跑）。

### 方向二：M1 模板正向推广——S1 重算链的 shift-select 降级（高收益/中高成本/中可验证）

- 内容：刻画 S1 内 HMR 配对 CCX 群算的函数（累加器 `q28/q27/q40` 的重算语义），
  选一群试点“精确重算 → shift-select + 条件修正 + 微角补偿”，A3 切片方法复用
  （`novel_primitive_slice_check`：控制位保持 / scratch 回收断言）。
- 预期收益：S1 池 10% 转化 ≈ **−2000 分量级**；风险是语义分析可能证伪（累加器 obstruction
  在旧 family 多次出现：`xreg_bigwin` 117/117 倒在共享控制不稳定）。
- 第一个实验：选 S1 内 `q28×47` 写群之一，提取其重算函数真值表（全定义域字仿真），
  判断是否为“小支撑选择函数”（若支撑集 ≤ A3 支撑集规模则 M1 可套用；
  判据：支撑集大小 + 移位选择分支数 ≤ 70 CSWAP 当量；成功标准：给出可套用的群或证伪报告）。
  不构建候选。

### 方向三：多阶段共享的粗近似表（摊薄型 QROM-for-seed）（中低收益/高成本/中可验证，垫底）

- 内容：只计量“种子/首轮近似”子段（定位 S1 内初始近似 CCX 数），设计一版本
  2^k 条目共享表 + CSWAP 路由（沿用 A3 shift-select 路由形态），由 ≥2 个求精阶段共用摊薄。
- 预期收益：若种子段 ~30–50 CCX 且表 + 路由摊薄后减半，**−500 ~ −800 分**；
  但旧 piecewise/ANF 下界（7.4×、百万 CCX）是强反指，需先过可行性不等式再投入。
- 第一个实验：种子段成本 + 共享表规模不等式（输入：新 KMB S1 前段；
  改动：无；判据：`表CCX/k共享阶段 + 路由CSWAP < 种子段CCX − 5`；
  成功标准：不等式成立才立项，否则关闭——大概率关闭，接受此结果）。
