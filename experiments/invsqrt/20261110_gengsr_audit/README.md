### “shifter 46”

- 规格化桶形移位树：新 **46 门全 `q48` 控制**（`[101:372]`），旧 47 门（45×`q48` + 2×`q37` 收尾）。
  公共交集仅 10 种配对；新树用不同的级间 `q48 = XOR(编码器位)` CX 解码扇入，
  CCX 完全相同（191/191）而 CX 省 7,278 —— **省的是免费 Clifford，不是分数**。
- 中部 shift-select：新 70 门（控制 `q18×19 / q27×20 / q21×19 / q23×12`）vs 旧 92 门
  （`q18×28 / q21×27 / q27×26 / q23×11` + 开头 `q18 q1 q3 / q18 q2 q23 / q21 q1 q3`）。
  移除 `q21 q8/q10/q11`、`q23 q40/q41/q50` 分支，改用 `q21/q23 q4/q5/q7` 分支。
- 反规格化 49 门两 family 逐字相同，不在“shifter 46”改动内。

## 3. 新 family 的不同构造模式（≥1 处）与语义验证

**模式 M1（A3，核心）：早期测量 shift-select 循环代替 CCX 乘积树。**
旧 A3 先用 CCX 树算乘积（`q3 q39 q21`、`q42 q54 q27`、`q24 q14 q28`…），再
`HMR + 条件 CZ`（CARRY_PATCHES 式）修正；新 A3 交替
`CSWAP q{18,27,21,23} … q28` 选位 → `Z_POW q28 <2.9e-11 起倍增的二进制权重微角>`
→ `HMR q28` → 条件 `CZ` 修正 → `CX q{52,55,…} q28` 重装 scratch。
即把进位/乘积反计算换成“移位-测-条件修正-重装”循环，附带微相位舍入补偿。

**模式 M2（S0）：`q48` 单控制复用桶形移位。** 去掉旧 `q37` 收尾级，
全部级复用 `q48`（级间用 CX 扇入重算），CX 解码网络大瘦身。

**模式 M3（S1+S2）：算术重分块。** S1 多花 +53 CCX（累加器改用 `q41/q50` 而非 `q20/q18`，
写目标 `q28×47/q27×35/q40×34…` 且 HMR 一一配对，属测-重算循环），
S2 相位窗合并（CZ −4,915，Z −804，条件块 −45），worst 误差与 worst_x=161 不变。

语义验证（本审计执行，不触发官方验证器）：
1. **全定义域字比较**：新电路无条件经典骨架（X/CX/CCX/SWAP/CSWAP/HMR）在
   全部 3,133,452 输入（48,961 × uint64 字）上追踪：退化付费门 **0**，
   末态 `q22..q61` 残差全 0（**归零 true**），与旧审计同口径。
2. **Simulator 切片**（穷举基态，Python-int 位掩码引擎，512 态）：
   切片 `new[16342:16350)`（CSWAP 选位 + `CX q23 q21` 解码对 + `HMR q28` + `CX q52 q28`；
   Z_POW 为对角门，不影响比特）——控制位 `q18/q21/q23/q27/q52` **逐比特保持**，
   scratch `q28` 终值恒等于初值 `q52`（**回收 true**），数据位 `q0/q3/q5` 按预期被路由
   （非保持，符合 shift-select 语义）。端到端相位正确性由官方 PASS 覆盖（本审计不重跑）。
3. **饱和探针**（新电路）：单门退化 0；`CCX→HMR` 未读 0（10 处有 Z_POW 守卫，不可经典替代）；
   写累积段 54 个多 CCX 段 / 776 个单 CCX 段（旧 48/785），辛秩约简未重算（见 §4）。

## 4. 迁移评估与结论：closed，无候选、无验证器运行

- A3 的 −72 Toffoli-like 不可单段迁回 `7c10edba`：控制/目标支撑集完全不同
  （新：`q18/21/23/27 → q28` + `q52/55` 重装；旧：`q3/38/39/42/54/24/14…` CCX 树），
  且与 S1 的 +53 CCX（不同累加器分配）及 S2 相位窗重构耦合。旧 family 局部窥孔
  （单删/辛秩/HMR/脏借用/T 融合）此前已全部 closed，A3 是整族算法更换，不是补丁。
- 新电路自身探针亦饱和（退化 0、未读 0），无净正收益候选方向。
- **故本轮无 `.kmb` 候选构建，无官方验证器运行。** 引用的 PASS 均为既有证据：
  新电路 PASS（主仓库提交回执 + 作者日志，小数点后一致），旧电路 PASS（历史基线）。
