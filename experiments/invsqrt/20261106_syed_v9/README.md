# Syed V9：无回退选择器迁移与独立证明

日期：2026-11-06（北京时间）。分支 `codex/invsqrt-research`。

## 当前结论

公开比较基线已切换到 **Syed V9 / run366109544 / dataset V9**。
实际电路为62Q、46,844操作、1,475个静态Toffoli-like，63,085个经典位。
作者报告成本约97,747.22；此数不是本次本机测量。

旧Maoxin上的约1C无回退方法**仍可迁移，但净收益缩小到约0.75C**。
Syed已把第二选择器从19系数的一般选择链压成两系数选择器，先吸收了约0.25C。
不能将旧约1C原数叠加到新版本。

本轮构造了 `artifacts/20261106_syed_v9/invsqrt/syed_v9_nofallback.kmb`：
62Q、49,051操作、1,457静态Toffoli-like；一般旋转及窗口外指令不变。
精确期望节省 **393215/524288 C = 0.74999809265 C**，
固定62Q下为 **46.4998817444成本**；单个shot不一定少0.75门。
将该期望扣除作者报告得到约 **97,700.72**，仅是投影，不是本地完整评分。

局部证明与3×21,760输入原生样本比较已通过，随后一次完整官方本地验证
**PASS：200,540,928 shots，成本97,700.776777236**。这是本轮实际候选成绩，未提交Kaggle。

## 实际差异与生成方法

输入只读来自 `artifacts/20261106_syed_v9/release/invsqrt.kmb`，
共享原始输入由main按固定数据集V9取得；未计算或匹配来源哈希。
旧窗口参考为仓库已保留的Kirill V5和Maoxin V2实际电路。

本机 `inspect_migration.py` 逐指令比较得到：

- Maoxin第一选择器 `[27911,28349)` 在Syed中完整保留，移至 `[27342,27780)`。
- 第一经典准备段132条完整保留，现位于 `[27210,27342)`。
- 第二准备段只保留原131条系数/补码写入，位于 `[27780,27911)`；
  原来的恒零b24358写入和旧19分支选择链被新的47条聚合/选择指令替代。
- 新第二选择器 `[27911,27958)` 先形成b61001/2/3三个仿射奇偶，
  相位为 `q27*q21*(b61001 + b61002*q14 + b61003*q16)`（加号为XOR）。
  用两个条件CCZ实现；收费恰为 `b61002 OR b61003`。
- 因后两奇偶在29个独立测量源上秩为2，第二选择器期望收费为3/4C。
  第一选择器仍收费 `1−2^-19 C`，联合原窗口共 `7/4−2^-19 C`。
- 我们把 `[27342,27958)` 整体替换为3分支无回退选择器，恰有一分支执行，
  收费1C。新增经典位为b63085…b63093，避开Syed已有b63084及以下位。

生成器使用本仓库既有 `migrate_public62_nofallback.py` 的发现与构造函数，
明确覆盖新窗口、准备位置和新经典位；不调用其历史hash检查/main入口。
三分支由当前真实前缀的x=1…63真值构造，并随后重新证明全部前件，
不因旧Maoxin证明通过就假定新前缀成立。

## 独立证明和实际局部检查

`selector_migration.py` 手动运行约16秒；所有结果在
`artifacts/20261106_syed_v9/invsqrt/selector_migration.json`和同名log。

1. **65项新前缀SSA断言：全部UNSAT。** 对全部合法x和自由测量结果，
   q21=1蕴含x≤63；q28/q40为零；每个小输入的62根量子线状态固定。
2. **2个旧选择器通用语义miter：UNSAT。** 确认原19系数相位和量子恢复，
   用作独立目标定义，不执行外部公开生成器。
3. **66项Syed第二选择器检查：全部UNSAT。** 任意量子输入恢复；q21=0时相位为零；
   收费恰等于两个聚合奇偶的OR；每个x=1…63时对任意19经典系数与旧目标相位一致。
   这些前件与第1项组合覆盖全部合法x，不是仅对63个输入的采样结论。
4. **三分支ANF/相位检查通过。** 全62线恢复，新增HMR相位系数消失；
   当q21=0时所有分支相位消失。三失败奇偶秩为2且XOR为零，不能同时失败。
   删除一条CZ纠相的负控被拒绝。
5. **测量源/经典存活检查通过。** 29个源的最后写入均为不同的无条件HMR；
   替换段删除的经典写入无后缀引用。新经典位无原电路占用。
6. **精确期望计费：** 旧`917503/524288 C`，新1C，净`393215/524288 C`。
   静态21→3并非每shot省18C；旧第二选择器含条件经典写入，
   本轮对其先做Boolean计费证明，再按实际仿射秩算概率，未硬套旧纯仿射计费器。
7. **native kickmix实际样本：** seeds101/202/303各21,760输入；
   恢复错误、scratch错误、相位差、容差失败均为0。
   样本平均Toffoli节省分别0.66227、0.70836、0.84104；
   新HMR改变后续随机数消耗，同seed并非全程测量历史配对，不能把偏差另算收益。
   两电路样本中均为41个一般旋转、T均值1.0，最坏误差比0.999323769@x161。
