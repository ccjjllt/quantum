本轮回答一个问题：**把 8-bit 半对数查表 + 二次 Horner + 41 个旋转换成
"归一化 → 双曲 CORDIC 向量化 + 同符号旋转 → 相位按 y 的二进制展开" 之后，
能不能把 front+旋转的 694.840824C 压下来，或者让 61Q 的新增 C < 25.833098？**

**不能。双曲 CORDIC 倒数平方根（双子系统共享 σ）的最便宜账面是
11,126.9C、Q=3,046、score 33,892,406，
是 694.840824C 预算的 16.01 倍、61Q 整电路预算 1,601.652C 的 6.95 倍；
相对基线新增 +9,551.0C，是 25.8331C 允许额的 369.7 倍。没有生成 KMB，
没有运行官方验证器**（按任务约定：账面已远超预算即停止）。
用 CORDIC 向量化 + 非恢复倒数的混合变体也只要 7,556.0C（10.87×），仍然远不够。

三条独立的否定证据：

1. **单是 CORDIC 迭代就超预算 7.5 倍。** 37 轮 × 4 次条件加减 × 35 个 paid
   ×（计算+反算）= 10,360C，占全部 C 的 93.1%。
2. **每轮必须有 4 次条件加减，且每次是全宽 35 个 CCX。**
   把符号折进操作数只省掉"控制"，省不掉位宽：目标寄存器低位的进位必须算，
   所以宽度不随 i 收缩；实测 i=1、14、28 的单轮成本都是 140。
3. **即使 CORDIC 迭代完全免费，只剩相位脚手架 766.9C，也已超过 694.840824C。**
   归一化 168 + 对齐 282 + 旋转 242.86 + prep/(P+Q) 74 = 766.9C。

对比上一轮非恢复数字递推（3,362.0C，4.84×）：**CORDIC 更贵**，
因为它的向量化递推每步要 4 次加减（两个坐标 × 两个子系统），
而数字递推的 digit 选择是残差符号位（免费），每步只需要 2 次加减。

顺带一个正面结论：**双曲 CORDIC 的 angle table 完全不需要**。
σ 来自残差符号，旋转子系统复用同一 σ，因此没有 atanh 表、没有 QROM、
没有角度寄存器、没有量子-量子比较。真正贵的是数据通路，不是角度。

## 1. 算法规格

### 1.1 归一化与指数

```
e = floor(log2 x) ∈ [0,21]          （22-bit LOD，后缀 OR 链）
k = e >> 1 ∈ [0,10]
M = m·2^G,  m = x / 4^k ∈ [1,4)      （G = 34 小数位；m 只有 22 个有效位，精确）
```

### 1.2 双曲向量化 + 同符号旋转（两个子系统共享同一个 σ）

经典双曲 CORDIC 用 `(A,B) = (m+1, m-1)` 向量化求 sqrt。为了直接得到
`1/sqrt(m)` 且**不出现除法、不出现角度寄存器**，这里同时推进第二个向量
`(P,Q)`，两者用**同一个 σ 序列**：

```
标度取 1/4（每个寄存器只需 1 个符号位）：
  b0 = (M - 2^G) >> 2        # (m-1)/4
  a0 = b0 + 2^(G-1)          # (m+1)/4   （只加 0.5，3-bit 片内一次 iadd）
  p0 = round(2^(G-2) / K),  q0 = 0

第 i 步，σ = -sign(b)：
  a <- a + σ·(b >> i)        b <- b + σ·(a_old >> i)
  p <- p + σ·(q >> i)        q <- q + σ·(p_old >> i)
```

恒等式（对**任意** σ 序列成立，因为每步矩阵
`[[1, σ2^-i],[σ2^-i, 1]] = sqrt(1-4^-i)·R(σ·atanh 2^-i)`）：

```
a_N = K·sqrt(a0^2 - b0^2) = K·sqrt(m)/2 ,   Θ = Σ σ_i atanh(2^-i)
p_N = (1/K)·K·cosh Θ ,  q_N = (1/K)·K·sinh Θ
所以  p+q = exp(Θ)
```

向量化把 b 驱动到 0，于是 `Θ = -atanh((m-1)/(m+1)) = -ln(m)/2`，因此

```
y := 4(p+q)/2^G = 1/sqrt(m)
```

**没有角度表、没有 QROM、没有比较器**：σ 就是 b 的符号位，用一根 CX 复制；
相位子系统的旋转角和相位子系统共享同一 σ，所以 atanh 常数从来不需要被物化。

### 1.3 迭代集合：重复是强制的

超双曲 CORDIC 的标准收敛规则必须保留：`i = 1..28`，其中 `i = 4,7,10,...,28`
（`i ≡ 1 mod 3`）重复，共 **37 轮**。全域数值检查直接量化了后果：

| 迭代集合 | 轮数 | 结果 |
|---|---:|---|
| `i = 1..28`（不重复） | 28 | **全部 3,133,452 个 x 失败，最差 708,428× 容差** |
| `i = 1..28` + `4,7,...,28` 重复 | 37 | 0 失败，最差 0.2587 |

所以"28 个固定角旋转"的直觉在这里不成立：超双曲需要 37 轮。
（26/27 轮也能过容差，但余量不足；见 §3.2。）

### 1.4 相位

`y ∈ (0.5, 1]`，前导 1 在 `2^-1`，用到 28 个小数位；`phase = 2^-k·y`
落在绝对位置 `1..38`，因此 **38 个旋转位**：

- 位置 1（角 `2^-1` turn = π）→ Clifford，免费（km 的
  `num_z_pow(min_clifford_hierarchy_level=4)` 实测不计数）
- 位置 2（角 `2^-2` turn）→ T，0.25C
- 位置 3..38 → 36 个一般旋转

`y` 只在 11 个 4 的整数幂（m = 1）上略大于 1（截断后 `y·2^28 = 2^28+30`），
多出的 `2^0` 位平移后落在位置 `k ∈ [0,10]`；位置 0 是整圈旋转 = 恒等，免费，
其余已在 1..38 内。因此对齐目标寄存器 39 位、一般旋转仍是 36 个。

## 3. 门级构造与实测

`kernels.py`：所有 paid 数（CCX+CCZ+CSWAP）都由官方 `km.CircuitBuilder`
构造完整电路后读 `OperationStatistics`，不是公式外推。

### 3.1 条件加/减的真实成本

CORDIC 每步需要 `x ← x ± (y>>i)`，符号是量子位。两种写法：

| 写法 | 每次 C |
|---|---|
| `iadd(y_slice, target=x, control=σ)`（"条件加"） | `2(W−i)+3`，实测 W=36 时 75 |
| **条件取补 + 无条件加**（本文采用） | `W−1 = 35` |

采用的恒等式（`W` 位二补）：

```
x - y = NOT( NOT(x) + y )   (mod 2^W)
```

所以两个分支都只是 **一次无条件量子-量子加**，两次"条件取补"是免费 CX。
实测：`iadd` 等宽 36 → 35；`iadd` 带 control 36 → 75。前者便宜一半以上。
`cas_primitive_check` 在 120 组随机 `(x, y, σ)` 上把 `i = 1..W−2` 的每一次
条件加减都紧跟一次精确逆，`x`、`y` 全部恢复（证明原语是双射且逆正确）；
正向语义由 `small_instance_simulation` 对整数模型逐位比对（9/9）。

注意 `km.iadd` 对**窄 offset 做零扩展**（不是符号扩展），所以 `y>>i`
必须先把 `y[W-1]` 复制到 scratch（免费 CX）补足 W 位；否则负数会加错。
因此每次加减都是全宽 35，不随 i 收缩（`a` 的低位进位必须算）。

  `P+Q` 与整数模型**逐位相同**（9/9）。
- **`large_spotcheck`（真实尺寸 F=34, W=36, 37 轮, 2,953 qubits, 73,146 ops）**：

  **所有 scratch 归零**。

### 3.4 快照 ancilla 的代价（Q 的主因）

每步需要 `a_old`（或 `b_old`）的一路快照。快照复制是 CX，**不能跨轮复用**，
否则会把两轮不同的旧值 XOR 在一起（本轮一开始就踩了这个坑，被小规模门级
仿真抓到，单轮 p/q 立刻偏离）。可行的实现只有两种：

1. **每步一个全新 |0> 快照**（本文实测采用）：paid 不变，但 74 个 36 位
   快照必须一直活到反算阶段 → Q 增加 2,664，`kernel_full` 实测 Q=2,953。
2. 复用一份快照：必须先重算出旧值再清 CX，每步每子系统至少多 2 次加法，
   按实测每次 35 计，C 至少 +5,180（单方向）。

本文按 (1) 记账：**C 是最小的，Q 是诚实的**。按 (2) 可以把 Q 降到约 290，
但 C 会升到约 16,300C（22× 预算）。两种实现都远超预算。

## 5. 为什么这条路必然亏

| 事实 | 数量 |
|---|---|
| 每轮条件加减次数 | 4（两个坐标 × 两个子系统） |
| 每次条件加减的最小 paid | `W−1 = 35`（无条件量子-量子加，实测） |
| 每轮 | 140 |
| 37 轮 forward | 5,180 |
| 计算+反算 | 10,360 |
| 非算术固定项（LOD+移位+对齐+旋转+prep） | 766.9 |

CORDIC 的每步必须同时维护 `a` 和 `b`（否则无法得到下一步的 σ），
并且为了 `1/sqrt` 必须再维护一对 `(p,q)`；这是 4 次加减的来源。
数字递推（上一轮）的 digit 选择就是残差符号位，每步只需要 2 次加减，
所以 **CORDIC 在本题门集里严格劣于数字递推**（11,126.9 vs 3,362.0）。

kickmix 门集没有 H、没有 QFT，Draper 型免费加法器不可用；
唯一的加法原语是 CCX 进位链。在这个前提下，`w` 位加法至少要 `w−1` 个
Toffoli-like 门（每个进位都是非线性的），所以 148 次加减 × 35 就是
**5,180C 的硬下界**（单方向），远超 694.840824C 的全部预算。
