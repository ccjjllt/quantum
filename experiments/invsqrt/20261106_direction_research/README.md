# invsqrt：高收益研究方向评估

日期：2026-11-06，北京时间。工作区 `.worktree/invsqrt`，起点提交 `24b1e78`。
任务是结合比赛数据、公开实现与前沿研究，确定下一轮值得投入的成本优化方向。
本记录区分**已有收益、这次新增的诊断证据、尚未实现的收益预算**。

## 结论与优先级

**主线应是“可达域上的算术与测量纠相联合重综合”，同时以 61/60Q 为空间目标。
继续逐门删除、同骨架小窗穷举或固定旋转掩码调角，预期价值明显较低。**

这里的“高收益”指有足够成本容量和机制依据、值得优先做具体电路实验；
本轮没有新电路通过官方验证，也没有证实当前最佳成本已经下降。
1%/5% 是比较路线的研究预算刻度，不是用户指定目标或收益承诺。

| 优先级 | 方向 | 量化依据 | 第一项可判定的实验 |
|---|---|---|---|
| P1 | 完整算术块 + 跨 HMR 纠相的共享乘积重综合 | 当前 81.27% 等效成本在 Toffoli-like；两旋转之间与第二旋转之后合计约 880.74C 的样本执行成本 | 对 `[21434,23311)` 的 46-CCX 多输出块提取可达域、真正存活输出与后继相位契约；允许改变内部表示，先构造至少一个可证明严格少付费门的替代 |
| P1（与上项联合） | 输出寄存器内直接计算、分段消费 seed/地址副本，争取 61/60Q | 少 1Q、无额外门时省 1.613%；允许额外总成本 <25.8331C。公开 63→62Q 曾以约 +4.5C 实现 | 覆盖全部 62Q 峰值阶段，先重构 seed/lookup 的编码与释放计划；给出完整 61Q 调度和 compute/纠相/recompute 总账 |
| P2 | 更大范围的测量相位坐标与经典奇偶共同综合 | 已有 nofallback 在新基线精确省约 0.75C；2026-09 论文给出更一般的表示优化框架 | 把多个 HMR 的 `sum m_i*g_i(x)` 连同已有纠相合成，允许冗余坐标与免费 XOR，逐分支证明恢复和计费 |
| P3 | 新分段近似 + 窄坐标 + 直接相位/原位消费的整体表示 | 本轮 24 组定点模型中 10 组全域满足数值容差；尚无可逆实现或硬件优势 | 先生成一个实际 truncated multiply/lookup+unlookup 内核，验证 Q/C 预算；只有账面能明显低于基线才实现全电路 |

P1 和 P2 有重叠，应作为同一表示设计问题推进，而不是把预期收益相加。
宽度路线潜在杠杆很大，但实现确定性低于一个具体块的门数改写。

权威本地契约为 `data/competition/verifiers/invsqrt/verify_submission_invsqrt.py`：
所有 `x=1..3,133,452`，22-bit 输入须恢复，scratch 清零，相位为 `1/sqrt(x)` turns，
逐输入容差 `2^-24/sqrt(x)`。每个 x 默认64 shots，没有允许舍弃罕见 x 或失败测量分支的预算。
量子控制为零仍会计入一个执行的 CCX；只有经典条件不成立才跳过门。

本轮通过 Kaggle MCP 重新读取 [Evaluation](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation/overview/evaluation)，
确认单项成本越低越好，组合榜分为三项改善倍数的几何平均。
因此本项成本降低5%在其他两项不变时只带来约1.725%总GM提升。
结构限制亦见 [比赛伴随论文 v2](https://arxiv.org/html/2610.23832v2)。
普通 H、QFT、QSVT 电路不能直接作为 kickmix 候选提交；HMR 的测量清零不等于保留态的 H。

## 2. 公开实现告诉我们哪些改进已经被用掉

完整来源、固定版本、源码读取范围见 [公开实现调查](public_implementations.md)。

- Syed V9 的共享乘积、延后纠相复用、尾部 thermometer shift、条件 T gadget 改写等已经在当前基线。
  原作者收益不可重新记为下一轮收益；当前本地 nofallback 额外约0.75C已有独立证明。
- 旧62Q源架构已经有8-bit mantissa地址、10个长寿命导数 seed，以及把 lookup 临时量写入输出字的技巧。
  持久归一化信息已经使用5-bit binary count，不能假设还存在可直接压掉的大串 unary flags。
- 公开63→62Q的关键是多处宽度高峰一起重综合：32个lookup AND中27个在输出字中直接计算，
  只保留5个临时量；另以经典奇偶和现有线的线性形式替代 helper。不是简单删一条闲置线。
- 公共数值模型已出现全域近似可行、但编译需175Q或相位控制难以廉价重建的例子。
  因而“数值模型过容差”只解决近似问题，不能代替可逆实现的成本证明。

本轮没有找到可以直接证明优于本地 97,700.7768 的公开 invsqrt 候选。
这是本次已查询来源的结论，不声称穷尽所有公开或私人实现。

## 3. 本轮对实际电路的新诊断

脚本 [cost_census.py](cost_census.py)；详细证据见 [成本结构分析](cost_structure.md)。
输入固定为当前 KMB，坐标是剔除寄存器声明后、从0开始的半开指令区间。

### 3.1 热点是大块算术与恢复，不是末尾几条 T 门

对三组均匀输入，每组16,384个 x，分别模拟随机测量轨迹并计费。
原生 kickmix 总门计数与独立 bitset 轨迹统计一致到抽样量级；两者测量流独立，不是逐shot等价证明。
局部统计不检查数值相位，不能冒充官方PASS。

| 当前区间 | 静态付费门 | 平均 Toffoli-like 成本 C（不含 T/旋转） | 研究含义 |
|---|---:|---:|---|
| `[0,15278)` | 247 | 247.0 | 归一化/lookup及第一相位前的计算；包含长62Q高峰 |
| `[15278,15617)` | 62 | 62.0 | 第一组15个一般旋转周围的逻辑 |
| `[15617,25408)` | 389 | 约376.985 | 主算术/纠相热点，不能用低次输入ANF假设替代真实前缀 |
| `[25408,25649)` | 91 | 91.0 | 第二组26个一般旋转周围的逻辑 |
| `[25649,49051)` | 668 | 约503.751 | 大量恢复、测量纠相与选择逻辑；不能因称“反计算”就全换为免费HMR |

特别是 `[24000,26000)` 有244个无条件付费门。
可优先分析的纯 X/CX/CCX 多输出段包括：

- `[21434,23311)`：46 CCX、31根涉及线；
- `[33980,36370)`：59 CCX、32根涉及线；
- `[3429,14081)`：117 CCX、47根涉及线。

这些是结构入口，不是已经证明为二次函数或可以压缩的窗口。
要真正取得5%单项成本改善，固定62Q需要净省78.79095C，必须触及大块或能多次应用的结构。

### 3.2 小跨HMR窗口有用，但独立小修的容量有限

本轮以≤32线、≤601条指令、恰1个HMR的三付费门跨度普查，选择39个互不重叠窗口。
若**每个窗口都恰好少一付费门**，静态预算最多39C，约2.475%当前成本；
以首付费门执行概率加权的样本情景约37.50C，不是严格上界或已证收益。
即使全体成功，也不足固定Q下的5%目标刻度。
这并不限制更大的多HMR重综合，只说明不能把有限几何窗口数当作高收益保证。

### 3.3 少1Q比少1门更有价值，但必须改变信息的存储方式

保守活跃区间模型得到98段62Q峰值，主要长峰有 `[3467,14082)`、`[27551,30168)`、
`[34609,36371)`，还有旋转与恢复附近的短峰。它仅描述现有表示和调度，不是量子位下界。

我们另外对**当前Syed候选**做了固定全0 HMR分支、全3,133,452输入的局部可达性检查：
在prefix `[0,3468)`之后，去掉q23时出现612,723个相邻冲突对；此时8个经典位全部为0。
具体反例：`x=1,974,272` 与 `x=493,568` 的其余61量子线完全相同，q23分别为0/1。
因此q23不能由这个时刻的其他量子/经典位确定性重建。
这是一个明确的局部反例，支持停止“测走长闲置q23、以后免费重算”的捷径；不否定重新编码的61Q方案。
证据为 `artifacts/20261106_direction_research/cost/q23_collision.json`。

其他看似仅由一次CCX产生的scratch，其原控制在下一条指令就改变，之后被多次改写，
不能按“重算一次CCX”计价。优先处理实际的lookup输出/seed共存与全阶段释放契约。

## 4. 统一回本预算：先算账，再做昂贵搜索

脚本 [economics.py](economics.py) 直接使用已有官方结果与原版计费公式。
输出 `artifacts/20261106_direction_research/economics.json`。

| 改动情景 | 净收益/回本条件 |
|---|---|
| 固定62Q净省1C | 省62成本，单项约0.06346% |
| 固定62Q净省20C / 100C | 单项约1.269% / 6.346% |
| 62→61Q | 额外总C必须 <25.8331；零额外C时单项省1.613% |
| 62→60Q | 额外总C必须 <52.5273；零额外C时单项省3.226% |
| 62→58Q | 额外总C必须 <108.6772；零额外C时单项省6.452% |
| 62→63Q | 必须净省 >25.0130C 才回本 |
| 全部直接T消失 | 只有0.25C / 15.5成本容量，约0.01586% |
| 41→32旋转、绝对余量不变且其他成本不增 | 可省66.3230C；这是新表示的回本预算，不是删9门即可取得 |

所有“额外C”均含计算、反计算、纠相、查表和旋转合成，而非只算forward AND。
不同方向的节省可能相互重叠，也可能因Q/误差变化抵消。

### 固定41旋转的精度改善存在可计算的小上界

由官方结果反推当前绝对最小余量 `m0=eps*41/pi=3.17659581365e-12 turns`。
任何合法近似的全域最小余量都不可能超过最严格输入的容差：
`tol(max_x)=3.36719742258e-11 turns`。因此即使相位误差处处为零，固定41旋转也最多把余量提高10.6000倍。

按官方合成模型，最多节省
`41 * 0.56/4 * log2(10.6000) = 19.55041C`，即1212.12545成本，**单项1.24065%**。
这一上界不依赖旧LP是否达到全局最优，但只适用于固定旋转执行数、固定其他资源的余量路线。
若减少旋转数或改变算术成本，应重新计算，不能拿该上界否定整个近似架构方向。

## 5. 前沿研究如何转成有效实验

完整一手论文、代码固定版本、适用边界见 [前沿方法调查](frontier_methods.md)。

- [Measurement-Based Uncomputation，2609.31605v1](https://arxiv.org/html/2609.31605v1#S4.SS3)：
  支持把测量诱导的相位表示与纠相电路共同设计。本题只能用全部syndrome均被正确修复的路线。
  对应的实验是多HMR、多输出、经典奇偶、真实可达域共同优化；不能把post-selection收益套进来。
- [乘法复杂度/XAG，1908.01609](https://arxiv.org/abs/1908.01609)：
  免费XOR与昂贵AND的分离贴合本题，但应优化最终Q×C并包含恢复成本。
  caterpillar、mockturtle可借用算法思想；现成库对任意dirty边界或总node数的最优性不等于本题最优性。
- [Reqomp](https://quantum-journal.org/papers/q-2024-02-19-1258/)：
  为有限qubit预算的重算提供方法参照。本题多测量/经典版本语义必须显式保留，不能直接套通用调度器。
- [2026-10数值函数电路研究，2610.22367v1](https://arxiv.org/html/2610.22367v1#S3)：
  支持分区、截断误差和寄存器消费次序共同设计。其Coulomb示例的输入/输出和绝对误差约束不同，
  不能把论文门数当作本赛候选成绩。
- 新QROM算法只有在相应表规模、输出宽度和dirty空间条件下才可能有用；
  标准dense QROM写回需要普通H时不符合kickmix。现有查表已经高度专用，不能直接宣称成本减半。

## 6. 新表示的全域数值可行性实验

[piecewise_numeric.py](piecewise_numeric.py) 实际运行约1.484秒（脚本内计时，不含解释器启动）。
它先把x按4的幂归一化，再在 `[1,2)`、`[2,4)` 各作dyadic等分，
用Chebyshev插值生成2/3/4次局部多项式，系数量化，Horner每步做有符号整数向下截断。
相位、参考值与容差均以64-bit相位单位比较。

24个参数组合，各覆盖全部3,133,452个x；10个组合没有数值容差失败，14个失败。
部分通过组合如下：

| 阶数 / 总区间数 / 系数小数位 | 最大误差/容差 | 绝对最小余量 turns |
|---|---:|---:|
| 2 / 128 / 28 | 0.796949 | 8.30784e-12 |
| 3 / 32 / 28 | 0.671441 | 1.27499e-11 |
| 3 / 64 / 30 | 0.107529 | 3.04522e-11 |
| 4 / 16 / 28 | 0.526307 | 1.68584e-11 |

结果、10组整数系数与Python/NumPy版本保存在 `artifacts/20261106_direction_research/numeric/`。
这是本轮新的**经典定点模型数值检查**，没有生成量子电路，没有检查scratch恢复或测量相位。
例如32段三次/28位若同时装载四个有符号系数，朴素表输出就是120位，已远超62Q总预算；
所以只有采用系数流式消费、复用输入/输出或直接相位表示，才有继续研究的意义。
它没有证明胜过原公开架构，也没有修正或替代当前候选。

## 7. 下一轮实验的具体进入与停止条件

1. **先做一个多输出块的完整契约。** 从46-CCX块开始，再查看相邻HMR与后缀消费。
   采用可达前缀约束，区分必须保留的输出、可改的临时表示、必须正确的测量相位。
   必须给出真实替代电路和严格正的期望计费改善；一次几何筛选命中不是候选。
2. **并行做61Q设计账。** 先覆盖98段保守峰值，至少对lookup、选择器、后段算术三类长峰提出兼容方案。
   提前排除q23简单重建；全电路净新增C（含重算、纠相及其他改动的增减）必须低于25.8331C。
   若只能局部降峰或已超预算，则该具体调度停止，不继续扩大无依据搜索。
3. **近似支线只生成一个关键内核。** 在数值通过的少数参数上计量实际合法门，
   包括系数prepare/unprepare和输入恢复。以实际Q计算总C上限，例如80Q仅容1221.2597C。
   若内核加其余不可省部分已经越界，则停止该参数；不能拿数值误差好看代替成本账。
4. **候选成立之后再验证。** 局部全域/符号证明、计费与小规模原生检查先行；
   只有明确正收益的真实KMB才手动运行原版完整验证。当前所有新增结果都还未到这一阶段。
