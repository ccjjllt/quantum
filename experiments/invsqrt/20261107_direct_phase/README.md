# invsqrt：41 个旋转掩码的 ANF 复杂度（直接相位表示可行性）

日期：2026-11-07。基线只读：`artifacts/20261106_syed_v9/invsqrt/syed_v9_nofallback.kmb`
（62Q，官方本地 PASS，score 97,700.776777236）。
本轮回答“能否绕开现有算术，直接从 22 个输入位综合 41 个相位控制”的第一步：
这些掩码作为 x 的布尔函数，ANF 到底有多稀疏。

## 方法

脚本 [anf_masks.py](anf_masks.py)：

1. 在**全部 2^22 个 22-bit x**（含 x=0 和 x>3,133,452 的非法点）上，
   按全 0 HMR 分支模拟基线到 41 个 fine `Z_POW`，记录控制线的真值表。
2. 对每个掩码做 22 维快速 Möbius 变换，得到 ANF 系数。
3. 统计非零系数数、代数次数、最高次单项式数。

这是**全立方体的一种特定扩展**，没有对非法 x 做 don't-care 最小化；
它回答的是“现有电路自然产生的掩码”是否适合直接单项式综合，而不是
证明合法域上不存在更稀疏的扩展。

## 结果

`artifacts/20261107_direct_phase/anf_masks.json`：

| 掩码 | op | ANF 非零项 | 次数 |
|---:|---:|---:|---:|
| 0 | 15287 | 170 | 9 |
| 1 | 15295 | 1,792 | 14 |
| 2 | 15303 | 3,642 | 14 |
| 3 | 15311 | 11,414 | 15 |
| 4-6 | 15318-15336 | 104k-812k | 20-21 |
| 7-14 | 15345-15607 | 1.5M-2.2M | 21-22 |
| 15-40 | 25408-25648 | 1.7M-2.1M | 21-22 |

- 41 个掩码的次数集合：`{9,14,15,20,21,22}`。
- 非零 ANF 项最少的 4 个掩码是低权重项（2^-17..2^-14），
  分别为 170 / 1,792 / 3,642 / 11,414 项；**仅这 4 个**低于 10 万项。
- 其余 37 个掩码的非零项在 **10 万到 220 万**之间，次数 20-22。
- 一个 170 项的掩码单独用单项式实现就要 170 个 CCX，已经超过该旋转
  7.19C 的合成成本；37 个百万项掩码更不可能用直接 ANF 综合。

## 结论

- 现有 41 个旋转掩码不是 22 位 x 上的稀疏低次多项式；直接按 ANF
  综合需要百万级 CCX，远高于当前 1,457 个付费门。
- 因此“直接相位表示”若要求精确重现现有掩码，不可行；只有改用
  **不同的近似相位函数**（piecewise/33 权重等）才可能绕开这些稠密掩码，
  而那些方向已分别被 7.4× 成本和 53C 覆盖代价否决。
- 这不是合法域 don't-care 最小化的下界；若未来发现合法域上极稀疏的
  等价扩展，结论需要重算。
- 本轮没有生成候选，没有运行官方验证；基线不变。
