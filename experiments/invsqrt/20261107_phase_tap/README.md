本轮回答一个问题：**能不能用“每个系数位控制一个固定角度 Z_POW、单项式用 AND 免费 CX 生成”

   而该表示需要 **2,095 个**（21.8 倍）；B 需要 9,332 个，预算只够 95 个（98.2 倍）。

## 1. 方案说明（哪些是实测、哪些是构造计数）

所有 paid 数（CCX/CCZ/CSWAP）都用官方 `km.CircuitBuilder` 构造后读
`OperationStatistics` 得到；见 `kernels_tap.py` 与
`artifacts/20261107_phase_tap/kernels/kernels.json`。旋转合成成本用官方公式
`0.56·log2(1/eps)+5.3` T（`eps = π·min_margin/n_rot`），除以 4 换成 C。
数值相位用全域整数/定点模型检查（第 2 节），不是量子模拟。

### 1.1 归一化与地址提取

22-bit 输入 `x ≥ 1`，`e = floor(log2 x)`，`s = e//2`（4 bit，0..10），`g = e & 1`。

```
N = x << (21 - e)        # 2^21 <= N < 2^22，隐藏位固定在 bit 21
f = N - 2^21             # 21 个尾数位
address = (g << 6) | (f >> 15)      # 7 bit = 128 段
v       = (f & 0x7fff) / 2^15       # 15-bit 段内余量
phase   = 2^-s * p_g(v),  p_g(v) = 1/sqrt(2^g (1+v)) 的 2 次插值
```

这与 `20261106_piecewise_cost/numeric_scan.py` 的 `(address, u)` **逐位相同**
（已用全部 3,133,452 个 x 验证 `array_equal`），所以 d2/S128/w28 与 d3/S32/w28
的数值结论可以直接继承。

构造：

| 组件 | paid | 说明 |
|---|---:|---|
| 22-bit leading-one detector（后缀 OR 链，e 的 5 位是免费 CX 奇偶） | 22 | 实测 `lod`，Q 峰值 22+23+5=50 |
| LOD 反算（恢复 x 前必须撤掉 t 寄存器） | 22 | 在移位 x 之前立刻做 |
| 22-bit barrel shift by `21-e`（5 级 CSWAP） | 79 | 实测 `shift(22,5)`；逆变换同价 |
| **归一化小计** | **202** | 79+79+22+22 |

注意 `21-e`，不是 `2s`：这样隐藏位固定在 bit 21、尾数位宽恒为 21，
`g` 只进入系数表（`2^{-g/2}` 因子），不引入位宽随组变化的问题。

### 1.2 系数 QROM

128 项表（32 项用于变体 B），输出三个（B 为四个）系数。实测：

| entries | 输出位宽 | paid |
|---:|---:|---:|
| 128 | 38 | 144 |
| 128 | 64 | 144 |
| 128 | 114 | 144 |
| 32 | 85 | 37 |
| 32 | 114 | 37 |

**输出位宽对 paid 完全免费**（拷贝是 CX），只有项数进入成本。
`init_lookup` + `del_lookup` 合计 144/37，含测量反计算；地址可以是
“6 个尾数位 + 1 个 g 位”的不连续 `km.array`，实测同价（144）。

系数在 2^-28 网格上四舍五入，符号在所有段上一致（A: `[+, -, +]`，
B: `[+, -, +, -]`，逐表检查过），所以用**符号-幅值**：只存幅值位，负系数整组用负角，
不需要符号控制位。存储位范围（绝对权重指数）：

| | c0 | c1 | c2 | c3 | 合计 |
|---|---|---|---:|---:|---:|
| A (128 段) | 1..28 | 8..28 | 14..28 | — | 64 bit |
| B (32 段) | 1..28 | 6..28 | 10..28 | 14..28 | 85 bit |

### 1.3 把 `2^-s` 折进系数位置（关键设计点）

任务要求“固定角度 Z_POW”。相位是 `2^-s·p(v)`，所以一个相对权重 `2^-b` 的系数位
必须落在**绝对**位置 `b+s`。`s` 是量子寄存器，因此必须把系数位搬到绝对位置：

- 每个系数一条 **38-bit 对齐寄存器**（位置 1..38 = 权重 2^-1..2^-38），
  QROM 直接把系数幅值位写进它（表项做位反序即可），
  再用 4 级 CSWAP 桶形移位器按 `s` 移位：`37+36+34+30 = 137` CSWAP/寄存器，实测 137。
- 求逆同样 137，再 `del_lookup`。三个系数（B 四个）合计 `2×3×137 = 822`
  （B: `2×4×137 = 1,096`）。

考虑过但更贵的替代（记录在此以便复核）：

| 方案 | 成本 | 结论 |
|---|---:|---|
| 11-bit 地址 QROM（把 s,g 并入，2048 项）直接输出绝对权重系数 | ~2,150C（抽头数量不变） | 比 432+822=1,254C 贵 ~900C |
| 每个抽头按 11 个 `s` 值条件化（11× 抽头 + 额外 AND） | ≈ +22,600 CCX 且 11× 旋转 | 明显更贵 |
| 相位寄存器 + Horner 算术后再移位 | 即 20261106 piecewise 路线（3,370.7C） | 见第 7 节 |

### 1.4 单项式

`v = Σ_{i=1..15} v_i 2^-i`（变体 B 17 位）。`v_i` 就是对齐后 x 寄存器的尾数位，
**不需要 XOR 拷贝**。乘积项用官方 `init_and` 生成（1 个 CCX，`del_and` 是
HMR + 条件 CZ，paid 为 0）：

- `v^1`：单项式就是单根线，0 个门；
- `v^2`：`v_i v_i'`（i<i'）各 1 个 CCX。A 用 105 个、B 用 136 个，全部保留到最后统一 `del_and`；
- `v^3`（仅 B）：3 个不同下标的单项式要 2 个 CCX（先 AND 出一对，再 AND 第三个），
  2 个不同下标的（`v_i^2 v_i'`）只要 1 个 CCX。实际用到 479 个三下标单项式，
  合计 `1,094` CCX（含 136 个二下标）。

### 1.5 相位抽头（Z_POW）

对每个（对齐后系数位位置 `p`，`v^j` 的单项式 `m`）：

```
weight = mult(m) * 2^-(p + k(m))        # k = 下标和
若 weight < 2^-K_abs：不建这个抽头
否则：init_and(系数位, 单项式, anc);  z_pow(anc, ±weight);  del_and(系数位, 单项式, anc)
```

- `init_and` 实测 **1 paid**，`del_and` **0 paid**；单抽头原型与 100 抽头链实测
  都是“每抽头 1 CCX + 1 Z_POW”（`kernels.json` 的 `taps`）。
- **j=0 的抽头不需要 ancilla**：直接 `z_pow(系数位, 2^-p)`，paid=0
  （实测 `z_pow` 直接打在系数位上 40 次，paid=0、rotations=40）。
- 角度分类按官方 `z_pow_class`：`p+k ≤ 2` 是 Clifford（2 个）、`p+k = 3` 是 T（1 个）、
  其余全部是 fine rotation。
- 同一（位置，单项式）只有唯一抽头，没有可合并的重复；“共享”只发生在
  单项式这一侧（一个 `v_i v_i'` ancilla 服务该位置所有系数位）= 上面的 105/136 个 CCX。
  （不同系数位的控制不同、角度不同，不能合并；同角度不同控制的旋转也不能合并。）

### 1.6 清理与恢复

逆序撤掉：抽头 ancilla（`del_and`，免费）→ 系数寄存器反移位（137×3/×4）→
`del_lookup`（含在 QROM 成本里）→ x 反移位（79，把 N 变回 x）。
LOD 的 t 寄存器在移位 x 之前就已经反算掉（22），末尾无需重建。
表项/角度/移位量都是经典常数，量子数据的搬运只有 x 的两次移位和每个系数寄存器的两次移位。
这里假设 `init_lookup`/`del_lookup` 的测量反计算分支与 `del_and` 的相位修正如官方
原语（与 20261106 piecewise 的成本模型同一假设）；**本轮没有构造 KMB 去实证**。

| 项 | Q |
|---|---:|
| x（移位后就地复用为 N） | 22 |
| e（s=e[1:5]、g=e[0] 都是免费 CX） | 5 |
| 系数对齐寄存器（逐个系数复用） | 38 |
| QROM 内部 unary-iteration ancilla（128 项 / 32 项） | 7 / 5 |

## 6. 稳健性：需要什么才可能翻盘

- 在 A 的余量（7.44e-12 turns）下，694.840824C 只能买 **96 个** fine rotation；
  该表示需要 2,095 个。即使把 3,621C 的 paid 全部按 0 计，仅旋转 16,370C
  仍是预算的 23.6 倍。
- 要让这类“每系数位 × 每单项式一个固定角旋转”的方案进预算，必须把抽头数
  降到 ~100 量级，即相位只需 ~10 个有效二进制位、或单项式只有 ~5 个——
  那已经不是 2^-24 相对精度下的分段多项式。
- 少 1Q（62→61）只放宽 25.8331C；本方案的缺口是它的 700–3,300 倍，
  Q 侧的调度完全无法弥补。
- 因此该方向在当前容差与计费模型下**结构性**不可行，而不是“再优化 5–10%”。

## 7. 与 Horner 算术实现对照

同一个 d2/S128/w28 多项式，20261106 的 Horner 账是 **3,370.7C**（Q=220 构造 /
134 下界）。本轮的直接抽头版是 **19,991.4C**，是它的 5.93 倍。
原因很直接：28×17 截断乘法一次只要 731C（compute+uncompute 1,462C），
而把同一个乘法拆成 `28×15 = 420` 个“系数位 × 余量位”的固定角旋转，
按每个 ~7.8C 就是 3,300C。**把乘法换成旋转抽头，在这个计费模型下是亏的。**
