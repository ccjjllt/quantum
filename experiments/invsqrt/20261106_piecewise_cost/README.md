日期：2026-11-06。工作区 `.worktree/invsqrt`，分支 `codex/invsqrt-research`。

> **2026-11-07 更正：** 后续 `20261107_newton_goldschmidt/` 对 `kernels.py::multiplier()`
> 做了 256 例穷举模拟，发现它实际计算的是 `(A·U) mod 2^w_acc` 的低位回绕，
> 不是高半部分。因此本文的 Horner/乘法门数是**下界**，不是合法乘法构造；
> 真实成本只会更高。分段三次族的结论（远高于预算）不受影响，反而更强。

## 4. 成本模型与账本

模型的分段相位评估器（全部可逆，测量反计算只用官方 `del_and`/`del_lookup` 式结构）：

```
x(22) --LOD--> e(5) --barrel shift--> mantissa(21) = address(5) + residual(r)
      --(d+1) 次 init_lookup--> 系数 c_d..c_0
      --degree-d truncated Horner（按幅度缩放项宽）--> p (w fractional bits)
      --right barrel shift by floor(e/2) (4 stages)--> phase register
      --每个相位位一个 Z_POW--> 反演 Horner --> del_lookup --> 反演归一化
```

d3/S32/w28 的完整账本（单位 C）：

| 组件 | C | 说明 |
|---|---:|---|
| 归一化 compute + uncompute | 96 + 96 | LOD 22 + 21-bit shift 74 |
| 系数 QROM | 148 | 4 × 37（已含 compute+uncompute） |
| Horner compute | 1,776 | 缩放项宽 [28,23,19,15]，u=17 |
| Horner uncompute | 1,776 | 精确逆，同价 |
| 相位 barrel shift compute + uncompute | 97 + 97 | 4 级，w=28 |
| 一般旋转 | 170.27 | 25 个；eps = π·1.275e-11/25 = 1.602e-12 → 6.82C/rot |
| 直接 T | 0.25 | 2⁻³ 位 |
| **合计** | **4,256.5** | |
| Q（builder 峰值 + 49） | 264 | Horner kernel 215 + x 22 + e 5 + LOD flags 22 |

d2/S128/w28 与 d2/S256/w27 的对照：

| 组件 | d2/S128/w28 | d2/S256/w27 |
|---|---:|---:|
| 归一化 ×2 | 192 | 192 |
| 系数 QROM | 3×144 = 432 | 3×279 = 837 |
| Horner ×2 （项宽） | 2,380（[28,21,15], u=15） | 2,124（[27,19,12], u=14） |
| 相位移位 ×2 | 194 | 186 |
| 一般旋转 | 172.43（eps 1.044e-12） | 162.35（eps 2.011e-12） |
| 直接 T | 0.25 | 0.25 |
| **合计** | **3,370.7** | **3,501.6** |

Q 取 builder 峰值 + 49（x 22 + e 5 + LOD flags 22）。flags 也可改为反演时重算，
省 22Q、多花 22C，score 变化 < 7%；两种取法都不改变结论。

决定性的单个 kernel 是 **28×17→28 截断乘法**：实测 731C forward，精确逆同价，
一次乘法 compute+uncompute = 1,462C，单独就是 694.84C 预算的 2.10 倍。
缩放项宽后 d3/S32 的三次乘法合计只有 1,776C（每项宽度不同），但整个 Horner
compute+uncompute 仍是 3,552C。

## 7. 为什么这一族必然亏：边际成本

同族内只有两个旋钮：多一阶多项式，或多一倍分段。用缩放项宽后：

| 变化 | Horner ΔC | QROM ΔC | 净 ΔC |
|---|---:|---:|---:|
| d2/S256 → d3/S32（w27） | +1,212（2,124→3,336） | −689（837→148） | **+523** |
| d2/S128 → d3/S64（w28） | +870（2,380→3,250） | −144（432→288） | **+726** |
| d3/S32 → d4/S16（w28） | +1,120（3,552→4,672） | −63（148→85） | **+1,057** |
| d2/S128 → d2/S256（w27） | −256（2,380→2,124） | +405（432→837） | **+149** |

"省 8 倍表只省 689C，多一阶 Horner 要花 870–1,212C"——两者同量级，
最优在 d2/S128–256 附近，而不是 32 段三次。这正是基线公开描述的
"8-bit 地址 + 二次 Horner + 一次 Newton"所在的位置。

与基线对照：本文最好的通用构造（d2/S256，3,501.6C）相对基线 1,575.8C 是 **2.22×**；
最低 C 的 d2/S128（3,370.7C）是 2.14×。这说明模型对"同族人工优化"还留了 ~2.2× 余量。
把同样的 2.2× 折扣套到 d3/S32/w28（4,256.5/2.2 ≈ 1,935C）仍高于 694.84C，
且低于本文的乐观 AND 构造计数 2,402.5C，说明该折扣不可叠加。

模型没有明显偏袒基线，可对照四个已知点：

| 实现 | Q | C | score |
|---|---:|---:|---:|

## 8. 敏感性：需要什么才可能翻盘

口径 A（front+旋转簇 694.84C）下，d3/S32 的非算术 paid 已经是 534.0C >
524.32C 的 paid 预算，所以：

1. 必须先把归一化 + QROM + 相位移位从 534.0C 压到 < 524.3C（至少 −10C，且不能加旋转）；并且
2. Horner 的 compute+uncompute 必须为 0 —— 不可能。

口径 B（整个电路 1575.8C）下，Horner 预算 = 1575.8 − 534.0 − 170.5 = 871.3C。
实测 3,552C 需要降 4.1×；乐观构造计数 1,698C 需要降 1.95×。

只有在以下情况才值得重开：

- 出现一种**每次截断乘法 < 250C（compute+uncompute）**的构造，且
- 相位不需要 4 级 barrel shift（例如直接产生对齐好的相位位），且
- 总 Q ≤ 100。

三者同时成立时，d3/S32 的总 C 才可能进到 ~1,000C 量级，仍需与基线 1,575.8C 比较。
按当前实测，这三条都没有依据。

## 9. 语义检查：HMR 结果不携带 x 信息（负面结果）

一个自然的"绕过算术"想法是：把 x 复制到 scratch、HMR 得到经典位、用免费经典逻辑
算出相位、再用经典条件旋转。本轮用官方 simulator 验证了这**不可行**：
`HMR` 是 X 基测量后复位，对 Z 基态的结果**均匀随机且与测量值无关**；
只有 `(-1)^{b·f(x)}` 的相位 kickback 与 f(x) 有关。

`hmr_semantics.py`（256 shots，x=0 vs x=1）：

```
{'x': 0, 'ones_in_outcome': 123, 'shots': 256, 'phase_values': ['0'], 'paid': 0, 'zpow': 0}
{'x': 1, 'ones_in_outcome': 138, 'shots': 256, 'phase_values': ['0', '1'], 'paid': 0, 'zpow': 0}
```

两个输入都是 ~50% 的 1，经典位不揭示 x；只有 phase 不同。
所以经典条件只能做相位修正，不能计算 x 的函数；可逆算术是必需的。
这也解释了为什么基线用 41 个**无条件** Z_POW（相位 kickback 在量子上完成），
而不是经典条件旋转。

## 10. 验证范围与不可声称的事项

- 数值结论是**全域经典定点模型**：3,133,452 个 x 全部检查，目标/容差用官方整数公式；
  不是量子电路，不检查 scratch 恢复、测量分支或相位。
- 门数是**官方构造原语的实测值**（`km.CircuitBuilder` + `OperationStatistics`），
  不是完整候选电路的官方计费。
- 没有生成候选 KMB，没有跑 `verify_submission_invsqrt.py`，没有官方 PASS，
  没有 Kaggle 成绩。也没有修改基线、共享依赖或官方数据。
- "乐观构造计数"是构造性计数（每 partial product 一个 AND），不是定理；
  它只用于说明即使按最有利的计数也亏。
- 基线的 2.22× 人工优化比只用于校准模型偏差，不是可叠加的收益。
- 项宽缩放假设各系数按固定 2 的幂缩放、加法时免费对齐（wire relabel）。
  这在 kickmix 的 CX/SWAP 免费模型下成立；没有为对齐引入额外 CCX。
