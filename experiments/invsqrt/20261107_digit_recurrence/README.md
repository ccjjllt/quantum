## 2. 算法规格

### 2.1 归一化与指数

```
e = floor(log2 x) ∈ [0,21]      (22-bit LOD，后缀 OR 链)
k = e >> 1 ∈ [0,10],  g = e & 1
R = x << (21 - 2k) ∈ [2^21, 2^23),     m = R / 2^21 ∈ [1,4)
```

`21-2k = 1 + 2(10-k)`：**无条件左移 1 位是纯 relabel（免费）**，剩下 4 个条件级
(2,4,8,16) 由 `10-k` 的 4 个 bit 控制。寄存器宽 23 位即可，因为对每个基态
部分移位数 ≤ 总移位数，最高位始终 ≤ 22，环移不会把有效位卷回。

### 2.2 non-restoring sqrt（n 位小数）

```
W_0 = m - 1
b_i = 1 if W_{i-1} ≥ 0 else 0        # 数字选择 = 残差符号位，1 根 qubit，免费
d_i = 2 b_i - 1
A'_i = 2 s_{i-1} + d_i 2^-i = Σ_{j<i} b_j 2^(2-j) + (3 + 2 b_i) 2^-i
W_i = 2 W_{i-1} - d_i A'_i
s_i = 1 + Σ_{j≤i} d_j 2^-j
```

关键实现点（都已用门级仿真验证）：

- **每步只有一次无条件加法。** `A'_i > 0` 且最低位恒为 1，所以
  `+A'_i` 与 `-A'_i = complement(A'_i)+1` 只在**最低位以上**不同；
  `-A'_i` 的取补恰好把低位表示成常量。把 offset 拼成
  `[1, 1, 0, b_{i-1}⊕b_i, ..., b_1⊕b_i, b_i, b_i]`（窗口 `[29-i, 32]`，宽 `i+4`）
  后，一次 `iadd` 就同时完成“加还是减”和“减 2^-i”，
  不需要 controlled add、不需要单独的常量减法。
- **2W 是纯 relabel**（qubit 列表前插一个 |0>），无门。
- 被移出的符号扩展位 = 新最高位（两者相等），用一根**免费 CX** 清零后回收，
  所以 W 寄存器恒定 33 位 + 1 根周转位。
- 位数 n=28、窗口逐位增长：forward = Σ_{i=1}^{28}(i+3) = 490，实测 492
  （含一次性 `W_0 = m-1` 的 `isub(1)` 2 个 paid）。

### 2.3 non-restoring 倒数（n 位）

```
r_0 = 1;   s = 2B + 2^-n = [1, b_n, ..., b_1]   (最低位恒为 1)
c_i = 1 if r_{i-1} ≥ 0 else 0
q_i = 2 c_i - 1
r_i = 2 r_{i-1} - q_i s
y = 2C - 1 + 2^-n = Σ_{j=2..n} c_j 2^(1-j) + 2^-n
```

同样利用“最低位恒为 1”，offset `[1, b_n⊕c_i, ..., b_1⊕c_i, c_i, c_i]`
一次 `iadd` 完成条件加减。窗口是全宽 `n+3` 位，
forward = n·(n+2) = 840，实测 840。

### 2.4 相位

```
phase = 2^-k y,   y ∈ (0.5, 1),  y = 0.c_2...c_n + 2^-n
Y = y·2^n = 1 + Σ_{j=2..n} c_j 2^(n+1-j)      (整数)
theta = Y << (64 - n - k)                       (精确，无舍入)
```

对齐：y 的 28 个 bit 在权重 `2^-1..2^-28`，右移 k 后落在 `2^-(k+1)..2^-(k+n)`，
`k ∈ [0,10]` ⇒ **位置并集是 1..38**，所以固定角旋转是 **38 个，不是 28 个**。
题面的“28 个固定角旋转”只有在 `2^-k` 对齐免费且位置固定时才成立；
本文按实际需要的 38 个计费，并另给 28 个的假设值（第 5 节）。

### 2.5 为什么用 sqrt+倒数，而不是直接 rsqrt 递推

直接的倒数平方根递推（`R_i = x y_i² - 1`, `y_{i+1} = y_i + d 2^{-(i+1)}`）需要维护
`P_i = x y_i`：

```
P_{i+1} = P_i + d 2^{-(i+1)} x
R_{i+1} = R_i + d 2^{-i} P_i + x 2^{-2(i+1)}
```

即**每 digit 3 次加法**，且修正项 `x·4^{-(i+1)}` 依赖量子寄存器 x（不能像 sqrt 的
`d² 4^{-(i+1)}` 那样折成经典常量）。而 sqrt+倒数是 **每 digit 2 次加法**
（sqrt 一次、倒数一次），且两边的修正项都能吸收进操作数的最低位。
所以本文选 sqrt+倒数；直接 rsqrt 只会更贵（约 1.5 倍算术）。

## 6. radix-4（30-bit）构造成本

radix-4 用 15 个 4 进制数字（30 bit），数字集 `{-2,-1,0,1,2}`。
每个 sqrt/倒数递推步需要：

1. **数字选择**：`d ≈ round(V/s)`，阈值在 `±s/2, ±3s/2`（含量子除数），
   必须做 quantum-quantum 比较；
2. **操作数生成**：`d·(2s)` 需在 `{0, ±2s, ±4s}` 中选，`2s/4s` 之间是条件移位；
3. **一次加法**（30 位，实测 29）。

两种选择模型（都用实测原语）：

| 选择模型 | 每步 C | 算术 C（4×15 步） | 总 C | Q | / 694.84 |
|---|---:|---:|---:|---:|---:|
| 精确阈值（2 次量子比较 + 3s/2 加法 + 数字位） | 152 | 9,120 | **9,818** | 169 | **14.13×** |
| 乐观 5-bit→3-bit QROM 查表（37）+ 移位 + 加法 | 96 | 5,760 | **6,458** | 169 | **9.29×** |

radix-4 比 radix-2 贵 1.9–2.9 倍：迭代次数减半，但每步要多一次量子比较
（30C）和一次条件移位（30C），而 radix-2 的数字选择是**残差符号位，完全免费**。
**radix-4 没有做全域数值检查，也没有构造电路**（结论不需要：两种选择模型都已远超预算）。
