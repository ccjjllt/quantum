# DQI 高收益方向：官方契约、公开源码与前沿方法的交叉研究

日期：2026-11-06（北京时间）。分支 `codex/dqi-research`，研究开始时 HEAD `58ffddb`。
固定对照：Syed notebook V9 / run366109544，dataset V9，892Q。

## 结论

**最应投入的是低宽度算术模块的完整重综合，以及相位与恢复调度的联合设计。**
继续盲扫旧模板、直接采用新论文的整机BM、重复实施mask投影，均缺乏相对当前基线的收益依据。
宽度优化必须和门数一起选择；“多一个qubit必然更差”与“少一个qubit必然更好”都不成立。

本轮确认了可操作的研究对象、可用源码和定量收益门槛，**没有确认新的全电路净降本候选**。
下列百分比是带前提的目标尺度，不是实验已实现成绩。

| 优先级 | 方向 | 当前证据 | 最小下一步与停止条件 |
|---|---|---|---|
| 1，短预算 | 在当前ABI上联合重综合重复二次算术核 | 已从真实Syed窗口提取精确ANF与张量；已独立验证公开42-CCX整域乘加核；PolyTOF提供不同于旧删门搜索的分解空间 | 先做一类小核，维持输入/输出、全局Q和phase；如只省免费CX或替代不满足边界契约则停止。无改善时不继续全文件随机扫描 |
| 2，大收益主线 | 相位与恢复表示、checkpoint、重算共同设计 | 三个恢复阶段占50.52%；找到可追溯的旧C1源bundle和独立BM生成器，能学习可逆状态重建 | 先重建一个高成本C1节点的forward/reverse契约，比较完整恢复及纠相。约1万门级目标才值得推进大范围改写 |
| 3，与2联合 | 扫描少量宽度—重算选择，而非单点缩宽 | 每+1Q需先省约885 meanT；12Q寄存器的价格约10428 meanT；只改一个局部峰不减全局Q | 对可生成节点枚举少数缓存/重算选择，按全局Q²T统一排序；不能靠局部allocator图宣称收益 |
| 4，有条件 | 可明确归因的稀有支持删减或高权重失败修复 | 已重新计算官方权重与CP/R预算；旧失败经验不能直接推总体概率 | 先找到具体资源和确定反例，理论节省小于惩罚预算就停止。仅修w≤17的预算约143门，通常不是高收益主线 |

两个重要修正：公开旧源并非普遍不可得；此前q26“只有3个Python文件”的记录遗漏了文件。
此外HW-22已公开与旧−42合并候选相同的电路标识，该候选应作为公开组合的本地重现与方法验证，不能宣称独占原创。
最新Syed V9的完整生成器仍未取得；找到的是可研究的旧C1源链和独立算法生成器。
来源、版本、许可、静态闭包审计见已删除的公开实现报告（清理前为 PUBLIC_IMPLEMENTATIONS.md，见 git 历史 `90afd5a`）。

## 1. 官方成本与输入约束

权威代码为本工作区只读共享的 `data/competition/verifiers/dqi/verify_submission_dqi.py`。
本轮读取原文，没有修改官方验证器。

- 输入接口已经占840Q：70×12-bit syndrome；必须恢复全部syndrome并清零其他qubits。
- E0…E4094是运行时经典mask，每个12-bit字独立均匀随机；要求计算解码错误与mask的内积相位，不要求输出整个错误字。
- 成本 `C=R(eps+) Q² meanT`，meanT只计实际执行的Toffoli-like；不能用CNOT、T-depth或文献T门数代替。
- 默认102400 shots、CP单侧置信参数2^-128；失败含值恢复与phase，两者不重复计数。
- 即便抽到零失败，R也约1.191260；不能把它当1。一个额外失败（0→1）会要求约1808 meanT的节省才能抵消。

本轮的资源情景统一使用已有普通256-shot的meanT=395395.47265625作为近似；它不是新增全量评分。
所有跨方案资源比较都说明是否固定R，不能以一次抽样分数决定小收益真假。

## 2. 本轮新增本机证据

### 2.1 精确静态阶段普查

`stage_census.py` 读取真实Syed KMB并按INFO_TAG逐门计数，8.53秒完成。
总数与native `operation_statistics()`一致：395679；嵌套标签错配0、未闭合0。
这把此前SVG坐标估计升级为精确静态计数；仍不等于各阶段平均执行门数。

| 阶段 | 静态Toffoli-like | 说明 |
|---|---:|---|
| extract | 59169 | forward |
| synthesis | 31635 | forward |
| convert | 60687 | 表示转换 |
| scan | 44275 | 已有mask跳过，静态计入被跳过的门 |
| unconvert | 62558 | 恢复 |
| unsynthesis | 40452 | 恢复 |
| unextract | 96903 | 恢复，明显大于extract但差额不等于可删冗余 |
| 合计 | 395679 | CCX382240 + CSWAP12060 + CCZ1379 |

恢复三段199913T，占50.52%；转换对123245T，占31.15%。这些集合重叠，不能把两种收益估算相加。
精确子核次数为inverse12 norm/scalar/products各163次，inverse24各23次；旧记录169/29不适用于新基线。
有标签的子核不是全机算术调用全集；恢复段大量工作只有顶层标签。

### 2.2 实际小核的精确代数结构

`kernel_structure.py` 提取首次出现的命名窗口，把每根边界线视为任意独立变量，传播完整布尔ANF。
下表五类窗口所有改变量均为仅依赖不变输入的二次/仿射函数；不需要假设ancilla初值为零。

| 原始窗口 | 使用线数 / CCX | 独立二次输入 / 改变输出 | 结构 |
|---|---|---|---|
| inverse12 norm | 22 / 15 | 12 / 10 | 可直接二部分为6+6 |
| inverse12 products | 30 / 25 | 18 / 12 | 当前基的二次图非二部 |
| inverse24 norm | 45 / 42 | 24 / 21 | 当前基的二次图非二部，另含免费仿射项 |
| inverse24 products | 60 / 70 | 36 / 24 | 当前基的二次图非二部，另含免费仿射项 |
| multiply v | 72 / 99 | 48 / 24 | 可直接二部分为24+24 |

因此可把目标具体化为 `outputs ^= quadratic(inputs) + affine(inputs)` 的受限分解。
二部者可走三分组双线性路径；其余可用输入×输入→输出分解或先寻找线性换基。
输出不得混入输入parity；需保留所有低阶项与完整线性映射，不能引入kickmix不支持的H gadget。
旧删1…4门失败只否定删除策略，不排除更换整个分解。

inverse12 scalar含R/HMR与相位修正，故没有用纯值ANF假装证明它；aligned_route含CSWAP，也单独保留未分析标记。
当前仅分析每类首例；其他同名调用是否同构、守卫是否相同仍要确认。**没有替换任何窗口。**

有标签inverse12 products总共4075门，给它设“省数万门”目标不合理。
每次省1门只得到163门；每次省8门得到1304门，约为总GM+0.1%的尺度，8门只是门槛而非可达预测。
需先有有效分解，再寻找未标记的同构窗口或多输出共享机会。

### 2.3 一个已独立证实的公开算术积木

固定PolyTOF源码commit `0dcac107d15adc34dc646242d222f21ae7d32699`，仅读取其GF(2^12)门文本。
自写解释器验证全部36输出ANF等于 `(a,b,c+a*b)`，域多项式`t^12+t^3+1`：
**42 CCX、308 CX、36线、0辅助线、0输出失配**。这是覆盖2^36基态的代数验证，非枚举或采样。
该核与Syed的25门products并非同一接口；换域基与嵌入当前程序都尚未完成。
来源版本、MIT许可及其它论文适配条件见已删除的文献报告（清理前为 LITERATURE.md，见 git 历史 `90afd5a`）。

## 3. 高收益要达到什么尺度

固定Q与R时，减少1% DQI成本需约3954 meanT；总GM约增加0.336%。
减少3%成本需约11862门，总GM约增加1.020%。旧−42约为0.0106%成本，仅适合作为微小优化对照。

| 条件性目标 | 成本变化尺度 | 尚未证明的部分 |
|---|---:|---|
| 恢复三段付费门少5%，Q/R不变 | 约省9996静态T，DQI约−2.53% | 新不变量、真实meanT、恢复与phase等价 |
| convert/unconvert少10%，Q/R不变 | 约省12325静态T，DQI约−3.12% | 完整转换契约及多产品共享 |
| unextract少10%，Q/R不变 | 约省9690静态T，DQI约−2.45% | 不是从forward/reverse差额直接推出 |
| 892→880，T/R不变 | DQI−2.67% | 六个阶段的全局峰都需降低；允许重算至多约10857 meanT才打平 |
| 892→904 | 至少先省10428 meanT才打平 | 新增一个12-bit缓存必须省足够重算，含清理 |

这些是替代目标和预算，不是互相独立、可直接累加的收益。
840Q为接口下界；即使辅助线全部消失且T不增加，单纯缩宽也最多省11.32%成本。
所以真正大收益需减少非线性算术/恢复工作，而不仅是挤掉一两根辅助线。

## 4. 公开优秀方案与新论文的反例检查

- [Gu等2026论文](https://arxiv.org/html/2610.22367v1)有完整独立BM源，精确资源442397T/1837Q。
  代入相同R的比赛公式约为当前Syed的4.745倍；其固定mask、TQ计分和量化权重也与比赛不同。
  相对官方EEA的倍数不能视为对Syed的增益；可借鉴其历史恢复和完整生成链。
- [PolyTOF v2](https://arxiv.org/html/2602.15285v2)为近期可直接研究Toffoli数的算法。
  适配已推进到真实窗口ANF，但还没有新的低秩分解；通用Clifford优化的H输出不能直接使用。
- [受控CNOT整体综合](https://arxiv.org/abs/2512.24982v1)提供n线网络最多n Toffoli的构造。
  只对控制不变且余部线性的窗口适用；当前还未找到有可证大收益的超界窗口。
- 当前存在mask_projection/restore_masks，scan=44275=(4095−70)×11，公开旧源也明确投影70点。
  免费线性相位和避免完整错误字物化都已经部分实现，不能再次记账。
- 原始q26完整列表25个Python文件，metadata还指向qcc-dqi-898；另有含248文件的旧C1可复现bundle。
  它们重开生成器级研究，但不是Syed V9生成器。源闭包静态审计不代表本机已构建或验证。

更多来源与版本比较、算法推导与失败预算见已删除的公开实现/算法报告（清理前为 PUBLIC_IMPLEMENTATIONS.md / ALGORITHMS.md，见 git 历史 `90afd5a`）。

## 5. 失败预算与停止投入的方向

权重≤17质量仅7.71e−7，102400 shots中预期0.079次；假设只有这类错误，完全修好它仅容许约143额外meanT。
另一方面w=35占2.77%，w≥34占11.97%，不能通过降低最大纠错权重把它们当稀有输入抛弃。
与“全部≤17失败”情景相比，若扩展至≤20，至少需额外省约7476 meanT；扩到≤21需约19465。
这些来自官方分布的有限二项和情景，非实测失败归因，未建模极小拒绝尾部为有限成本。

不继续优先投入：重复旧−42模板扫描；无相位账的死门删除；靠零mask跳过整机；以CNOT/T-depth改善当榜分改善；
以当前少量普通输入0错宣称全域正确；不考虑全局Q的局部缓存；把新BM宣传倍数或小域论文百分比直接套到Syed。
