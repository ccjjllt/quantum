# DQI 算法路线：新论文的适配边界与高收益假设

日期：2026-11-06（北京时间）。对象仅为 DQI；当前对照为 Syed V9 / run366109544，892Q。
本次读取官方源码、现存电路统计、公开论文及作者代码；只运行标量概率/成本计算，没有生成新候选，没有调用官方 `verify`，没有榜分。

## 1. 必须先固定的契约

本地权威为 `data/competition/verifiers/dqi/verify_submission_dqi.py`：

- 70 个 12-bit syndrome 量子字必须恢复，所有其他量子位归零。
- 4095 个 12-bit `E` 字是每 shot 独立均匀采样的**经典 mask 输入**，不是待输出错误字。
- 要求相位为 `(-1)^sum_j popcount(e_j & M_j)`。不要求输出 49140-bit 解码结果。
- 默认 N=102400，错误数含 value 与 phase 两类且不重复；CP 置信参数 δ=2^-128，成本为 `R(eps_plus) × Q² × meanT`。
- 官方错误权重为三对角矩阵主特征向量的平方；不是均匀 0…35，也不是仅固定权重35。

这些区别使“输出更少”“经典解码器更快”“论文容许10^-3错误”都不能单独推出比赛收益。

## 2. 最新 BM 论文不能整机替换当前 C1

[Gu et al., arXiv:2610.22367v1](https://arxiv.org/html/2610.22367v1)，2026-10-15，给出可重建的 Berlekamp–Massey 架构。其优势来自合并 retain/replace 算术、由输出重建反向信息、稀有历史栈截断和相位直接求值。
这证明新可逆算法架构能远胜原始同步 EEA，但其比较对象不是当前 Kaggle C1/Schur 电路。

[作者精确结果](https://raw.githubusercontent.com/andigu/uncompute/64b5a13aa249f1360846657392e6c66817b26d0f/tasks/dqi-reed-solomon/results.jsonl)为：

| 电路 | Toffoli | Q | 结果口径 |
|---|---:|---:|---|
| 作者重建 Khattar EEA | 5,125,070 | 1,938 | 作者 evaluator |
| 作者优化 BM | 442,397 | 1,837 | 作者 evaluator |
| 当前 Syed V9 | 395,395.47 | 892 | 本机普通分布256-shot meanT；非完整验证 |

仅把已报告资源代入相同 R 的 Q²T，BM/Syed ≈ **4.74536**。这只是跨契约资源比较，不能称 BM 在 Kaggle 的实际成本，但已足以否决“12×宣传意味着可以直接升级当前基线”。

还需处理三项明确不兼容：

1. [作者任务 README](https://raw.githubusercontent.com/andigu/uncompute/64b5a13aa249f1360846657392e6c66817b26d0f/tasks/dqi-reed-solomon/README.md)采用固定随机 mask，优化 T×Q，报告100000-shot的作者验证。
2. [作者 contract](https://raw.githubusercontent.com/andigu/uncompute/64b5a13aa249f1360846657392e6c66817b26d0f/tasks/dqi-reed-solomon/contract.json)将权重分布舍入到1/65536格点，可能消除极低概率权重；比赛直接使用浮点特征向量权重。
3. 原论文采用100/100000的错误容许规则，并讨论97.5%置信界；比赛采用更强CP置信参数与连续R惩罚，且检查 syndrome 恢复。

作者提供的整体生成器可作为算法复现参考；不是当前 Syed 生成器，也不是通过官方验证的替代候选。源码固定到 commit `64b5a13aa249f1360846657392e6c66817b26d0f`（2026-10-16T02:06:21Z，Apache-2.0）；精确发表版本为论文v1，访问日2026-11-06。

## 3. “只求相位”已经部分实现，不能重复记账

[Khattar et al., arXiv:2510.10967v1](https://arxiv.org/html/2510.10967v1)已经把 MBU 解码明确为相位修正，并提供隐式 Bézout 表示和共享寄存器的可逆 EEA。官方 Python 参考电路也按 forward EEA → Chien/Forney phase → reverse EEA 实现。

Gu 的[实现说明](https://andigu.github.io/projects/uncompute/dqi-reed-solomon.html)进一步将 Forney 相位写成 trace pairing，并在扫描前计算 reciprocal polynomial，避免逐点除法；其扫描仍需23T/点。

当前 Syed 的扫描静态总计44275T，恰为 `(4095−70)×11`；现存标签包含 `mask_projection` 与 `restore_masks`。主研究本轮逐门分阶段计数也确认投影存在。
因此以下不能当新高收益：

- 把 mask 的 syndrome-linear 部分移到免费 Z 门；
- 避免持有全部4095个错误字；
- 用论文23T/点扫描替换已经约11T/点的现有扫描；
- 把免费 CNOT 的减少当作比赛 Toffoli 收益。

还有一个简单代数界：设二进制 syndrome 矩阵为 H（840×49140）。若所有运行时 mask 的目标相位都能由 syndrome 的线性函数实现，取逐位单位 mask 就得到线性解码矩阵 D；在所有单比特错误上必有 DH=I。但 `rank(DH)≤840<49140`，矛盾。故整个相位函数不能普遍线性化。这个论证**不是非线性门数下界**，也不排除更便宜的非线性相位实现。

## 4. 真正值得投入的算法级方向

### A. 直接围绕相位和恢复联合重综合：第一优先

当前三个恢复阶段 `unconvert + unsynthesis + unextract = 199913` 静态T，占总静态T **50.52%**。其中 unextract=96903，明显大于 extract=59169。这个差额不是冗余证明，却明确说明恢复调度值得优先解释。

研究问题应是：当前 C1 的 retained-head / Wronskian / continuant 表示，哪些中间量只为下一段相位或反向重建服务？能否保持 projective scale、把转换与恢复配对、用边界仍存活量重建被覆盖量，或将中间乘积直接收缩进所需相位？不预设先生成完整标准 locator/evaluator。

这是从论文可逆信息重建原则导出的**假设**，不是可直接搬入的新恒等式。Syed已采用 narrow return、flag carry及部分产品缓存，必须先识别未覆盖工作。

最小可证伪实验：

1. 从一个反复出现的 C1 节点取得 forward/reverse 边界的精确线映射、域基、守卫及相位契约；先选付费成本最高的转换/恢复节点，而非整段58M操作。
2. 重建一个可生成的局部算术模块，列出它的输入、输出、需保留的非线性临时量以及 HMR 修正；参考公开 BM 的信息重建方式提出替代调度。
3. 用代数等价或小域穷举检查输出和相位；随后对实际12/24-bit模块进行定向零/极点/普通输入诊断。只比较清理、纠相都包含在内的完整模块。
4. 在相同全局Q与失败语义下，若全部恢复阶段能少5%，则静态约省9996T、DQI成本约降2.53%；这是目标尺度而非预测。若局部收益被重算吞没，立即停止该变体。

### B. 选择性省去稀有支持资源：第二优先，必须按官方分布定价

有潜力的是将罕见分支的额外栈/flag/系数窗口从常见路径中分离，再删除这部分资源；不是把采样未触发的任意门直接删掉。前沿 BM 的小栈只是这种思想的实例，不能照用其分布和预算。

本轮重新用官方权重和CP/R函数计算有限二项分布和，结果在 `artifacts/20261106_high_return_research/algorithms/budgets.json`。以下是假定“所有w≤边界失败，除此无错，meanT恒定”的情景；不等于测得的 Syed 失败归因：

| 放弃权重上界 | 概率质量 | N中预期失败 | 相对已放弃≤17，需额外省多少meanT才打平 |
|---|---:|---:|---:|
| 17 | 7.7126e−7 | 0.0790 | 0 |
| 18 | 3.4662e−6 | 0.3549 | 485 |
| 19 | 1.4326e−5 | 1.4670 | 2267 |
| 20 | 5.4524e−5 | 5.5833 | 7476 |
| 21 | 1.9127e−4 | 19.5858 | 19465 |

只有能定位到明确额外资源的低概率路径，才值得用这些数值筛选；目前没有这样的新候选。若出现的是 phase-only错误且该错误只以一半mask显露，失败模型也要重算。

最小实验是重建单个带 pole 支持的节点，识别触发条件对应的权重/代数类别；先算完全删除该支持的静态资源上限，若达不到上表预算就不跑大规模仿真。对通过预算筛查的少数变体再固定逻辑输入做差分，追踪恢复错误和相位错误，不挑最好salt。

### C. 有针对性的高权重偶发失败修复：有价值，但收益依赖定位

修复w≤17在上述仅此一类失败情景下最多允许约 **142.58额外meanT**；仅w≤16约29.26。因此为低权重尾部建立昂贵fallback通常不划算。

更值得定位的是官方分布主区间w≈28…35的意外零/极点错误。必须先以固定逻辑输入重放找到反例，再区分 inherited decoder、近似路径与新改写；不能把一次0错salt视为已经修复。其可用预算取决于真实概率与修复影响，不从旧seed11两次错误直接推总体频率。

## 5. 明确降级的路线

- **整机切BM、朴素Hankel求解、普通经典快算法直接可逆化**：当前公开BM已有足够资源证据不占优；Syed正文还报告其Hankel尝试约14倍超预算，但后者只是作者报告，未在本机复现。
- **把最大纠错数35降至34/33**：官方 `P(w=35)=2.7666%`，`P(w≥34)=11.9658%`。若这些权重上发生value失败，前者R惩罚很大，后者超过1/16；它们不是稀有尾部。若只以随机mask半概率出现相位错误，仍需另算惩罚，不能宣称直接节约。
- **单纯缩到840Q**：840是接口本身下界，即使T与R完全不变，892→840最多降低11.32%成本；当前只有52辅助Q，而不是论文1837Q的宽裕状态。忽略恢复与多阶段峰值的“砍一排寄存器”没有证据。
- **继续盲扫旧 −42 模板**：新基线已检查无适用骨架。只在出现新的精确局部ABI后重开。

`budgets.json`保存完整36项官方权重、N、Q、meanT、CP/R情景参数与二项分布求和覆盖质量。求和使用

`p0=(1−p)^N; p[k+1]=p[k]·(N−k)/(k+1)·p/(1−p)`，

再计算 `sum_k p[k] R(CP(k,N))`，直到所覆盖质量≥1−2e−14。极小尾部及可能拒绝的事件没有作为有限成本建模，所以称有限和情景，不能宣称严格全分布期望评分。

相对≤17情景的门数打平条件为 `T_new < T_old × R17/Rnew`。修复预算条件为 `T_new < T_old × Rold/R0`。使用当前普通256-shot meanT只是便于排序的近似。
