### 为什么局部缓存已枯竭（载体 0/1618 的结构原因）

四个 closed 实验从四个角度证明了同一件事——**52/52 压力**（`deepfix` §4：
200k 窗口重跑 29 窗口中 23 个 52/52 全忙）：

1. 仿射干净乘积无重复（`20261109_dqi_deepfix` §2）：权威修复（跨阶段污染定位＋
   阶段入口重置）后 `unsynthesis` 141 clean / `unextract` 1030 clean，
   strict 与 mask-only 重复组均为 **0**（SWAP 精确/保守两种语义下一致）。
2. 深非线性值等价也不可缓存（`deepfix` §3/§5）：精确原子-掩码结构哈希找到
   1618 组函数重复（3500 位点，含 368 组字面不同、778 位点，8 对经官方模拟器
   切片验证值全等）——但全跨度持有 **0/1618 可行**、连续子间隔 **0/1882**、
   小间隔宽池 **0/40**。诊断分布的关键句：约束卡在"跨度内有闲置线，但其
   **最近一次触碰非归零**"，而非跨度内被触碰——即**归零线供给为 0**，不是
   需求侧问题。
3. 脏线借用语义错误（`20261109_dqi_dirtyk2` §1/§4）：固定 +2 开销的跨持有经
   toy 实测值污染；唯一值正确的脏线构造是逐处 4 门恒等式（每处 **+1**），
   正确模型下 648 位点净 +648。双重 closed（既无载体，模型本身也亏）。
4. 退路全是 Q 换 T 且净负（`20261109_dqi_decoder_struct` §4、
   `20261109_dqi_r_nonw17` §2）：84 稳定对需 +1Q（+8.41亿）换 −84 门（−7.96千万），
   净 +7.61亿；检测守卫需 +2Q（+16.81亿）换 +2 门，净 +16.8亿。

一句话：**Isabe/Syed-V10 模板要求"干净闲置线"，而该电路在全部时间尺度
（全跨度→200k 窗口→gap=2）上干净闲置线恒为 0**——构造性透明的改写（s7 片段
892Q＋99,567bit 全等）证明恒等式成立，但**载体不存在**使任何实例化都必须
+Q，而 +Q 的账（§2）在当前门数密度下永远算不过来。

## 2. 大收益杠杆排序（量化）

### 2.1 三项的汇率与 break-even 线

| 杠杆 | 单位收益 | 换算成门 |
|---|---|---|
| 静态/T −1 门 | −947,843 分 | 1 |
| 失败 −1 shot（/102400） | −17.21亿分（−0.459%） | **≈1817 门** |
| Q −1（892→891） | −8.41亿分（−0.22%） | **≈887 门** |

推论（后文反复使用）：
- **R 项是单发最大杠杆**：修 1 个失败 ≈ 省 1817 门，超过全部历史 −N（−21/−14/−3/−55）
  中任何一次。但它是**期望量**，不是静态量——需要多 salt 大样本才能确权
  （`r_nonw17` §2：慷慨假设"修 1 残余/7.37M"省 23.9M，但单事件 Poisson SE ±110M，
  与零不可区分）。
- **Q 项的 break-even 线是 887 门/Q**：任何 +1Q 的改写必须省 >887 门才回本；
  任何 −1Q 的改写最多可花 887 门。84 稳定对（−84 门/+1Q）与检测守卫
  （+2 门/+2Q）死在这条线上——不是差一点，是差一个数量级。
- **T 项是确定性最强的杠杆**：静态差分≈均值差分（无条件位点执行概率≈1），
  每门 947,843 分**无方差**。`unextract` 96,888 门占 24.5%：其中 1% ≈ 969 门
  ≈ 9.2亿分 ≈ −0.25%，且不需要任何 R 实证。

### 2.2 R 项改进的期望定价框架

对任何"修失败"假设，净账公式（`r_nonw17` §2 口径）：

```text
E[Δscore] = −Δk(每102400期望修好的失败数) × 1.721e9
            ＋ ΔT(静态门变化) × 947,843
            ＋ Δ(Q²)(宽度变化) × R × T
```

可 claim 的门槛：`|E[Δscore]| ≫ Poisson SE`。残余失败率 ~21/7.37M
（0.29/102400）时，72-draw campaign 的 SE ≈ √21/72 per 102400 ≈ 0.064/102400
≈ **±1.1亿分**——任何期望收益 <1亿的 R 假设在现有算力下不可确权，
只能记为"量级吻合的假设"而不能 claim。

### 2.3 w17 之外的 R 候选清单（状态：全部未确权，仅一项值得保留）

按 `r_nonw17` §1 分类（诚实边界：除 w17 外均为"量级估计＋静态位置"，
非实测归因；默认 salt 2048-shot 基线 value=0/phase=0，无失败分布可定位）：

| 候选 | 量级估计 | 状态 |
|---|---|---|
| w17 极点退化 | Syed 实测 27→21/72 draws（期望 0.063/102400，与权重 `p(17)=6.14e-7` 吻合）；修复 +175 门（+1.66亿）vs 期望省 ~6 fails/7.37M ≈ −1.4亿 | **唯一实证过的 R 修复**；frontier 缺 node-9/fold-18 保留；手工插 175 门不可靠，未构造。保留为模板 |
| extract 69×`inverse24` accidental-zero | 69·2⁻²⁴ ≈ 0.42/102400，与 Syed 残余 0.29/102400 **同量级吻合** | 最可疑但最难：69 块合计 ~3910 CCX，单块率 0.006/102400 永不可归因；需结构性论证（如加宽测试位宽？代价门），不是守卫能解决的 |

72-salt 实证先行**（入口 README 记载的唯一切口之一）。

## 3. 新架构方向（每个：upside 数量级＋第一个具体实验）

> 前提：§1 证明**同一解码器族内的局部改写已枯竭**（干净载体恒 0、
> 脏借用语义错、Q 换 T 差一个数量级）。大幅提分只能来自**换族、换参数理解、
> 整段重写、或宽度重构**——即改变"52/52 压力"这个约束本身，而不是在约束内找载体。

### 方向 A：先把 −55 吃透（最便宜，定向一切）

- **问题**：`e9f54be3` 相对 `4432ec5f` 的 −55 门机制未知（字节大 773B、
  三家同代字节相同说明是同一家族的新优化，但谱系未记录）。
- **upside**：理解 −55 的 pattern 类别（新窥孔类？新复用类？宽度换门类？），
  若是可推广的 pattern 类（如 Kirill 窥孔当年 14 处），残余实例每处
  −1…−50 门（−0.001%…−0.01%）；即使不可推广，也为方向 B/C 排除已优化区。
- **第一个实验**（纯静态，无候选无验证器）：把 `frontier_audit` 的
  `audit_frontier_4432ec5f.py` 方法原样搬到 `e9f54be3 vs 4432ec5f`：
  按 `SEMANTIC` 阶段逐门精确差分＋门类细分（CCX/CCZ/CSWAP），定位 −55 落在
  哪些阶段；再对差异窗口做局部反汇编分类。是 −38 拆解的复用，工作量最小、
  信息量最大。

### 方向 B：换解码器族（upside 最大，10% 量级想象空间）

- **现状理解**（`decoder_struct` §1 实测）：frontier 实现的是频域风格解码——
  extract 侧 depth-1 主体 54,357 CCX＋192 CSWAP、69×inverse24（3,910 CCX）、
  6×multiply-v（594 CCX，6 体各异）、6×inverse12；unextract 侧窄返回
  （无 multiply/inverse24 逆块）＋50 个 flag-carry 重建段；
  scan 侧 44,275 rung（conditionally-clean AND，4025 掩码守卫）。
- **候选族**：Berlekamp-Massey（伴随式→错误定位多项式，O(n²) GF 乘 vs 当前
  频域链）、Euclid（Gao 式解码）、窄返回变体（单遍逆节点已用，能否把
  depth-1 主体 94,193 CCX 也纳入"算一次、测一次、偿一次"的形态？）、
  时域 Chien＋Forney vs 当前频域实现。
- **upside**：解码器族切换是历史上 −62（Syed V10）之外唯一出现过的
  >50 门量级变化的层级；extract（59,169）＋unextract（96,888）合计 156k 门中
  若有 5% 结构性差异 ≈ 7,800 门 ≈ 74亿分 ≈ −2%。即使只动 extract 的
  inverse24（3,910 CCX，accidental-zero 的同一位置），改写测试结构也是一鱼两吃
  （T 省＋R 修）。
- **第一个实验**（静态只读）：拿到 SomeJoint 889Q 电路
 （`quantum-circuits-22-77-local-gm-889-qubit-dqi`，带嵌入生成器，
  research-map 已索引）做**阶段画像对比**：Q=889（−3Q ≈ −25亿天然优势？）、
  各阶段 paid 门数、extract 是否含 inverse24/multiply、scan 是否掩码守卫、
  unextract 是否窄返回。若 889Q 的 T 与 frontier 同量级，则"−3Q 的宽度重构"
  本身就是方向 D 的存在性证明；若其 extract 阶段显著更小，则换族切口确立。

### 方向 C：综合器重写——整个 unextract 的窄返回重构＋跨阶段 pebbling

- **动机**：`unextract` 96,888 门是全电路最大单阶段（24.5%），其中 depth-1 主体
  94,193 CCX；窄返回已擦除了 multiply 逆块（`decoder_struct` S1 closed 的反面
  启示：**擦除发生过，且省了一整类逆块**）。问题是：depth-1 主体为什么不能
  被"第二次擦除"？当前它是值复用（Ozer −21 已吃）＋逐点反算；替代方案是
  跨 extract→scan→unextract 边界的 Bennett pebbling 分析——**存 syndrome
  中间值（花 Q）vs 重算（花 T）的全局最优点**，而不是在 52/52 约束内找载体。
- **upside**：1% ≈ 969 门 ≈ −9.2亿（−0.25%），无方差、无 R 实证需求；
  若 pebbling 重构打开 5% ≈ −1.2%。
- **第一个实验**（静态分析）：从 kmx 解析做 extract→scan→unextract 边界的
  **存活值 DAG 分析**——多少值跨过边界、每值的重算代价（门数）vs 存储代价
  （1 线宽×跨度），把每个候选点标在 Q-N 平面上（§2.1 的 887 线）。
  输出是一张"重算/存储交换表"，不是候选。这是方向 C 是否值得投入综合器
  重写的判决性证据。

### 方向 D：Q−N 权衡重构（break-even 887 门/Q 是铁律）

- **现状**：两次 +Q 尝试死在 break-even 线上一个数量级之外（§1.4）；
  反向（−Q）从未被系统尝试。SomeJoint 889Q 悬置了一个问题：−3Q 是否可行，
  代价多少 T？
- **关键子问题**：峰值 892 由哪个阶段驱动？52 根 ancilla（840..891）的
  高水位是全局的还是局部的？若峰值局部（如仅 unextract 某窗口），
  串行化该窗口 −kQ 的代价是 +gates（重算/溢出到 bit），只要 gates < 887×k
  就净胜——这是 break-even 线**上方**第一次出现可能为正的区域。
- **upside**：−1Q ≈ −8.4亿（−0.22%）≈ 887 门等价；−3Q（若 T 不变）≈ −25亿
  ≈ −0.67%，超过历史上任何一次 −N。
- **第一个实验**（纯静态）：kmx 单遍扫描各阶段**存活 qubit 高水位线**
  （per-stage live-qubit high-water mark）＋峰值窗口定位。 cheap，
  直接回答"宽度是哪一段顶上去的"以及"串行化切口在哪里"。

### 不列为方向的东西（已 closed，只引用）

- 字面/仿射/结构乘积缓存、脏线借用、CCZ 缓存、广播、稳定对退路、
  scan 守卫移植、单点检测守卫、node-3 极点——见入口 README 汇总表，
  全部 0 可行或净负，不再投入。
- Private LB 双提交字节哈希分散化（`frontier_audit` §2.3）：是对冲抽样波动的
  **提交战术**，不改变期望分数，不列为架构方向；最终提交前再执行即可。

## 4. 方向排序（2-3 个，先做哪个）

1. **方向 A（`e9f54be3` −55 差分）＋ 方向 B 的第一个实验（SomeJoint 889Q 画像）
   并行先做**：两个都是纯静态只读、复用 `frontier_audit` 现成方法、几天量级；
   输出决定后进方向：若 −55 是可推广 pattern→局部再收割一轮；
   若 889Q 画像显示宽度/阶段结构差异→方向 D/B 立项。
2. **方向 D（Q 高水位＋串行化切口）**：break-even 线上方唯一未经系统探索的区域；
   输出是"−kQ 花多少门"的报价单，直接可与 887 线比较，判决性强。
3. **方向 C（跨阶段 pebbling 交换表）**：投入最大（需 DAG 分析），但 unextract
   24.5% 的体量使即使 1% 也有 −0.25%；放在 A/B/D 定向之后，避免在未知 −55
   机制的电路上做无用功。

R 项（w17 重建＋72-salt 7M-shot 实证）不进入前三：它是**验证密集型**而非
架构型，且期望净账在当前估计下≈0（+1.66亿门 vs −1.4亿期望，SE ±1.1亿）；
只有当 A–D 产出结构性候选、或申请到 7M-shot 算力时，才值得把 w17 模板
（含 +175 门构造工程）重新拿起。入口 README 的"唯一切口"判断依然有效：
**换码族，或 72-salt R 实证**——本复盘把前者细化为 B/C/D，把后者留作算力
到位后的保留项。
