# Maoxin V2：DQI 方法审计与下一步方向（2026-11-05，北京时间）

本研究在分支 `codex/dqi-research` 的独立 worktree 中进行。输入为 Maoxin V2 原始 ZIP 解压的
`artifacts/20261105_maoxin_v2/release/dqi.kmb`；没有改动候选，没有计算或匹配 SHA，
没有运行完整官方验证、查询本账号榜分或提交 Kaggle。文中的 `fd0ef`、`993c` 是上游文件标识。

## 结论

当前 DQI 是 Syed 的 891Q 解码器、yoyobar 的 `993c` 改写与 Busy 的 R41 乘积缓存组合；
Maoxin 的这次新贡献主要在化学权重迁移，DQI 本身复用 Busy 的文件。
现有缓存只再省约 13.816 个平均 Toffoli，约为 DQI 成本的 **0.003481%**、总 GM 的
**0.001160%**。追求总 GM +0.1% 需要约 **1,188.34** 个平均 Toffoli，不能把不断寻找
同类单门窗口当作高收益主线。

本轮得到两类新证据：

1. 当前实际 KMB 的 42 处缓存改写片段与公开指令数据逐项对应；14 条缓存的两端载体
   干净性和中间闲置可以直接从本机电路证明。尚缺的是 **14 个跨时间端点乘积恒等式**，
   不是把局部 80 案例检查升级成整个 DQI 的正确性证明。
2. 本版本的固定权重诊断中，`w=17` 两个独立批次共 512/512 次 syndrome 恢复失败；
   `w=18,19,20,31,35` 各 256 次未观察错误。这不同于旧 889Q 审计的 w17 结果，
   因而旧版本的失败边界不能沿用。它仍不是比赛分布失败率测量。

## R41 实际做了什么

设第一次使用乘积 `p=a*b` 时载体 `s=0`：原来的 `CCX a b t` 改为
`CCX a b s; CX s t`。在较长公共区间后，先把 p 用 SWAP 放入另一个空闲载体 r，
再用 `CX r u` 代替后续 `CCX c d u`，或用 `CZ r u` 代替 `CCZ c d u`。
最后 `HMR r m; CZ c d if m` 清空载体并抵消测量产生的相位。

这要求在两个时间点有 `a*b=c*d`，还要求载体初始为零、其存活期间没有被其他指令使用。
单纯省掉反计算门或看到相同物理线名不足以建立这些条件。

当前 14 个核中，11 个末端为 CCX，3 个为 CCZ。42 处补丁各自的静态净变化合计为
少 14 个付费门（属于已采用的历史收益）；Busy 的三个 paired seed 实测平均节省为
13.816（各约13.6、14.1、13.7）。测量结果会影响后续条件门实际执行数，因此静态14与
有限样本均值应分别记录。Busy 的旧 892Q 电路曾节省 2,577 门，那是不同基线，不能在此再相加。

### 本机独立结构核查

`analyze_dqi.py` 从实际 KMB 导出内存文本，不写大体积 KMX，不计算哈希：

- 58,390,266 行规范文本中的 42 个片段均与公开指令字面量一致。
- 14 个首次载体的最后改值指令均为无条件 HMR，故载体初始为0。
- 14 个 SWAP 目标的最后改值均为 SWAP；沿其输入再追一步均遇到无条件 HMR，故目标为0。
- 每个核分别扫描第一次写入至 SWAP、SWAP 至最后使用两个区间，28 个区间均没有引用
  当时的载体。整个缓存跨度为 **133,084–367,290 行**；并非只看相邻几条门。
- 首次、SWAP和最终窗口的外部条件栈均为空。
- 最后写入检查覆盖当前实际门集全部会改变计算基值的操作：R、HMR、X、CX、CCX、
  SWAP、CSWAP；CZ/CCZ/Z/NEG 是相位操作，BIT 操作作用在经典位，条件栈单独处理。
- 7 个核的端点控制线名称相同，但两线在公共区间内均有相关改值；所以零个核能仅靠
  “相同且未修改的控制线”规则证明乘积相等。这是剩余证明义务，**不是证明乘积不等**。
- 自写布尔/相位公式对 CCX 和 CCZ 各枚举80个满足 `a*b=c*d` 的时间边界案例，
  值和相位差均为0；删除最终条件CZ，每种核出现4个相位反例。这个计算假设端点乘积相等，
  不验证完整公共区间，更不构成全局解码证明。

证据：[analysis.json](../../../artifacts/20261105_maoxin_v2/dqi/analysis.json)。
没有加载父 `993c` 二进制，所以“所有其他父子指令相同”仍属于上游报告，并非本机完整差分。

## 当前资源和成本瓶颈

本机静态统计：**891Q**，其中840Q为70个12位 syndrome 输入、51Q为私有空间；
58,336,121 operations，**397,177 Toffoli-like**（382,636 CCX + 13,064 CSWAP + 1,477 CCZ）。
52,166,276 条 CX 不直接进入付费门数，减少这些线性门主要改善模拟吞吐量。

Kirill V7 作者的一次完整官方报告为102,400 shots、平均 **396,904.594189** Toffoli、
1 value / 0 phase error、成本 **377,084,131,045.4871**；本研究只读报告，未复跑。
Maoxin 的默认 salt 日志为0 value / 1 phase error，成本377,084,094,889.3039。
二者的失败类别和均值不必相同；不能由组合榜分反推分项错误数。

静态门数比上述作者均值仅高272.406，即0.06859%。在其他条件不变的假设下，
仅扩大已有随机跳过比例很难带来大幅收益。

| 阶段 | 静态 Toffoli 估计 | 占比 | native 图示峰值Q |
|---|---:|---:|---:|
| extract | 59,595 | 15.0046% | 891 |
| synthesis | 31,637 | 7.9655% | 891 |
| convert | 60,796 | 15.3070% | 891 |
| scan | 44,275 | 11.1474% | 890 |
| unconvert | 62,711 | 15.7892% | 891 |
| unsynthesis | 40,539 | 10.2068% | 891 |
| unextract | 97,624 | 24.5795% | 891 |

这些阶段值由 native flame SVG 的舍入坐标换算，约有1门的舍入误差，是静态估计，
不是运行时分阶段计数。六个阶段同时达到891Q，降低单个分配峰并不自动降低计分Q。
`convert+unconvert` 合计 **31.0962%**，`unextract` 占 **24.5795%**，是优先找结构收益的区域。

## 失败诊断与 R 的代价

本轮手动执行两个有界命令，合计 **2,816 shots**：1,792-shot 初步诊断加
1,024-shot 边界复核。使用官方输入生成/寄存器判定 helpers 和本机 native kickmix，
不调用 `verify()`，不产生 PASS 或比赛分数。

| 输入分布 | shots | 实际观察 |
|---|---:|---|
| 固定 w=0 | 256 | 256 value errors |
| 固定 w=16 | 256 | 256 value errors |
| 固定 w=17，两次预定seed | 512 | 512 value errors；第二批明确为syndrome恢复错误、scratch零 |
| 固定 w=18/19/20/31/35 | 各256 | 每批0 value / 0 phase errors |
| 官方权重分布，两批 | 512 | 0 value / 0 phase errors |

固定权重样本不是比赛分布；0错误的小样本不能说明稀有错误消失。来源和参数见
[初步诊断](../../../artifacts/20261105_maoxin_v2/dqi/distribution_probe.json)及
[边界复核](../../../artifacts/20261105_maoxin_v2/dqi/boundary_probe.json)。
官方分布 `P(w≤17)=7.71261e-7`。即使该集合全部失败，也只对应每102,400 shots
约0.07898次预期失败；这只是该权重集合的最大贡献，不能解释或排除更高权重的稀有失败。
本轮未证明所有w≤17必败，未证明w≥18全正确，也未归因于新缓存还是继承的近似解码。

原始成本为 `R(epsilon_plus) × Q² × mean_T`；即便观察到0失败，
128-bit置信水平仍给出 `R0=1.1912604648`，不是1。

| 失败数/102,400 | R | 相对0失败的DQI成本变化 | 总GM变化（其他项固定） |
|---:|---:|---:|---:|
| 0 | 1.191260465 | 0 | 0 |
| 1 | 1.196731499 | +0.459264% | −0.152621% |
| 2 | 1.201388060 | +0.850158% | −0.281790% |

单次从0变1失败需约 **1,814.51** 个平均 Toffoli 节省才能抵消；这是单次计分敏感性，
不是“最多能花1814门修复一个错误”的期望预算。新文件改变官方抽样/测量随机性；
候选比较应预先固定相同逻辑输入和测量seed或报告多seed分布，不能挑选最好的salt。

## 下一轮方向：按可兑现收益排序

| 优先级 | 研究问题与最小实验 | 保留条件 |
|---|---|---|
| 1，近期 | **补齐14条跨时间乘积证明，再找可扩展复用。** 把端点乘积沿实际公共指令反向传播成受限ANF或有限域表达式；先处理7个端点控制线同名窗口中的一个。当前载体干净/闲置已有明确证据，可避免重复审计它们。保存真实反例或UNKNOWN。 | 必须证明两时间函数相等并保留HMR纠相。它是研究可信度前提，单独完成无直接降本；若扩展后仍只有十几门，应停止同类大范围盲扫。 |
| 2，主攻结构 | **联合改写 convert/unconvert 与相位scan，或 extract/unextract 的数据表示和恢复。** 先为一个重复有限域内核建立当前输入/输出契约、付费门计数和反向清理成本，再考虑节点顺序、转换融合或共享乘积。 | 目标净省至少约1,200 mean T，Q≤891，失败行为不恶化。整个转换对约123,507静态门，降1%约1,235门，足以达到总GM约+0.1%的尺度；不是已取得候选。 |
| 3，宽度协同 | **让所有891Q峰值降到890或889。** 根据六个达峰阶段逐个解释51个私有位的存活，并考虑用重复计算换1–2个scratch，而非只移动单个peak。 | Q890在R不变时可接受约892.42额外mean T；Q889可接受1,787.86。若不加门，分别约+0.07489%和+0.14993%总GM。所有峰需一起下降。 |
| 4，高不确定性 | **有限域算术联合综合。** 针对转换或恢复中重复的GF(2^24)乘法/求逆，搜索邻接乘积共享或更低rank构造，先精确计数调用次数与清理。 | 不能沿用旧889Q的rank调用频率和预算；先用当前阶段/源码证明次数。每多1Q必须至少省约889.42mean T才能保本。 |
| 5，稳健性 | **定位w17失败及高权重稀有反例，再按实际概率评估修复。** 对同一逻辑输入比较继承父电路与当前缓存版，区分新增错误和继承近似。 | 不盲目恢复全部guard。必须用任务分布概率和R的变化算期望收益，固定权重256/256失败本身不说明值得投入大量门修复。 |

840Q只是输入寄存器下界，不是可达到的解码器宽度；假设T/R完全不变，891→840的
极乐观总GM收益也只有约4.01%。同样，有限模板失败不构成算法下界。

## 复现与实际执行范围

环境沿用 Python3.12、PyPI native kickmix1.0.0。在本worktree手动运行：

```sh
uv run python experiments/dqi/20261105_maoxin_v2/analyze_dqi.py
uv run python experiments/dqi/20261105_maoxin_v2/probe_distribution.py
uv run python experiments/dqi/20261105_maoxin_v2/probe_distribution.py --boundary
```

当前脚本追加了syndrome/scratch分项，首轮原始distribution_probe.json保留运行时较早字段；
边界文件有分项。没有新优化电路，没有全量本地成绩，没有新增线上成绩。
